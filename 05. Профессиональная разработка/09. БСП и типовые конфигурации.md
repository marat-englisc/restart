> [!abstract] Коротко
> **БСП** (Библиотека стандартных подсистем) — библиотека общих механизмов, используемая во многих современных типовых конфигурациях 1С: пользователи и права, печать, дополнительные отчёты и обработки, файлы, обмены, длительные операции и десятки служебных функций (`ОбщегоНазначения.*`). При доработке типовой используем механизмы установленной БСП и расширения, проверяя совместимость после обновлений.

> [!info] Отдельная среда для этой темы
> В учебной «1С:Купец» БСП не внедрена. Поэтому вызовы `ОбщегоНазначения.*` нельзя просто скопировать в неё: используйте копию решения с БСП и документацию **его** версии. Состав подсистем и экспортных методов в разных конфигурациях различается.

![[Картинки/05. Профессиональная разработка/09-Общие-модули-учебной-базы.png]]

*Реальный состав ветки «Общие модули» учебной базы: `РасчетыКлиентСервер`, `ПроверкиОбъектов`, `ФоноваяПроверка`. Модуля `ОбщегоНазначения` здесь нет. В решении с БСП ищите нужный экспортный метод в модуле этой библиотеки и сверяйте его параметры.*

## Часто используемые подсистемы БСП

| Подсистема БСП | Что даёт | Где встретите |
| --- | --- | --- |
| Базовая функциональность | `ОбщегоНазначения`, `ОбщегоНазначенияКлиентСервер`, `СтроковыеФункцииКлиентСервер` | В любом модуле |
| Пользователи, Управление доступом | Группы доступа, профили, RLS по шаблонам | Администрирование |
| Печать | Общее окно печати, подключаемые команды, PDF/почта | Кнопка «Печать» |
| Дополнительные отчёты и обработки | Подключение `.epf/.erf` без изменения конфигурации | Администрирование → Печатные формы, отчёты и обработки |
| Длительные операции | Фоновое выполнение с индикатором | Тяжёлые отчёты, обработки |
| Подключаемые команды | Команды «Создать на основании», «Заполнить» для многих объектов | Формы документов |
| Обмен данными, Работа с файлами, Свойства, Версионирование… | Готовые механизмы | По задаче |

Документация — на [ИТС](https://its.1c.ru/db/bsp3doc) (раздел «Библиотека стандартных подсистем»). Перед тем как писать своё — ищем готовое в БСП.

## Самые нужные функции

```1C
// Значение одного реквизита по ссылке — одним запросом, без получения объекта
ИНН = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Контрагент, "ИНН");

// Несколько реквизитов → Структура
Реквизиты = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Договор, "Владелец, Организация, ВалютаВзаиморасчетов");

// Сообщение с привязкой к полю (в БСП 3.x — серверный/клиентский варианты)
ОбщегоНазначения.СообщитьПользователю("Не заполнен покупатель", ЭтотОбъект, "Покупатель", , Отказ);

// Отбор динамического списка без ручного поиска элемента
ОбщегоНазначенияКлиентСервер.УстановитьЭлементОтбораДинамическогоСписка(
	Список, "Покупатель", ПокупательОтбор, ВидСравненияКомпоновкиДанных.Равно, , ЗначениеЗаполнено(ПокупательОтбор));

// Проверка: есть ли подсистема в этой конфигурации
Если ОбщегоНазначения.ПодсистемаСуществует("СтандартныеПодсистемы.Печать") Тогда ...
```

> [!warning] Сверяйте версию
> Сигнатуры функций меняются между редакциями БСП (например, `СообщитьПользователю` в старых версиях жило в `ОбщегоНазначенияКлиентСервер`). Открываем модуль в конкретной конфигурации и читаем комментарий к экспортной функции — он описывает параметры.

> [!tip] Почему `ЗначениеРеквизитаОбъекта`, а не `Ссылка.ИНН`
> Обращение через точку от ссылки может загрузить объект в кэш и привести к лишним чтениям, особенно в цикле. В тонком клиенте разыменование прикладных ссылок недоступно. Получайте нужные поля на сервере одним запросом или подходящей функцией БСП; несколько полей одной ссылки лучше читать вместе. Выигрыш зависит от кэша и контекста вызова.

## Правила доработки типовой

1. **Сначала расширение** ([[04. Расширения и перехват методов]]). Основная конфигурация остаётся на поддержке — обновления ставятся быстро.
2. Если правка основной конфигурации неизбежна — включаем возможность изменения только **у нужного объекта**, а не снимаем с поддержки всю конфигурацию.
3. **Размечаем изменения** в коде — по ним при обновлении находят «свои» правки:

```1C
// ++ Иванов И.И. 19.10.2026 Задача №123 Проверка лимита кредита
Если ПревышенЛимит(Покупатель, СуммаДокумента) Тогда
	Отказ = Истина;
КонецЕсли;
// -- Иванов И.И. 19.10.2026 Задача №123
```

4. Используем **механизмы БСП** вместо самописных: печать — через подсистему «Печать», права — через профили групп доступа, внешние формы — через «Дополнительные отчёты и обработки».
5. Не меняем типовые общие модули БСП — для этого есть **переопределяемые модули** (`…Переопределяемый`), куда разработчик встраивает свою логику.

## Внешние обработки в типовой

Внешняя обработка подключается к типовой через «Дополнительные отчёты и обработки», если в её модуле объекта есть функция регистрации:

```1C
Функция СведенияОВнешнейОбработке() Экспорт
	ПараметрыРегистрации = ДополнительныеОтчетыИОбработки.СведенияОВнешнейОбработке("2.4.1.1");
	ПараметрыРегистрации.Вид = ДополнительныеОтчетыИОбработкиКлиентСервер.ВидОбработкиДополнительнаяОбработка();
	ПараметрыРегистрации.Версия = "1.0";
	// команды обработки: ПараметрыРегистрации.Команды.Добавить() ...
	Возврат ПараметрыРегистрации;
КонецФункции
```

Так распространяют небольшие доработки (печатные формы, заполнение, загрузки) без обновления конфигурации.

## Обновление типовой с доработками

**Конфигурация → Поддержка → Обновить конфигурацию** → файл `.cfu`/`.cf` поставщика → окно **сравнения/объединения трёх конфигураций**: старая поставщика, новая поставщика, ваша. Изменённые вами объекты требуют решения: взять поставщика, оставить своё или объединить по модулям. Чем меньше правок в основной конфигурации, тем проще этот шаг — ещё один довод за расширения.

> [!question]- Проверь себя
> 1. Почему в типовой предпочитают `ОбщегоНазначения.ЗначениеРеквизитаОбъекта`, а не обращение через точку?
> 2. Нужна новая печатная форма в «Бухгалтерии». Как сделать, не меняя конфигурацию?
> 3. Зачем размечать изменения комментариями `// ++` и `// --`?
>
> > [!success]- Ответы
> > 1. Серверное получение нужных полей позволяет избежать лишних чтений объекта; в тонком клиенте разыменование прикладных ссылок недоступно. Несколько полей лучше получать вместе.
> > 2. Внешняя печатная форма через «Дополнительные отчёты и обработки» или расширение.
> > 3. Чтобы при обновлении и поиске быстро найти и перенести свои правки.
