> [!abstract] Коротко
> Полная печатная форма: **макет** с областями (`Шапка`, `ШапкаТаблицы`, `Строка`, `Подвал`) → **функция модуля менеджера** `ПечатнаяФорма(МассивСсылок)` получает данные одним запросом и выводит области в `ТабличныйДокумент` → **команда объекта** «Печать» вызывает её на сервере и показывает результат на клиенте. Поддерживаем печать нескольких документов и переносы страниц.

Опираемся на макет `ПечатьНакладной` из [[01. Основы конфигурирования/24. Макеты и печатные формы|темы 24 раздела 01]].

## 1. Макет

Документ `РасходнаяНакладная` → **Макеты** → `ПечатьНакладной` (табличный документ). Именованные области строк:

![[Картинки/05. Профессиональная разработка/03-Макет-накладной.png]]

*Исходный макет из темы 01/24 в открытой «1С:Купец»: `Шапка`, `СтрокаТовара`, `Подвал`, параметр итога `ИтоговаяСумма`. Перед кодом ниже его нужно доработать.*

1. Выделите строки 1–3 и переназначьте область `Шапка`; строке 4 задайте имя `ШапкаТаблицы` через **Таблица → Имена → Назначить имя**.
2. Переименуйте область строки 5 из `СтрокаТовара` в `Строка`. Параметр подвала `ИтоговаяСумма` переименуйте в `ИтогоСумма`.
3. Добавьте в шапку параметр `Склад`, в строку товара — колонку с параметром `НомерСтроки`; добавьте соответствующий заголовок. Если вставляете строки, проверьте границы всех областей заново.

Итоговая структура для следующей функции:

| Область | Содержимое | Параметры ячеек |
| --- | --- | --- |
| `Шапка` | «Расходная накладная № … от …», покупатель, склад | `Номер`, `Дата`, `Покупатель`, `Склад` |
| `ШапкаТаблицы` | Заголовки колонок: №, Товар, Кол-во, Цена, Сумма | — |
| `Строка` | Одна строка товара | `НомерСтроки`, `Товар`, `Количество`, `Цена`, `Сумма` |
| `Подвал` | «Итого», подписи | `ИтогоСумма` |

Ячейкам параметров ставим **Заполнение = Параметр** и имя параметра. Формат чисел задаём в свойствах ячейки (например, `ЧДЦ=2`).

## 2. Функция в модуле менеджера

```1C
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

// Формирует печатную форму расходных накладных.
//
// Параметры:
//  МассивСсылок - Массив из ДокументСсылка.РасходнаяНакладная
//
// Возвращаемое значение:
//  ТабличныйДокумент
//
Функция ПечатнаяФорма(МассивСсылок) Экспорт

	ТабДок = Новый ТабличныйДокумент;
	ТабДок.КлючПараметровПечати = "ПАРАМЕТРЫ_ПЕЧАТИ_РасходнаяНакладная";
	ТабДок.ОриентацияСтраницы = ОриентацияСтраницы.Портрет;
	ТабДок.АвтоМасштаб = Истина;
	Макет = Документы.РасходнаяНакладная.ПолучитьМакет("ПечатьНакладной");

	Запрос = Новый Запрос(
	"ВЫБРАТЬ
	|	Д.Ссылка КАК Ссылка,
	|	Д.Номер КАК Номер,
	|	Д.Дата КАК Дата,
	|	Д.Покупатель КАК Покупатель,
	|	Д.Склад КАК Склад,
	|	Д.Товары.(
	|		НомерСтроки КАК НомерСтроки,
	|		Товар КАК Товар,
	|		Количество КАК Количество,
	|		Цена КАК Цена,
	|		Сумма КАК Сумма) КАК Товары
	|ИЗ
	|	Документ.РасходнаяНакладная КАК Д
	|ГДЕ
	|	Д.Ссылка В (&МассивСсылок)
	|УПОРЯДОЧИТЬ ПО
	|	Д.Дата, Д.Ссылка");
	Запрос.УстановитьПараметр("МассивСсылок", МассивСсылок);
	Выборка = Запрос.Выполнить().Выбрать();

	ОбластьШапка   = Макет.ПолучитьОбласть("Шапка");
	ОбластьШапкаТч = Макет.ПолучитьОбласть("ШапкаТаблицы");
	ОбластьСтрока  = Макет.ПолучитьОбласть("Строка");
	ОбластьПодвал  = Макет.ПолучитьОбласть("Подвал");

	ПервыйДокумент = Истина;
	Пока Выборка.Следующий() Цикл

		Если НЕ ПервыйДокумент Тогда
			ТабДок.ВывестиГоризонтальныйРазделительСтраниц();   // каждый документ — с новой страницы
		КонецЕсли;
		ПервыйДокумент = Ложь;

		ОбластьШапка.Параметры.Заполнить(Выборка);             // одноимённые поля: Номер, Покупатель…
		ОбластьШапка.Параметры.Дата = Формат(Выборка.Дата, "ДЛФ=D");
		ТабДок.Вывести(ОбластьШапка);
		ТабДок.Вывести(ОбластьШапкаТч);

		ИтогоСумма = 0;
		ВыборкаТоваров = Выборка.Товары.Выбрать();
		Пока ВыборкаТоваров.Следующий() Цикл
			ОбластьСтрока.Параметры.Заполнить(ВыборкаТоваров);

			// Перенос страницы: если строка не помещается — повторяем шапку таблицы
			Если НЕ ТабДок.ПроверитьВывод(ОбластьСтрока) Тогда
				ТабДок.ВывестиГоризонтальныйРазделительСтраниц();
				ТабДок.Вывести(ОбластьШапкаТч);
			КонецЕсли;

			ТабДок.Вывести(ОбластьСтрока);
			ИтогоСумма = ИтогоСумма + ВыборкаТоваров.Сумма;
		КонецЦикла;

		ОбластьПодвал.Параметры.ИтогоСумма = ИтогоСумма;
		ТабДок.Вывести(ОбластьПодвал);

	КонецЦикла;

	Возврат ТабДок;

КонецФункции

#КонецОбласти

#КонецЕсли
```

| Приём | Зачем |
| --- | --- |
| Один запрос на **все** документы | Не делаем запрос в цикле по ссылкам |
| Вложенная табличная часть `Д.Товары.(…)` | Шапка и строки одним запросом, обход — `Выборка.Товары.Выбрать()` |
| `Параметры.Заполнить(Выборка)` | Заполняет одноимённые параметры области — меньше кода |
| `ПроверитьВывод` | Строка не поместится — разрыв страницы и повтор заголовка таблицы |
| `КлючПараметровПечати` | Платформа запомнит настройки печати пользователя для этой формы |

Параметры страницы задаём **до** `ПроверитьВывод`: результат проверки зависит от них и доступного принтера. Для подписи, которую нельзя отрывать от последней строки, проверяем массив из строки и подвала — приём описан в [примере постраничного вывода 1С](https://1c-dn.com/library/page_by_page_output_to_spreadsheet_document/).

> [!warning] Печать = данные документа
> Итог считаем по строкам документа, а не заново по цене × количество: печать должна совпадать с тем, что записано и проведено.

## 3. Команда «Печать»

Документ → вкладка **Команды** → **Добавить** `ПечатьНакладной`:

| Свойство | Значение |
| --- | --- |
| Группа | Командная панель формы. Важное (или «Печать») |
| Тип параметра команды | `ДокументСсылка.РасходнаяНакладная` |
| Режим использования параметра | **Множественный** — печать нескольких выделенных в списке |
| Изменяет данные | Нет |

Модуль команды:

```1C
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды)

	ТабДок = СформироватьНаСервере(ПараметрКоманды);
	ТабДок.Показать("Расходная накладная");

КонецПроцедуры

&НаСервере
Функция СформироватьНаСервере(МассивСсылок)
	Возврат Документы.РасходнаяНакладная.ПечатнаяФорма(МассивСсылок);
КонецФункции
```

При множественном режиме `ПараметрКоманды` — **массив** ссылок; при одиночном — одна ссылка (тогда оборачиваем: `Новый Массив` + `Добавить`). Команда появится и в форме документа, и в списке.

> [!tip] Печать из формы с несохранёнными изменениями
> Печать читает данные **из базы**. Если документ изменён, но не записан, — сначала запишите его (в типовых решениях на БСП платформа подсистемы печати предлагает это сама).

## Печать в типовых конфигурациях

В решениях на БСП печатные формы подключаются через подсистему **«Печать»**: модуль менеджера реализует `ДобавитьКомандыПечати(КомандыПечати)` и `Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода)`, а пользователь получает общее окно печати с копиями, PDF и почтой. Принцип формирования табличного документа тот же. См. [[09. БСП и типовые конфигурации]].

## Проверка

- Одна строка, много строк (перенос на вторую страницу, повтор заголовка), пустая табличная часть.
- Несколько документов из списка — каждый с новой страницы.
- Длинное наименование товара переносится в ячейке (свойство «Размещение текста: Переносить»).
- Итог совпадает с `ИтоговаяСумма` документа (без услуг — если их нет в печати, это должно быть явно указано).

> [!question]- Проверь себя
> 1. Почему данные для печати нескольких документов получают одним запросом?
> 2. Что делает `ОбластьСтрока.Параметры.Заполнить(ВыборкаТоваров)`?
> 3. Почему функция печати — в модуле менеджера, а не в модуле формы?
>
> > [!success]- Ответы
> > 1. Запрос в цикле по ссылкам — N обращений к базе вместо одного.
> > 2. Заполняет параметры области значениями одноимённых полей выборки.
> > 3. Печать нужна из формы, из списка и из других мест; менеджер — общее место для операций над документами этого вида.
