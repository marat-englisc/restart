> [!abstract] Коротко
> **Подсистемы** делят программу на разделы («Торговый учёт», «НСИ») и определяют, какие команды увидит пользователь. **Командный интерфейс** подсистемы задаёт порядок и группы команд. Дополнительно в ветке «Общие» есть **определяемые типы**, **группы команд**, **общие картинки**; в свойствах корня — имя и синоним всей программы.

## Имя и синоним конфигурации

ПКМ по корню дерева → **Свойства** → меняем **Имя** и **Синоним**:

*Свойства конфигурации: имя `merchant`, синоним «1С:Купец».*

Синоним выводится в заголовке окна Предприятия:

![[Pasted image 20260916200409.png]]

*Заголовок приложения — «1С:Купец».*

## Подсистемы

**Подсистема** логически делит функциональность конфигурации и формирует разделы интерфейса пользователя. Создаётся в **Общие → Подсистемы**:

![[Pasted image 20260916224103.png]]

*Подсистема «Кадровый учёт»: флажок «Включать в командный интерфейс», кнопка «Командный интерфейс», картинка раздела.*

На вкладке **«Состав»** отмечаем объекты, которые входят в подсистему:

![[Pasted image 20260916224215.png]]

*Состав подсистемы «Торговый учёт»: справочники Номенклатура, Контрагенты, Договоры и три документа.*

Один объект может входить в несколько подсистем. После обновления конфигурации БД в Предприятии появится панель разделов:

![[Pasted image 20260916224319.png]]

*Разделы «Кадровый учёт», «НСИ», «Торговый учёт»; в разделе — команды открытия списков и отчёт.*

> [!warning] «Объект создан, но его не видно»
> Самая частая причина — объект не включён ни в одну подсистему (или у пользователя нет прав на него). Проверяем вкладку «Подсистемы» объекта или «Состав» подсистемы.

### Отбор дерева по подсистемам

В большой конфигурации удобно видеть только объекты одной подсистемы: **Действия → По подсистемам** в шапке дерева:

![[Pasted image 20260916225010.png]]

*Меню «Действия» дерева конфигурации: пункт «По подсистемам». Здесь же «Поиск ссылок на объект».*

![[Pasted image 20260916225115.png]]

*Окно отбора: отмечаем нужные подсистемы и нажимаем «Установить».*

В дереве останутся только объекты выбранных подсистем.

## Группы команд и командный интерфейс

Чтобы разложить команды раздела по смысловым блокам, создаём **группу команд**: **Общие → Группы команд**:

![[Pasted image 20260917000817.png]]

*Группа команд «Торговые операции», категория «Панель навигации».*

Открываем подсистему → кнопка **«Командный интерфейс»**:

![[Pasted image 20260917000918.png]]

*Подсистема «Торговый учёт» на вкладке «Основные».*

Перетаскиваем команды в группы, задаём порядок стрелками и видимость флажками (в том числе по ролям):

![[Pasted image 20260917001236.png]]

*Командный интерфейс подсистемы: документы — в группе «Торговые операции», справочники — в «Учётные данные».*

![[Pasted image 20260917001334.png]]

*Результат в Предприятии: команды раздела сгруппированы по заголовкам.*

| Категория группы команд | Где выводится |
| --- | --- |
| Панель навигации | Ссылки на списки (слева/в разделе) |
| Панель действий | Команды «Создать», «Отчёты», «Сервис» |
| Командная панель формы / Форма навигации | В формах объектов |

## Определяемые типы

**Определяемый тип** — один раз описанный набор допустимых типов, который используют разные реквизиты. Создаётся в **Общие → Определяемые типы**:

![[Pasted image 20260911150400.png]]

*Определяемый тип `ДенежныеСредства`: Число(15, 2), неотрицательное.*

Теперь у всех денежных реквизитов указываем тип `ОпределяемыйТип.ДенежныеСредства`. Если понадобится другая точность, меняем её в одном месте. Подробнее — [[25. Общие реквизиты и составные типы]].

> [!question]- Проверь себя
> 1. Документ создан, конфигурация обновлена, но в Предприятии его нет. Что проверить первым?
> 2. Как в большом дереве быстро оставить только объекты подсистемы «Склад»?
> 3. Зачем нужен определяемый тип, если можно указать Число(15,2) у каждого реквизита?
>
> > [!success]- Ответы
> > 1. Включён ли он в подсистему (и есть ли права у пользователя).
> > 2. «Действия → По подсистемам» в шапке дерева.
> > 3. Чтобы менять описание типа в одном месте и гарантировать единообразие.
