> [!abstract] Коротко
> **Перечисление** — фиксированный набор значений, который задаёт разработчик: виды номенклатуры, статусы заказа, способы оплаты. Пользователь может только выбирать значения, но не добавлять новые. Значения используются в коде по имени: `Перечисления.ВидыНоменклатуры.Товар`.

## Когда нужно перечисление

| Ситуация | Что выбрать |
| --- | --- |
| Набор значений известен заранее и меняется только с новой версией программы, от значения зависит алгоритм | **Перечисление**: статусы заказа, Товар/Услуга |
| Пользователи сами пополняют список | **Справочник**: склады, единицы измерения |
| Вариант нужен только в одной форме и не влияет на логику | Можно обойтись списком выбора поля ([[09. Форма справочника]]) |

## Использование в реквизите

Меняем тип реквизита `ВидНоменклатуры` справочника на `ПеречислениеСсылка.ВидыНоменклатуры`:

![[Pasted image 20260909174757.png]]

*Реквизит `ВидНоменклатуры` справочника «Номенклатура» теперь имеет тип перечисления.*

В Предприятии поле станет выпадающим списком из значений перечисления. В базе хранится **ссылка** на значение, а не текст — переименование синонима ничего не сломает.

> [!warning] Тип изменили — проверьте старые данные
> Если реквизит раньше был строкой, после смены типа на перечисление старые строковые значения не превратятся в ссылки сами. При обновлении БД они будут потеряны или потребуют переноса.

## Перечисление в коде

```1C
// Сервер: через менеджер
Если Товар.ВидНоменклатуры = Перечисления.ВидыНоменклатуры.Услуга Тогда
	// услуги не учитываем на складе
КонецЕсли;

// Клиент управляемого приложения: через ПредопределенноеЗначение
Вид = ПредопределенноеЗначение("Перечисление.ВидыНоменклатуры.Товар");
```

В запросе: `ЗНАЧЕНИЕ(Перечисление.ВидыНоменклатуры.Товар)`. Сравниваем с перечислением по **имени значения**, а не по его синониму: синоним могут перевести или переименовать.

> [!question]- Проверь себя
> 1. Нужен список складов, который пополняет кладовщик. Перечисление или справочник?
> 2. Чем перечисление надёжнее списка выбора у поля формы?
> 3. Как получить значение перечисления в клиентском коде формы?
>
> > [!success]- Ответы
> > 1. Справочник — пользователи добавляют значения сами.
> > 2. Перечисление — это тип: в реквизит нельзя записать ничего, кроме его значений, в любом месте программы.
> > 3. `ПредопределенноеЗначение("Перечисление.ВидыНоменклатуры.Товар")`.
