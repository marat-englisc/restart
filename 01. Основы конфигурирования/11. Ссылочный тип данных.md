> [!abstract] Коротко
> **Ссылка** — значение, которое однозначно указывает на объект базы: элемент справочника, документ, значение перечисления. В реквизите хранится не текст «Магомедов М.М.», а ссылка на сотрудника; текст — лишь её **представление**. Переименовали сотрудника — все ссылки показывают новое имя.

## Что такое ссылка

Тип ссылки называется по объекту: `СправочникСсылка.Номенклатура`, `ДокументСсылка.РасходнаяНакладная`, `ПеречислениеСсылка.ВидыНоменклатуры`.

Внутри ссылка содержит **уникальный идентификатор** объекта. Его можно увидеть в Предприятии: ПКМ по элементу → **Получить ссылку**:

![[Pasted image 20260909170909.png]]

*Навигационная ссылка на сотрудника «Магомедов М.М.»: в конце строки — его уникальный идентификатор.*

Текст, который мы видим на экране, — **представление ссылки** (обычно наименование). У двух сотрудников могут быть одинаковые ФИО, но ссылки разные.

| | Ссылка | Представление |
| --- | --- | --- |
| Что это | Идентификатор объекта | Текст для человека |
| Уникально | Да | Нет |
| Меняется при переименовании | Нет | Да |
| Используем для | Хранения, связей, отборов, поиска | Показа пользователю |

## Ссылочный реквизит

Укажем ссылочный тип у константы «Генеральный директор»: в свойстве **Тип** выбираем `СправочникСсылка.Сотрудники`:

![[Pasted image 20260909171051.png]]

*Окно «Редактирование типа данных»: кроме примитивных типов доступны ссылки на справочники, документы, перечисления и другие объекты.*

Теперь в Предприятии значение константы выбирается из справочника сотрудников. Константа хранит **ссылку**; если изменить ФИО в справочнике, в константе сразу отобразится новое имя — она указывает на того же сотрудника.

## Пустая ссылка

Если сотрудник не выбран, в реквизите лежит **пустая ссылка этого типа** — это не `Неопределено` и не пустая строка.

```1C
Если Директор.Пустая() Тогда ...               // метод ссылки
Если НЕ ЗначениеЗаполнено(Директор) Тогда ...  // универсальная проверка
Директор = Справочники.Сотрудники.ПустаяСсылка();
```

## Ссылка и объект

Ссылка позволяет **прочитать** реквизиты объекта (`Директор.Наименование`), но не изменить их. Для изменения по ссылке получаем объект, меняем и записываем:

```1C
// На сервере
СотрудникОбъект = Директор.ПолучитьОбъект();
СотрудникОбъект.Наименование = "Магомедов М.А.";
СотрудникОбъект.Записать();
```

Подробно — [[02. Программирование/23. Программная работа со справочниками|23. Программная работа со справочниками]].

> [!warning] Удаление объекта, на который ссылаются
> Если объект удалить без контроля ссылок, ссылка в реквизитах останется, но объекта уже не будет — появится «битая ссылка» `<Объект не найден>`. Поэтому в 1С есть пометка удаления: [[13. Пометка удаления]].

> [!question]- Проверь себя
> 1. В документе выбран покупатель «ООО Ромашка», потом его переименовали в «ООО Лютик». Что покажет документ?
> 2. Чем пустая ссылка отличается от `Неопределено`?
> 3. Можно ли написать `Директор.Наименование = "…"` и записать?
>
> > [!success]- Ответы
> > 1. «ООО Лютик» — документ хранит ссылку, а не текст.
> > 2. Пустая ссылка имеет конкретный тип (`СправочникСсылка.Сотрудники`), `Неопределено` — отдельное значение без типа объекта.
> > 3. Нет, ссылка только для чтения. Нужно получить объект через `ПолучитьОбъект()`.
