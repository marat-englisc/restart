> [!abstract] Коротко
> Работа в Конфигураторе строится вокруг трёх окон: **главное меню**, **дерево конфигурации** (все объекты программы) и **палитра свойств** выбранного объекта. Сначала открываем конфигурацию, затем выбираем объект в дереве и настраиваем его свойства.

## Главное меню и панель инструментов

![[Pasted image 20260908125709.png]]

*Главное меню Конфигуратора и панель инструментов под ним.*

| Пункт меню | Для чего чаще всего используем |
| --- | --- |
| **Файл** | Новые внешние обработки/отчёты (`Ctrl+N`), открыть файл `.epf`/`.erf` |
| **Конфигурация** | Открыть конфигурацию, сохранить, обновить конфигурацию БД (`F7`), сравнение, расширения, поддержка |
| **Отладка** | Запуск с отладкой (`F5`), точки останова, подключение к сеансам |
| **Администрирование** | Пользователи, выгрузка/загрузка `.dt`, журнал регистрации, тестирование и исправление |
| **Сервис** | Запуск 1С:Предприятия, параметры Конфигуратора |
| **Справка** | Синтакс-помощник, содержание справки |

## Дерево конфигурации

Открываем: **Конфигурация → Открыть конфигурацию**.

![[Pasted image 20260908151723.png]]

*Дерево конфигурации: ветка «Общие» и прикладные объекты — константы, справочники, документы, регистры и другие.*

Ветки дерева — это **виды объектов конфигурации**. Ветка **«Общие»** содержит то, что не относится к одному объекту: подсистемы, общие модули, роли, общие формы, подписки на события, регламентные задания.

Действия в дереве:
- **ПКМ → Добавить** (или `Insert`) — создать объект выбранного вида.
- Двойной щелчок — открыть окно редактирования объекта.
- Строка поиска над деревом (`Ctrl+Alt+M`) — быстро найти объект по имени.
- **Действия → По подсистемам** — показать только объекты выбранной подсистемы ([[15. Подсистемы, интерфейс и общие объекты]]).

## Палитра свойств

У любого объекта и у самого корня «Конфигурация» есть палитра свойств: **ПКМ → Свойства** или `Alt+Enter`.

![[Pasted image 20260908151953.png]]

*Свойства корня конфигурации: имя, синоним, основной режим запуска, модули приложения, сеанса и внешнего соединения, хранилища настроек.*

> [!tip] Настроим палитру один раз
> - У палитры два режима — **списком** и **закладками**. Переключаются через ПКМ по палитре. Закладки удобнее: свойства сгруппированы как на снимке выше.
> - Отключаем фильтр **«Показывать только важное»** кнопкой на панели палитры. Иначе часть свойств будет скрыта, и нужную настройку не найти.
>

## Другие окна, которые понадобятся

| Окно | Как открыть | Зачем |
| --- | --- | --- |
| Окно сообщений | Открывается само | Результаты проверки модулей, ошибки, `Сообщить()` при отладке |
| Синтакс-помощник | **Справка → Синтакс-помощник** или `Ctrl+F1` на слове в коде | Описание методов, параметров и их доступности |
| Окно редактирования объекта | Двойной щелчок по объекту | Вкладки «Основные», «Данные», «Формы», «Команды», «Макеты», «Прочее» |

Полный список горячих клавиш — в [[99. Шпаргалки/02. Горячие клавиши|шпаргалке]].

> [!question]- Проверь себя
> 1. В какой ветке дерева искать общие модули и роли?
> 2. Почему в палитре свойств «не хватает» настроек и как это исправить?
>
> > [!success]- Ответы
> > 1. В ветке «Общие».
> > 2. Включён фильтр «Показывать только важное» — его нужно отключить.
