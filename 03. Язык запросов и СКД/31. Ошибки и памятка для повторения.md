> [!abstract] Коротко
> Памятка раздела: таблица «симптом → что проверить», каркас запроса и пары понятий, которые важно различать. Используйте для повторения перед практикой и собеседованием.

## Если результат неправильный

| Симптом | Что проверить первым |
| --- | --- |
| Поле или таблица не найдены | Имя метаданных, псевдоним, структуру своей базы |
| Параметр не задан | Все `&Имена` и вызовы `УстановитьПараметр` |
| Не попал последний день | Время конца периода, включение границы |
| Сумма увеличилась после соединения | Сколько совпадений справа для каждой строки слева |
| После левого соединения пропали товары без продаж | Условия правой стороны в `ГДЕ` |
| Вместо нуля пустое значение | `NULL`, `ЕСТЬNULL`, наличие строки источника |
| В СКД ничего не выводится | Структуру, включение узлов и выбранные поля |
| Нет итогов | Ресурсы, выражения и «Рассчитывать по» |
| Старая настройка после изменения схемы | Вариант и сохранённые пользовательские настройки |
| Цена в итоге неверна | Отношение сумм вместо суммы/среднего готовых цен |
| Данные есть у администратора, но нет у пользователя | Роль и ограничения доступа |

## Каркас запроса

```text
ВЫБРАТЬ поля и выражения
ИЗ источники и соединения ПО условиям
ГДЕ условия исходных строк
СГРУППИРОВАТЬ ПО разрезы
ИМЕЮЩИЕ условия рассчитанных групп
УПОРЯДОЧИТЬ ПО порядок
ИТОГИ агрегаты ПО уровни
```

Это памятка, не готовый запрос. Необязательные части добавляем по задаче.

## Что важно различать?

| Пара | Отличие |
| --- | --- |
| `ГДЕ` / `ИМЕЮЩИЕ` | Отбор строк / отбор групп |
| `СГРУППИРОВАТЬ ПО` / `ИТОГИ` | Свернуть строки / добавить итоговые уровни |
| Соединение / объединение | Сопоставить строки и колонки / добавить строки |
| Пустая ссылка / NULL | Значение конкретного типа / отсутствие значения |
| Движения / обороты / остатки | Записи изменений / изменения за период / состояние на момент |
| Набор СКД / выбранные поля | Доступные данные / выводимые колонки |
| Ресурс СКД / группировка | Как считать показатель / по каким разрезам показывать |
| Схема / настройки | Возможности отчёта / выбранный способ формирования |

## Вопросы для самопроверки

1. Почему три строки накладной могут утроить итог её шапки?
2. Почему `РАЗЛИЧНЫЕ` не лечит неправильное соединение?
3. Чем отличаются условия по цене внутри среза и после него?
4. Почему нельзя суммировать остатки по дням?
5. Где задаётся конец дня: в коде запроса, в параметре или в выражении СКД?
6. Как проверить, что средняя цена в общем итоге верна?
