> [!abstract] Коротко
> `NULL` — «нет значения» в результате запроса (чаще всего при левом соединении). Проверяем `ЕСТЬ NULL` / `ЕСТЬ НЕ NULL` (не `= NULL`), заменяем `ЕСТЬNULL(Поле, 0)`. `NULL + 10 = NULL`. `NULL`, пустая ссылка, `0`, `""` и `Неопределено` — разные значения.

## Что означает NULL?

`NULL` означает отсутствие значения в результате операции с данными. Типичный случай: при левом соединении для товара не нашлось строки продаж.

| Значение | Пример |
| --- | --- |
| `0` | Число: сумма равна нулю |
| `""` | Пустая строка |
| Пустая ссылка | Значение ссылочного типа без выбранного объекта |
| `NULL` | Нет значения, например нет совпавшей строки |
| `Неопределено` | Отдельное значение встроенного языка; не синоним NULL |

## Проверка и замена

```1C
ГДЕ П.Номенклатура ЕСТЬ NULL
```

Так найдём товары без совпавшей строки в примере левого соединения. Для обратного условия: `П.Номенклатура ЕСТЬ НЕ NULL`. Не пишем `= NULL`.

```1C
ЕСТЬNULL(П.СуммаОборот, 0) КАК СуммаПродаж
```

Если сумма `NULL`, получим 0. Если она уже 0 или 500, значение сохранится. Значение замены выбираем совместимого типа.

У замены учитывается тип первого выражения: например, слишком длинная строка может усечься до его длины. [Пояснение 1С о ЕСТЬNULL](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Queries/Query_language/).

`ЕСТЬNULL()` не заменяет пустую ссылку и пустую строку. Их проверяем отдельными условиями.

## Почему пропала строка?

После левого соединения условие `П.СуммаОборот > 0` не истинно для `NULL`, поэтому строка без продаж не пройдёт `ГДЕ`.

При сложении `NULL + 10` тоже получается `NULL`. Если по задаче отсутствие суммы означает ноль, сначала заменяем её через `ЕСТЬNULL()`.

**Проверка:** для товара без продаж выводим рядом исходную сумму и `ЕСТЬNULL(Сумма, 0)`. Объясняем, почему значения различаются.

> [!question]- Проверь себя
> 1. Как найти товары, для которых не нашлось продаж?
> 2. Заменит ли `ЕСТЬNULL` пустую ссылку?
> 3. Почему нельзя писать `= NULL`?
>
> > [!success]- Ответы
> > 1. `ГДЕ П.Номенклатура ЕСТЬ NULL`.
> > 2. Нет, только `NULL`.
> > 3. Сравнение с NULL не даёт Истину; нужен оператор `ЕСТЬ NULL`.
