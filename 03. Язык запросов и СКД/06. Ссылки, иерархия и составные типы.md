> [!abstract] Коротко
> Через точку получаем реквизиты по ссылке (`Н.Покупатель.Наименование`) — платформа сама добавляет соединение. Пустая ссылка — `ЗНАЧЕНИЕ(Справочник.Контрагенты.ПустаяСсылка)`. `В ИЕРАРХИИ` выбирает элементы группы со всеми подгруппами. Для составного типа — `ССЫЛКА` (проверка типа) и `ВЫРАЗИТЬ` (приведение).

## Поле через точку

```1C
ВЫБРАТЬ
    Н.Покупатель КАК Покупатель,
    Н.Покупатель.Наименование КАК ИмяПокупателя
ИЗ Документ.РасходнаяНакладная КАК Н
```

Первое поле — ссылка; второе — строковый реквизит объекта по этой ссылке. Платформа сама организует получение связанных данных. Длинные цепочки через точку могут добавлять соединения и увеличивать стоимость запроса.

Ссылку сохраняем для связей, отбора и открытия объекта. `ПРЕДСТАВЛЕНИЕ(Н.Покупатель)` даёт текст для показа, но текст не заменяет идентификатор: у разных контрагентов могут совпадать названия.

## Пустая ссылка

```1C
ГДЕ Н.Покупатель = ЗНАЧЕНИЕ(Справочник.Контрагенты.ПустаяСсылка)
```

`Контрагенты` — имя справочника в учебной конфигурации; если оно отличается, подставляем своё. Пустая ссылка — значение конкретного ссылочного типа. Она отличается от `NULL`: [[09. NULL и отсутствующие значения]].

## Иерархический справочник

Для справочника с иерархией групп и элементов:

```1C
ГДЕ
    Н.Ссылка В ИЕРАРХИИ (&Группа)
    И НЕ Н.ЭтоГруппа
```

Получаем элементы выбранной группы и всех её подгрупп. `Н.Родитель = &Группа` выбирает только непосредственных детей.

В `&Группа` передаём выбранную непустую ссылку на группу. Если нужен весь справочник, убираем условие иерархии. [Пояснение 1С о пустой ссылке в В ИЕРАРХИИ](https://1c-dn.com/library/specifics_of_using__in_hierarchy__clause_in_query_language/).

## Составной тип

Поле `Регистратор` может ссылаться на разные документы. Ограничим тип:

```1C
ГДЕ П.Регистратор ССЫЛКА Документ.РасходнаяНакладная
```

Для обращения к реквизиту известного типа:

```1C
ВЫРАЗИТЬ(П.Регистратор КАК Документ.РасходнаяНакладная).Покупатель
```

`П` здесь — псевдоним таблицы регистра `Продажи`. Если значение другого типа, результат приведения будет `NULL`. Не применяем приведение без понимания допустимых типов поля.

> [!question]- Проверь себя
> 1. Чем `Родитель = &Группа` отличается от `Ссылка В ИЕРАРХИИ (&Группа)`?
> 2. Почему длинные цепочки через точку замедляют запрос?
> 3. Что вернёт `ВЫРАЗИТЬ(Регистратор КАК Документ.РасходнаяНакладная)` для заказа?
>
> > [!success]- Ответы
> > 1. Первое — только непосредственные дети, второе — все уровни вложенности.
> > 2. Каждое разыменование добавляет неявное соединение.
> > 3. `NULL`.
