> [!abstract] Коротко
> `СГРУППИРОВАТЬ ПО` сворачивает строки по полям-разрезам; остальные поля должны быть в агрегатных функциях: `СУММА`, `КОЛИЧЕСТВО`, `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ …)`, `МИНИМУМ`, `МАКСИМУМ`, `СРЕДНЕЕ`. `ГДЕ` фильтрует строки **до** группировки, `ИМЕЮЩИЕ` — группы **после**.

## Свернём строки

```1C
ВЫБРАТЬ
    П.Номенклатура,
    СУММА(П.Количество) КАК Количество,
    СУММА(П.Сумма) КАК Выручка
ИЗ
    РегистрНакопления.Продажи КАК П
ГДЕ
    П.Активность
    И П.Период >= &Начало
    И П.Период < &КонецИсключая
СГРУППИРОВАТЬ ПО
    П.Номенклатура
```

Получаем **одну строку на товар**. Для учебного разбора читаем движения напрямую; для обычного отчёта по оборотам предпочтительнее виртуальная таблица из [[16. Виртуальные таблицы регистров накопления]].

В выбранных полях должны остаться поля группировки и агрегатные выражения. Если добавим `Контрагент` обычным полем, его тоже нужно включить в группировку. Тогда строка означает уже **товар + контрагент**.

## Функции

| Функция | Результат |
| --- | --- |
| `СУММА(Поле)` | Сумма значений |
| `КОЛИЧЕСТВО(*)` | Число строк |
| `КОЛИЧЕСТВО(Поле)` | Число значений, кроме NULL |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Поле)` | Число разных значений, кроме NULL |
| `МИНИМУМ`, `МАКСИМУМ` | Наименьшее и наибольшее значение |
| `СРЕДНЕЕ` | Среднее арифметическое |

Количество строк не равно сумме проданных единиц: строка с количеством 10 считается одной строкой.

## ГДЕ и ИМЕЮЩИЕ

После группировки можно добавить:

```1C
ИМЕЮЩИЕ
    СУММА(П.Сумма) > &МинимальнаяВыручка
```

`ГДЕ` отбирает исходные строки. `ИМЕЮЩИЕ` отбирает уже рассчитанные группы. Условие на общую выручку товара задаём в `ИМЕЮЩИЕ`.

## В конструкторе

На вкладке **Группировка** поля разрезов переносим в верхний список, числовые показатели — в нижний и выбираем функцию.

![[06-Группировка-и-суммирование.jpg]]

*Показан промежуточный шаг: номенклатура уже в группировке, сумма — в агрегатах. Оставшиеся выбранные поля тоже нужно распределить или исключить из выбора.*

**Проверка:** две продажи одного товара на 100 и 200 дают одну строку на 300.

> [!question]- Проверь себя
> 1. Условие «выручка товара больше 400» — в `ГДЕ` или `ИМЕЮЩИЕ`?
> 2. Добавили в выбор поле `Контрагент` без агрегата. Что нужно сделать?
> 3. Равно ли `КОЛИЧЕСТВО(*)` сумме проданных штук?
>
> > [!success]- Ответы
> > 1. `ИМЕЮЩИЕ СУММА(Сумма) > 400`.
> > 2. Включить его в `СГРУППИРОВАТЬ ПО`; строка станет «товар + контрагент».
> > 3. Нет, это число строк.
