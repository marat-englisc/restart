> [!abstract] Коротко
> **Запрос** описывает, *какие данные получить* (а не как их обработать): поля, отбор, соединения, итоги. Источники — таблицы, которые платформа строит по объектам конфигурации: `Справочник.…`, `Документ.…`, `Документ.….ТабличнаяЧасть`, `РегистрНакопления.…` и **виртуальные таблицы** регистров. В запросе используются **имена** объектов, а не синонимы.

## Зачем нужен запрос?

**Запрос** получает данные из базы: выбирает нужные поля, отбирает строки, соединяет таблицы и считает суммы. Например: «покажи продажи за октябрь по каждому покупателю».

Встроенный язык управляет действиями программы. Язык запросов описывает, **какие данные получить**. В запросе нельзя написать `Для Каждого`, вызвать `Сообщить()` или записать документ. Изменяем объекты средствами встроенного языка.

## Откуда берутся таблицы?

Платформа предоставляет таблицы по структуре конфигурации. Используем **имена объектов**, а не их синонимы из пользовательского интерфейса.

| Источник | Что означает одна строка |
| --- | --- |
| `Справочник.Номенклатура` | Элемент или группа справочника |
| `Документ.РасходнаяНакладная` | Шапка одного документа |
| `Документ.РасходнаяНакладная.Товары` | Одна строка табличной части |
| `РегистрНакопления.Продажи` | Одна запись движения |
| `РегистрНакопления.Продажи.Обороты(...)` | Рассчитанный оборот по выбранным разрезам |

**Виртуальная таблица** рассчитывается платформой при обращении. Её не создаём и не заполняем отдельно. Состав виртуальных таблиц зависит от вида регистра.

![[03-Конструктор-таблицы-и-поля.jpg]]

*В открытой учебной базе у оборотного регистра доступны `Продажи` и `Продажи.Обороты`.*

## На чём будем учиться?

Продолжаем базу «1С:Купец» из первых разделов. Используем:

- `Номенклатура` — справочник товаров.
- `РасходнаяНакладная` — документ с `Покупатель`, `ИтоговаяСумма` и табличной частью `Товары`: `Товар`, `Количество`, `Цена`, `Сумма`.
- `Продажи` — **оборотный** регистр: измерения `Номенклатура`, `Контрагент`; ресурсы `Количество`, `Сумма`.

`ЦеныНоменклатуры` и регистр остатков потребуются только в отдельных примерах; их структуру укажем рядом. Для первых запросов достаточно справочника.

> [!question]- Проверь себя
> 1. Можно ли в запросе изменить документ?
> 2. Что означает одна строка `Документ.РасходнаяНакладная.Товары`?
> 3. Нужно ли заполнять виртуальную таблицу `Продажи.Обороты`?
>
> > [!success]- Ответы
> > 1. Нет, язык запросов только читает данные. Изменения — средствами встроенного языка.
> > 2. Одна строка табличной части «Товары» какого-то документа.
> > 3. Нет, её рассчитывает платформа при обращении.
