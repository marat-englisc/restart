> [!abstract] Коротко
> `ВЫБРАТЬ поля ИЗ источник КАК Псевдоним УПОРЯДОЧИТЬ ПО …`. `КАК` задаёт имена колонок и таблиц. Без `УПОРЯДОЧИТЬ ПО` порядок строк **не гарантирован**. `ПЕРВЫЕ N` — ограничить количество строк, `РАЗЛИЧНЫЕ` — убрать полные дубли выбранных полей.

## Основной каркас

```1C
ВЫБРАТЬ
    Н.Ссылка КАК Товар,
    Н.Наименование КАК Название
ИЗ
    Справочник.Номенклатура КАК Н
УПОРЯДОЧИТЬ ПО
    Название
```

`ВЫБРАТЬ` задаёт колонки, `ИЗ` — источник. `КАК Н` задаёт псевдоним таблицы. `КАК Название` задаёт псевдоним поля; именно это имя получим в выборке или таблице значений.

Псевдоним не переименовывает реквизит в конфигурации. После `Н.` пишем настоящее имя реквизита. Псевдонимы полей можно использовать в `УПОРЯДОЧИТЬ ПО`; в `ГДЕ` обычно повторяем исходное поле или выражение.

## Порядок строк

```1C
УПОРЯДОЧИТЬ ПО
    Название ВОЗР,
    Н.Код УБЫВ
```

Сначала сортируем по названию. При одинаковом названии — по коду в обратном порядке. Без `УПОРЯДОЧИТЬ ПО` порядок **не гарантирован**, даже если при нескольких запусках он совпал.

## ПЕРВЫЕ и РАЗЛИЧНЫЕ

```1C
ВЫБРАТЬ ПЕРВЫЕ 5
    Н.Ссылка,
    Н.Наименование
ИЗ Справочник.Номенклатура КАК Н
УПОРЯДОЧИТЬ ПО Н.Наименование, Н.Код, Н.Ссылка
```

Получаем первые пять строк после сортировки. Для воспроизводимого выбора добавляем поля, позволяющие различить строки с одинаковым названием.

`ВЫБРАТЬ РАЗЛИЧНЫЕ` убирает строки, у которых совпали **все выбранные значения**. Два разных товара с одинаковым названием станут одной строкой, если выбрано только название. Если выбрана ещё и ссылка, товары останутся разными.

`РАЗЛИЧНЫЕ` не исправляет ошибочное соединение таблиц. Сначала выясняем, почему появились повторения.

**Проверка:** выберем только `Наименование` с `РАЗЛИЧНЫЕ`, затем добавим `Ссылка`. Объясним, почему количество строк могло измениться.

> [!question]- Проверь себя
> 1. Гарантирован ли порядок строк без `УПОРЯДОЧИТЬ ПО`?
> 2. Чем опасен `РАЗЛИЧНЫЕ` при выборе только наименования?
> 3. Исправляет ли `РАЗЛИЧНЫЕ` ошибку соединения?
>
> > [!success]- Ответы
> > 1. Нет, даже если при тестах он совпадал.
> > 2. Разные товары с одинаковым названием сольются в одну строку.
> > 3. Нет, только маскирует. Нужно найти причину размножения строк.
