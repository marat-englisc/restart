> [!abstract] Коротко
> Шапка документа и его табличная часть — **разные таблицы**. В `Документ.….Товары` поле `Ссылка` — документ-владелец строки, через него доступны реквизиты шапки (`Т.Ссылка.Дата`). Главная ловушка: суммировать реквизит шапки по строкам — итог умножится на число строк.

## Шапка и строки — разные таблицы

В `Документ.РасходнаяНакладная` одна строка соответствует документу. В `Документ.РасходнаяНакладная.Товары` — одной товарной строке.

```1C
ВЫБРАТЬ
    Т.Ссылка КАК Накладная,
    Т.НомерСтроки,
    Т.Товар,
    Т.Количество,
    Т.Цена,
    Т.Сумма
ИЗ
    Документ.РасходнаяНакладная.Товары КАК Т
ГДЕ
    Т.Ссылка = &Накладная
УПОРЯДОЧИТЬ ПО
    Т.НомерСтроки
```

В `&Накладная` передаём ссылку на документ. Поле `Т.Ссылка` указывает на **документ-владелец строки**, а не на отдельный товар. `Т.Товар` указывает на номенклатуру.

## Как добавить поля шапки?

```1C
ВЫБРАТЬ
    Т.Ссылка.Дата КАК Дата,
    Т.Ссылка.Покупатель КАК Покупатель,
    Т.Товар,
    Т.Сумма
ИЗ Документ.РасходнаяНакладная.Товары КАК Т
ГДЕ Т.Ссылка.Проведен
```

При трёх строках товара дата и покупатель повторятся три раза. Это нормальная детализация результата.

**Ошибка:** выбрать `Т.Ссылка.ИтоговаяСумма`, затем просуммировать колонку. Итог шапки повторится по числу строк и окажется завышен. Для товарной суммы складываем `Т.Сумма`. Для общего итога документов читаем таблицу шапок.

## Через конструктор

1. Раскрываем **Документы → РасходнаяНакладная**.
2. Выбираем таблицу `РасходнаяНакладная.Товары`.
3. Переносим `Ссылка`, `НомерСтроки`, `Товар`, `Количество`, `Сумма`.
4. В **Условия** добавляем `Ссылка = &Накладная`.
5. В **Порядок** — `НомерСтроки`.

**Проверка:** документ с двумя товарами даёт две строки. Пустая табличная часть даёт 0 строк, даже если шапка документа существует.

> [!question]- Проверь себя
> 1. Что содержит поле `Ссылка` таблицы `Документ.РасходнаяНакладная.Товары`?
> 2. Почему `СУММА(Т.Ссылка.ИтоговаяСумма)` даёт завышенный результат?
> 3. Сколько строк вернёт запрос к табличной части документа без товаров?
>
> > [!success]- Ответы
> > 1. Ссылку на документ, которому принадлежит строка.
> > 2. Сумма шапки повторяется в каждой строке товаров.
> > 3. Ноль.
