> [!abstract] Коротко
> **СКД** строит отчёт по **схеме** (наборы данных, ресурсы, параметры) и **настройкам** (структура, поля, отборы, оформление). Схема → компоновщик макета → процессор компоновки → вывод в табличный документ. Простой отчёт делается без кода.

## От строк к отчёту

**Система компоновки данных (СКД)** получает данные, применяет настройки и формирует отчёт: группировки, итоги, таблицы и диаграммы. Простой отчёт можно создать без программного кода.

| Часть | На какой вопрос отвечает |
| --- | --- |
| Схема компоновки данных | Откуда брать данные и какие возможности предоставить? |
| Набор данных | Какие строки и поля получаем из источника? |
| Ресурсы | Какие показатели и по каким формулам считать в итогах? |
| Настройки | Что выводить, как группировать, отбирать и оформлять? |
| Макет компоновки | Как выполнить конкретную схему с конкретными настройками? |
| Результат | Что пользователь увидит после формирования? |

Не путаем **систему** и **схему**: система — механизм платформы, схема — описание нашего отчёта. [Устройство СКД в документации 1С](https://v8.1c.ru/platforma/sistema-komponovki-dannykh/).

## Где открывать?

В Конфигураторе: **Отчёты → нужный отчёт → Основные → Открыть схему компоновки данных**.

![[01-Отчёт-и-основная-схема.jpg]]

*В базе уже есть `ОтчетПоПродажам`. Для новой практики создадим отдельный `ПродажиЗаПериодУчебный`.*

## Порядок работы

1. **Наборы данных:** создаём запрос и получаем поля.
2. **Ресурсы:** задаём итоговые показатели.
3. **Параметры:** описываем период и другие входные значения.
4. **Настройки:** выбираем поля и строим структуру.
5. В режиме пользователя задаём период и нажимаем **Сформировать**.

Само наличие запроса ещё не делает отчёт готовым: без структуры и выбранных полей данные могут не выводиться. Названия полей запроса, их заголовки и состав показанных колонок настраиваются отдельно.

> [!question]- Проверь себя
> 1. Чем схема отличается от настроек?
> 2. Почему отчёт с готовым запросом может ничего не выводить?
> 3. Нужно ли программировать для простого отчёта по регистру?
>
> > [!success]- Ответы
> > 1. Схема описывает доступные данные и возможности, настройки — конкретный способ их вывести.
> > 2. Не задана структура и выбранные поля в настройках.
> > 3. Нет, достаточно схемы и настроек.
