> [!abstract] Коротко
> `ПОМЕСТИТЬ ВТ_Имя` сохраняет результат во **временную таблицу**, `;` разделяет запросы **пакета**, следующие части видят ВТ предыдущих. `Выполнить()` возвращает результат последнего запроса, `ВыполнитьПакет()` — массив результатов. Между разными объектами `Запрос` ВТ передаются через `МенеджерВременныхТаблиц`.

## Разобьём расчёт на шаги

Временная таблица хранит промежуточный результат запроса. Это не новый объект конфигурации.

```1C
ВЫБРАТЬ
    П.Номенклатура КАК Номенклатура,
    СУММА(П.СуммаОборот) КАК Выручка
ПОМЕСТИТЬ ВТПродажи
ИЗ
    РегистрНакопления.Продажи.Обороты(
        &Начало, &Конец, , ) КАК П
СГРУППИРОВАТЬ ПО
    П.Номенклатура
ИНДЕКСИРОВАТЬ ПО
    Номенклатура
;

ВЫБРАТЬ
    ВТ.Номенклатура,
    ВТ.Выручка
ИЗ
    ВТПродажи КАК ВТ
ГДЕ
    ВТ.Выручка > &МинимальнаяВыручка
```

`ПОМЕСТИТЬ` создаёт временную таблицу. `;` разделяет части пакета. Платформа выполняет их последовательно, поэтому вторая часть видит результат первой.

![[23-Пакет-запросов.png]]

*Этот же пакет в конструкторе запроса: вкладка «Пакет запросов» с частями `ВТПродажи` и «Запрос пакета 2».*

![[24-Временная-таблица-в-конструкторе.png]]

*Первая часть пакета, вкладка «Дополнительно»: тип запроса «Создание временной таблицы», имя `ВТПродажи`. Справа вертикальные закладки для переключения между частями.*

`ИНДЕКСИРОВАТЬ ПО` создаёт индекс промежуточной таблицы. Он полезен при дальнейшем отборе или соединении по этому полю; на маленькой таблице создание индекса может стоить дороже выигрыша. В показанной второй части индекс по номенклатуре не используется — он подготовлен для возможного соединения.

## Выполнение пакета

В серверном коде помещаем весь пакет в `Запрос.Текст`, задаём параметры и вызываем:

```1C
Результат = Запрос.Выполнить();
```

Получаем результат последнего запроса. Если нужны результаты всех частей, используем `ВыполнитьПакет()`: он возвращает массив результатов в порядке частей пакета.

## Несколько объектов Запрос

Чтобы временная таблица была доступна между отдельными запросами, используем общий менеджер:

```1C
МенеджерВТ = Новый МенеджерВременныхТаблиц;
Первый = Новый Запрос;
Первый.МенеджерВременныхТаблиц = МенеджерВТ;
Второй = Новый Запрос;
Второй.МенеджерВременныхТаблиц = МенеджерВТ;
// Задаём тексты и параметры. Первый создаёт ВТ, второй читает её.
```

Это каркас: перед выполнением нужно заполнить оба текста. Менеджер определяет общую область временных таблиц и их время жизни; после завершения работы его можно закрыть методом `Закрыть()`.

> [!question]- Проверь себя
> 1. Что вернёт `Запрос.Выполнить()` для пакета из трёх запросов?
> 2. Является ли временная таблица объектом конфигурации?
> 3. Когда нужен `ИНДЕКСИРОВАТЬ ПО`?
>
> > [!success]- Ответы
> > 1. Результат последнего.
> > 2. Нет, она существует только во время работы запроса/менеджера ВТ.
> > 3. Когда по полю ВТ дальше выполняется соединение или отбор на больших данных.
