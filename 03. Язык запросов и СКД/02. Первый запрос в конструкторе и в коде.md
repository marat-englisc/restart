> [!abstract] Коротко
> Запрос можно собрать в **конструкторе** (таблицы → поля → порядок) или написать текстом. В коде: `Запрос = Новый Запрос; Запрос.Текст = "…"; Результат = Запрос.Выполнить();` → `Выгрузить()` (таблица значений) или `Выбрать()` (выборка). Запросы выполняем **на сервере**; символ `|` — продолжение строки встроенного языка, а не часть запроса.

## Соберём запрос визуально

Для просмотра конструктора используем отчёт. В Конфигураторе открываем **Отчёты → ОтчетПоПродажам → Открыть схему компоновки данных**. Если отчёта ещё нет, сначала выполняем [[20. Создание отчёта и набора данных]].

1. На вкладке **Наборы данных** выбираем набор типа **Запрос**.
2. Нажимаем **Конструктор запроса**.
3. Слева раскрываем **Справочники**. Двойным щелчком по `Номенклатура` переносим её в список **Таблицы**.
4. Раскрываем выбранную таблицу. Переносим поля `Ссылка`, `Код`, `Наименование` в правый список **Поля**.
5. На вкладке **Порядок** добавляем `Наименование`, направление — по возрастанию.
6. Нажимаем **ОК**. В наборе появится текст запроса.

![[03-Конструктор-таблицы-и-поля.jpg]]

*На снимке показан тот же конструктор с таблицей продаж: слева источники, в центре выбранные таблицы, справа поля результата.*

Конструктор **строит текст**, но сам по себе не показывает результат выполнения. Запрос набора выполняется при формировании настроенного отчёта. Для отдельного запуска можно использовать код ниже; специальная консоль запросов для этого не обязательна.

## Выполним в коде

Создаём неглобальный общий модуль `УчебныеЗапросыСервер`, включаем свойство **Сервер** и помещаем функцию:

```1C
Функция ПолучитьНоменклатуру() Экспорт
    Запрос = Новый Запрос;
    Запрос.Текст =
    "ВЫБРАТЬ
    |    Н.Ссылка КАК Товар,
    |    Н.Код КАК Код,
    |    Н.Наименование КАК Наименование
    |ИЗ
    |    Справочник.Номенклатура КАК Н
    |УПОРЯДОЧИТЬ ПО
    |    Наименование";

    Возврат Запрос.Выполнить().Выгрузить();
КонецФункции
```

## Запуск с кнопки

Если учебной обработки ещё нет:

1. **Обработки → Добавить**, имя `УчебныеЗапросы`.
2. **Формы → Добавить**, создаём основную управляемую форму обработки.
3. В редакторе формы на вкладке **Команды** создаём `ПоказатьНоменклатуру`.
4. У команды в свойстве **Действие** создаём клиентский обработчик. Перетаскиваем команду в дерево **Элементы**, чтобы появилась кнопка.
5. В модуле формы размещаем обработчик и серверную процедуру:

```1C
&НаКлиенте
Процедура ПоказатьНоменклатуру(Команда)
    ПоказатьНоменклатуруНаСервере();
КонецПроцедуры

&НаСервереБезКонтекста
Процедура ПоказатьНоменклатуруНаСервере()
    Данные = УчебныеЗапросыСервер.ПолучитьНоменклатуру();
    Сообщить("Строк: " + Данные.Количество());
    Для Каждого Строка Из Данные Цикл
        Сообщить(Строка.Код + " — " + Строка.Наименование);
    КонецЦикла;
КонецПроцедуры
```

6. Сохраняем конфигурацию, обновляем конфигурацию БД и запускаем 1С:Предприятие. Под административной ролью открываем **Сервис и настройки → Функции для технического специалиста → Обработки → Учебные запросы**, нажимаем кнопку.

Внутри функции получаем таблицу значений с тремя колонками; на форме выводятся сообщения с количеством строк и названиями. Если справочник пустой, строк будет 0 — это нормальный результат. Свойство `Код` в этом примере имеет строковый тип, как в учебной базе.

Вертикальная черта `|` продолжает **строку встроенного языка**. В чистый текст запроса в СКД её не копируем. `Н` — короткое имя таблицы, `КАК Товар` — имя колонки результата.

> [!question]- Проверь себя
> 1. Где выполняется `Запрос.Выполнить()` в управляемом приложении?
> 2. Чем `Выгрузить()` отличается от `Выбрать()`?
> 3. Почему при копировании текста в СКД нужно убрать `|`?
>
> > [!success]- Ответы
> > 1. Только на сервере.
> > 2. `Выгрузить` возвращает всю таблицу значений в память, `Выбрать` — выборку для последовательного обхода.
> > 3. Это синтаксис многострочной строки встроенного языка, а не языка запросов.
