> [!abstract] О шпаргалке
> Сочетания клавиш Конфигуратора и 1С:Предприятия, которые используются в курсе. Актуальный список — в меню соответствующей версии платформы.

## Конфигуратор: общее

| Клавиши | Действие |
| --- | --- |
| `Ctrl+S` | Сохранить основную конфигурацию |
| `F7` | Обновить конфигурацию базы данных |
| `F5` | Начать отладку (запустить Предприятие с отладчиком) |
| `Ctrl+F5` | Запустить Предприятие без отладки |
| `Alt+Enter` | Палитра свойств выбранного объекта |
| `Ctrl+Alt+M` | Поиск в дереве конфигурации |
| `Ctrl+Shift+F` | Глобальный поиск по модулям |
| `F9` (в дереве) | Скопировать объект |
| `Insert` | Добавить объект |
| `Ctrl+Shift+Up / Down` | Переместить объект вверх/вниз |
| `Alt+Shift+F2` | Добавить объект в расширение |
| `Ctrl+F1` | Синтакс-помощник для слова под курсором |

## Редактор модулей

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Пробел` | Контекстная подсказка, автодополнение |
| `Ctrl+Shift+Пробел` | Подсказка по параметрам метода |
| `Ctrl+Q` | Шаблоны кода (Если, Для, Пока…) |
| `Ctrl+Alt+P` | Список процедур и функций модуля |
| `F12` | Перейти к определению метода |
| `Ctrl+F7` | Синтаксическая проверка модуля |
| `Shift+Alt+F` | Форматирование отступов |
| `Ctrl+/` / `Ctrl+Shift+/` | Закомментировать / раскомментировать строки |
| `Ctrl+F`, `F3` | Найти, найти следующее |
| `Ctrl+H` | Заменить |
| `Ctrl+G` | Перейти к строке |

## Отладка

| Клавиши | Действие |
| --- | --- |
| `F9` | Поставить / снять точку останова |
| `F10` | Шаг без захода в метод |
| `F11` | Шаг с заходом в метод |
| `Shift+F11` | Выйти из текущего метода |
| `F5` | Продолжить выполнение |
| `Shift+F9` | Вычислить выражение |

Список точек останова, условная точка останова, табло, стек вызовов — в меню **Отладка** (сочетания отличаются по версиям).

## 1С:Предприятие

| Клавиши | Действие |
| --- | --- |
| `Insert` | Создать |
| `F9` | Скопировать |
| `F2` | Изменить (открыть) |
| `Delete` | Пометить на удаление / снять пометку |
| `Shift+Delete` | Удалить непосредственно (если есть право) |
| `Ctrl+F` / `Alt+F` | Быстрый / расширенный поиск в списке |
| `Ctrl+Q` | Отменить поиск |
| `Ctrl+Enter` | Записать и закрыть |
| `Ctrl+S` | Записать |
| `Ctrl+Shift+F` | Поиск по всей программе |
| `Ctrl+F11` / `Shift+F11` | Получить / перейти по ссылке |
