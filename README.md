# re:start — GitHub Pages

Built website and complete 1C course content, ready for GitHub Pages.

- Website: https://marat-englisc.github.io/restart/
- Source: https://github.com/marat-englisc/restart/tree/main/site
- Publishing source: `gh-pages`, directory `/`
- Base path: `/restart`
- Content: 140 notes and 278 illustrations / downloadable examples

This branch contains the static export. Edit the source project to make changes.
From its `site` directory, run `npm run build:pages` and `npm test`, then publish the contents of `out/` at this branch's root, including `.nojekyll`.
