# re:1c

Сайт для конспекта по 1С:Предприятию на основе [refront](https://github.com/marat-englisc/refront).
Сохранены монохромный интерфейс, навигация, чтение и прогресс. Система FSRS и карточки удалены.

## Запуск

Нужен Node.js 22.18 или новее.

```powershell
cd "C:\Users\Marat\Desktop\1C\site"
npm install
npm run dev
```

Откройте http://127.0.0.1:3000/. Зависимости уже установлены в текущем проекте.
В Windows также можно открыть `start.cmd`. Для остановки нажмите Ctrl+C в терминале.

## Возможности

- Все 145 заметок: пять учебных разделов, шпаргалки и оглавление.
- Дерево разделов, оглавление статьи, переходы между уроками и полоса чтения.
- Поиск по названиям и полному тексту, включая код: Ctrl+K или /.
- Ссылки и изображения Obsidian, таблицы, сворачиваемые вопросы и ответы.
- Схемы Mermaid, подсветка 1С/BSL, копирование кода.
- Иллюстрации и скачивание учебных примеров .epf и .bsl.
- Светлая, тёмная и системная темы; мобильная навигация.
- Жёлто-оранжевые акценты, подсветка карточек под курсором и плавные переходы.
- Фон Magic UI Animated Grid Pattern с орбитами, свечением и лучами; кнопка паузы внизу главного экрана.
- Отметки изученных уроков и разделов, продолжение чтения, статистика и календарь.
- Экспорт и импорт прогресса в JSON через «Настройки».

Данные сохраняются в localStorage под ключом `re-1c:progress:v1` и синхронизируются между вкладками.
Импорт заменяет прогресс данными резервной копии. Файлы другого приложения и повреждённые данные отклоняются.

## Материалы

Markdown читается из родительской папки. Исходный конспект сайт не изменяет.
Редактируйте заметки в привычных папках; для обновления открытой страницы перезагрузите её.
После добавления изображений или файлов перезапустите `npm run dev`.
Встроенные шрифты системы используются без запросов к Google Fonts.

При запуске и сборке `scripts/sync-assets.mjs` копирует изображения и примеры в `public/vault/`.
Эта папка генерируется автоматически и не хранится в Git.

ID прогресса зависит от пути заметки без числовых префиксов: перенумерация сохраняет отметки, переименование меняет ID.
Альтернативный корень материалов можно задать переменной окружения `CONTENT_DIR` до запуска команд.

## Сборка и проверка

```powershell
npm run build
npm run typecheck
npm test
npm run preview
```

Готовый статический сайт находится в `out/`. Сервер предпросмотра доступен по http://127.0.0.1:3000/.
Команда `npm start` также запускает предпросмотр готовой сборки.
Тесты выполняются после сборки: проверяют наличие всех заметок, ссылки, изображения, форматирование и резервные копии.

Для размещения на статическом хостинге загрузите содержимое `out/`.
Если сайт будет жить в подпапке, задайте путь до сборки:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = "/имя-репозитория"
npm run build
npm run preview
```

При изменении конспекта выполните сборку повторно.

## Устройство

Next.js 16 со статическим экспортом, React, TypeScript, Redux Toolkit, Tailwind CSS, shadcn/ui,
unified/remark/rehype, Shiki и Mermaid. Бэкенд и регистрация не нужны.

Анимации используют Motion и адаптированный компонент [Magic UI Animated Grid Pattern](https://magicui.design/docs/components/animated-grid-pattern).
Его лицензия сохранена в `src/components/magicui/LICENSE.md`. Фон останавливается вне экрана и в скрытой вкладке.
Системная настройка «Уменьшение движения» отключает декоративное движение и круговой переход темы.
Наклон карточек и реакция на курсор работают только для мыши.

- `src/lib/content.ts` — дерево материалов и поисковый индекс.
- `src/lib/obsidian.ts` — ссылки и вложения Obsidian.
- `src/lib/markdown.ts` — преобразование Markdown в HTML.
- `src/store/` и `src/lib/progress-data.ts` — прогресс и проверка резервных копий.
- `scripts/preview.mjs` — локальный сервер готовой сборки без дополнительных зависимостей.
- `tests/` — проверки контента и данных.

Код адаптирован из refront; исходная [лицензия MIT](LICENSE) сохранена.
