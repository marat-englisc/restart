> [!abstract] Коротко
> Три сущности: **менеджер** (`Справочники.Номенклатура` — создать, найти, выбрать), **ссылка** (указатель, только чтение), **объект** (`ПолучитьОбъект()`/`СоздатьЭлемент()` — изменить и `Записать()`). Поиск: `НайтиПоКоду`, `НайтиПоНаименованию`, `НайтиПоРеквизиту` возвращают ссылку или **пустую ссылку**. Весь код — на сервере.

## Менеджер, ссылка и объект

При работе со справочником важно различать три вещи:

| Значение | Для чего используем |
| --- | --- |
| `Справочники.Номенклатура` | Менеджер: создать элемент, найти ссылку, получить выборку |
| `СправочникСсылка.Номенклатура` | Указать на конкретный элемент базы |
| `СправочникОбъект.Номенклатура` | Читать и изменять данные элемента, записывать их |

Все примеры этой заметки выполняем **на сервере**. Предполагается, что справочник `Номенклатура` уже существует.

## Создание элемента

```1C
НовыйТовар = Справочники.Номенклатура.СоздатьЭлемент();
НовыйТовар.Наименование = "Телефон";
НовыйТовар.Записать();

СсылкаНаТовар = НовыйТовар.Ссылка;
```

До `Записать()` мы работаем с новым объектом в памяти. После успешной записи он существует в базе, и на него можно ссылаться из других объектов.

Если у справочника есть обязательные дополнительные реквизиты, их тоже нужно заполнить. При включённой автонумерации код обычно выдаёт платформа.

> [!warning] Важно
> Повторный запуск этого примера создаст ещё один товар. Одинаковое наименование не означает одинаковую ссылку. Для загрузки данных отдельно определяем правило поиска уже существующего объекта.

## Поиск

```1C
Товар = Справочники.Номенклатура.НайтиПоКоду("000000001");

Если Товар.Пустая() Тогда
	Сообщить("Товар не найден");
Иначе
	Сообщить(Товар.Наименование);
КонецЕсли;
```

Менеджер возвращает ссылку. Если подходящего элемента нет, ссылка будет пустой, а не `Неопределено`.

Также есть `НайтиПоНаименованию()` и `НайтиПоРеквизиту()`. Наименование не обязательно уникально, поэтому для однозначного сопоставления нужен подходящий ключ по условиям задачи.

## Изменение объекта

Ссылку нельзя использовать как редактируемый объект. Получаем объект и записываем изменение:
```1C
Если НЕ Товар.Пустая() Тогда
	ОбъектТовара = Товар.ПолучитьОбъект();
	ОбъектТовара.Наименование = "Смартфон";
	ОбъектТовара.Записать();
КонецЕсли;
```

Другие ссылки на этот товар сохраняются. Меняется его наименование, а не идентичность объекта.

Если данные могли изменить другие пользователи, нужно учитывать конкурентную запись и при необходимости повторно читать объект. Подробнее - [[28. Транзакции и блокировки]].

## Выборка

Для последовательного обхода элементов без языка запросов:
```1C
Выборка = Справочники.Номенклатура.Выбрать();

Пока Выборка.Следующий() Цикл
	Сообщить(Выборка.Наименование);
КонецЦикла;
```

`Следующий()` перемещает выборку и возвращает Булево. До первого успешного вызова текущий элемент ещё не выбран. Для больших массовых обработок отдельно оценивают объём чтения.

## Группы и владелец

В иерархическом справочнике для группы используем `СоздатьГруппу()`, для элемента - `СоздатьЭлемент()`. У элемента можно заполнить `Родитель` ссылкой на группу.

Для подчинённого справочника заполняем `Владелец`. Обычный ссылочный реквизит с похожим названием не становится владельцем автоматически.

## Пометка удаления

Для установленной ссылки можно получить объект и вызвать `УстановитьПометкуУдаления(Истина)`. Это помечает объект, а не выполняет окончательное удаление с проверкой ссылок.

Запись из кода вызывает события объекта. Поэтому правила, которые должны действовать и при работе через форму, и при загрузках, размещаем в модуле объекта или соответствующих подписках.

> [!question]- Проверь себя
> 1. Что вернёт `НайтиПоКоду`, если элемента нет?
> 2. Как переименовать товар по ссылке?
> 3. Почему повторный запуск кода `СоздатьЭлемент()…Записать()` создаёт дубли?
>
> > [!success]- Ответы
> > 1. Пустую ссылку (проверяем `.Пустая()`), а не `Неопределено`.
> > 2. `Объект = Ссылка.ПолучитьОбъект(); Объект.Наименование = "…"; Объект.Записать();`
> > 3. Каждый вызов создаёт новый объект; правило поиска существующего нужно писать отдельно.
