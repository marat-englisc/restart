> [!abstract] Коротко
> Три цикла: `Для Сч = 1 По N Цикл` (счётчик), `Для Каждого Эл Из Коллекция Цикл` (обход коллекции), `Пока Условие Цикл` (пока истинно). `Прервать` выходит из цикла, `Продолжить` переходит к следующей итерации. В `Пока` обязательно меняем то, от чего зависит условие.

## Определение

Иногда нужно обработать некоторый ограниченный набор данных, например пройтись по массиву, или выполнить алгоритм фиксированное количество раз. Для этого есть синтаксические конструкции: `Для` и `Для Каждого`.

Начнём с простого блока цикла `Для`:
```1C
Для НомерТалона = 1 По 3 Цикл

	Сообщить(НомерТалона);	

КонецЦикла;
```

В данном цикле мы задаём стартовую позицию (НомерТалона который равен 1) и конечную позицию (Где НомерТалона будет равен 3, каждую итерацию увеличиваясь на 1). 

## Пока

Иногда алгоритм нужно выполнять до тех пор, пока выполняется определённое условие. Для описания такого действия используется цикл с условием `Пока`:
```1C
ОстатокКонфет = 5;

Пока ОстатокКонфет <> 0 Цикл

	Сообщить(ОстатокКонфет);
	ОстатокКонфет = ОстатокКонфет - 1;
	
КонецЦикла;
```

## Для Каждого

Чтобы последовательно обработать элементы коллекции, используем `Для Каждого`:
```1C
Товары = Новый Массив;
Товары.Добавить("Телефон");
Товары.Добавить("Ноутбук");

Для Каждого Товар Из Товары Цикл
	Сообщить(Товар);
КонецЦикла;
```

Переменная `Товар` на каждой итерации содержит очередное значение. Таким же образом можно обходить табличную часть документа.

## Прервать и Продолжить

`Прервать` заканчивает ближайший цикл целиком. `Продолжить` пропускает остаток текущей итерации и переходит к следующей:
```1C
Для Номер = 1 По 10 Цикл

	Если Номер = 3 Тогда
		Продолжить;
	КонецЕсли;

	Если Номер = 6 Тогда
		Прервать;
	КонецЕсли;

	Сообщить(Номер);

КонецЦикла;
```

Результат: 1, 2, 4, 5. Тройку пропустили, а на шестёрке закончили цикл.

> [!warning] Важно
> В цикле `Пока` должно изменяться значение, от которого зависит условие выхода. Иначе мы можем получить бесконечный цикл. При удалении элементов коллекции во время обхода нужно отдельно продумать индексы: следующий элемент может сдвинуться и остаться необработанным.

> [!question]- Проверь себя
> 1. Какой цикл удобнее для обхода табличной части?
> 2. Чем `Прервать` отличается от `Продолжить`?
> 3. Почему опасно удалять элементы массива в цикле с возрастающим индексом?
>
> > [!success]- Ответы
> > 1. `Для Каждого Строка Из Товары Цикл`.
> > 2. `Прервать` завершает весь цикл, `Продолжить` — только текущую итерацию.
> > 3. Элементы сдвигаются, и следующий окажется пропущен. Удаляем, обходя с конца: `Инд = Массив.ВГраница(); Пока Инд >= 0 Цикл … Инд = Инд - 1; КонецЦикла;`.
