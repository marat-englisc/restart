> [!abstract] Коротко
> В модуле объекта документа живут правила, которые должны работать при любом способе записи: пересчёт сумм в `ПередЗаписью`, проверки в `ОбработкаПроверкиЗаполнения`, движения в `ОбработкаПроведения`. Итог колонки табличной части — `Товары.Итог("Сумма")`. В обработчиках записи нельзя вызывать `Записать()` повторно.

## Основы

Точно так-же, как мы работали с модулями справочника, мы можем работать с модулями документа. Для этого нам нужно зайти на вкладку "Прочее":

![[Pasted image 20260915202735.png]]

*Вкладка «Прочее» документа `ЗаказКлиента`: модуль объекта и модуль менеджера.*

Добавим функцию подсчёта итоговой суммы по документу, для описания логики нам нужен модуль объекта с вот таким кодом:
```1C
#Область ОбработчикиСобытий

Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	
	Для Каждого СтрокаТовара Из ЭтотОбъект.Товары Цикл
		СтрокаТовара.Сумма = Окр(СтрокаТовара.Количество * СтрокаТовара.Цена, 2);
	КонецЦикла;
	ЭтотОбъект.ИтоговаяСумма = ЭтотОбъект.Товары.Итог("Сумма") + ЭтотОбъект.Услуги.Итог("Сумма");
	
КонецПроцедуры
	
#КонецОбласти
```

Перед этим мы создали новый реквизит `ИтоговаяСумма`. В данном коде мы, обращаясь к таблицам, использовали метод `Итог("")`. Его суть - находить сумму по всем значениям переданного столбца.

Теперь при записи документа поле `ИтоговаяСумма` будет автоматически заполняться. Для товаров мы сначала пересчитываем суммы строк, чтобы изменение через код тоже учитывалось. В этом примере сумма услуги вводится напрямую: если у услуг есть количество и цена, для них нужен аналогичный пересчёт.

## Основные события

- `ОбработкаЗаполнения` - заполнение нового объекта, в том числе на основании другого.
- `ОбработкаПроверкиЗаполнения` - проверка при вызове механизма проверки заполнения.
- `ПередЗаписью` - действия перед записью документа, в том числе программной.
- `ПриЗаписи` - действия в процессе записи объекта.
- `ОбработкаПроведения` - формирование движений при проведении.
- `ОбработкаУдаленияПроведения` - дополнительные действия при отмене проведения.

У разных событий разные параметры и момент вызова. Сигнатуру создаём средствами Конфигуратора. В обработчике записи не вызываем `ЭтотОбъект.Записать()` повторно: это может привести к рекурсивной записи.

## Модуль менеджера

В модуль менеджера можно вынести экспортную функцию, которая относится к документу как виду: например, формирование его печатной формы по ссылке. Из серверного кода она вызывается как `Документы.РасходнаяНакладная.ИмяФункции(...)`.

У менеджера нет данных конкретной накладной, пока мы явно не передали ссылку или не получили объект. Это отличается от модуля объекта, где реквизиты текущего документа доступны напрямую.

> [!question]- Проверь себя
> 1. В каком событии формировать движения регистров?
> 2. Почему в `ПередЗаписью` нельзя вызывать `ЭтотОбъект.Записать()`?
> 3. Как получить сумму колонки `Сумма` табличной части `Товары`?
>
> > [!success]- Ответы
> > 1. `ОбработкаПроведения`.
> > 2. Это снова вызовет `ПередЗаписью` — рекурсия.
> > 3. `Товары.Итог("Сумма")`.
