> [!abstract] Коротко
> Строка — неизменяемое значение в двойных кавычках. Склейка — оператором `+`, подстановка значений — `СтрШаблон("%1 шт.", 5)`. Многострочный текст пишем с `|` в начале строк продолжения, кавычку внутри строки — удваиваем. Главные функции: `СтрДлина`, `Лев/Прав/Сред`, `СокрЛП`, `СтрНайти`, `СтрЗаменить`, `СтрРазделить/СтрСоединить`, `ВРег/НРег`.

## Литералы строк

```1C
Имя = "Марат";
Пустая = "";
Кавычки = "ООО ""Ромашка""";          // внутри строки кавычка удваивается → ООО "Ромашка"

ТекстЗапроса = "ВЫБРАТЬ
               |    Н.Наименование
               |ИЗ
               |    Справочник.Номенклатура КАК Н";  // многострочная строка: | в начале продолжения

ДвеСтроки = "Первая" + Символы.ПС + "Вторая"; // перевод строки
```

`Символы` — набор спецсимволов: `ПС` (перевод строки), `Таб` (табуляция), `НПП` (неразрывный пробел).

## Склейка и шаблон

Строка неизменяема: любая операция возвращает **новую** строку.

```1C
ИмяЧеловека = "Марат";
Текст1 = "Привет, " + ИмяЧеловека + "!";            // конкатенация
Текст2 = СтрШаблон("Привет, %1!", ИмяЧеловека);      // шаблон
Текст3 = СтрШаблон("%1: %2 шт. по %3", "Чайник", 2, 1500); // числа преобразуются сами
```

`%1`, `%2` … — места подстановки параметров по порядку (до 10). Шаблон читается лучше, чем длинная цепочка `+`, и упрощает перевод интерфейса.

> [!tip] Число в строке
> При `"Сумма: " + 1500` число преобразуется в строку по правилам представления: может появиться неразрывный пробел-разделитель тысяч (`1 500`). Для управляемого вида используем `Формат(1500, "ЧГ=0")` ([[05. Работа с числами]]).

## Главные функции

| Функция | Что делает | Пример → результат |
| --- | --- | --- |
| `СтрДлина(С)` | Длина строки | `СтрДлина("Кот")` → `3` |
| `ПустаяСтрока(С)` | Пустая или только пробелы | `ПустаяСтрока("  ")` → `Истина` |
| `Лев(С, N)` | N символов слева | `Лев("Собака", 2)` → `"Со"` |
| `Прав(С, N)` | N символов справа | `Прав("Кошка", 3)` → `"шка"` |
| `Сред(С, Нач, N)` | N символов с позиции Нач (нумерация с 1) | `Сред("Привет", 2, 3)` → `"рив"` |
| `СокрЛ / СокрП / СокрЛП` | Убрать пробелы слева / справа / с обеих сторон | `СокрЛП("  кот ")` → `"кот"` |
| `ВРег / НРег / ТРег` | ВЕРХНИЙ / нижний / Каждое Слово С Заглавной | `ТРег("большой кот")` → `"Большой Кот"` |
| `СтрНайти(С, Подстрока)` | Позиция первого вхождения или 0 | `СтрНайти("Кот Собака", "Собака")` → `5` |
| `СтрЧислоВхождений(С, П)` | Сколько раз встречается | `СтрЧислоВхождений("а-б-в", "-")` → `2` |
| `СтрЗаменить(С, Что, НаЧто)` | Заменить **все** вхождения | `СтрЗаменить("ООО Кот", "ООО ", "")` → `"Кот"` |
| `СтрНачинаетсяС / СтрЗаканчиваетсяНа` | Проверка начала / конца | `СтрНачинаетсяС("1234", "12")` → `Истина` |
| `СтрРазделить(С, Разд)` | Разбить в **массив** | `СтрРазделить("а;б;в", ";")` → `["а","б","в"]` |
| `СтрСоединить(Массив, Разд)` | Собрать массив в строку | `СтрСоединить(Части, ", ")` → `"а, б, в"` |
| `СтрШаблон(Ш, …)` | Подставить значения | см. выше |
| `СтрСравнить(С1, С2)` | Сравнение без учёта регистра: −1, 0, 1 | `СтрСравнить("кот", "КОТ")` → `0` |
| `Строка(Знач)` | Привести к строке | `Строка(15)` → `"15"` |

У `СтрНайти` есть дополнительные параметры: направление (`НаправлениеПоиска.СКонца`), начальная позиция и номер вхождения.

## Типовые задачи

```1C
// Нормализовать ввод пользователя перед поиском
Поиск = НРег(СокрЛП(ВведенныйТекст));

// Получить инициалы: "Иван" → "И."
Инициал = Лев(Имя, 1) + ".";

// Разобрать строку CSV
Части = СтрРазделить("Телефон;2;30000", ";");
Товар = Части[0];
Количество = Число(Части[1]);

// Проверить, что артикул состоит из 8 символов и начинается с "ART"
АртикулКорректен = СтрДлина(Артикул) = 8 И СтрНачинаетсяС(Артикул, "ART");
```

> [!warning] Сравнение строк
> Оператор `=` для строк **учитывает регистр**: `"Кот" = "кот"` → `Ложь`. Для сравнения без учёта регистра приводим обе строки к одному регистру (`ВРег`) или используем `СтрСравнить`.

> [!question]- Проверь себя
> 1. Как записать в строку текст `Договор "Основной"`?
> 2. Что вернёт `СтрНайти("abc", "x")`?
> 3. Чем `СтрЗаменить` отличается от замены «первого вхождения»?
> 4. Как превратить `"а,б,в"` в массив?
>
> > [!success]- Ответы
> > 1. `"Договор ""Основной"""` — кавычки внутри удваиваются.
> > 2. `0` — подстрока не найдена.
> > 3. `СтрЗаменить` заменяет **все** вхождения.
> > 4. `СтрРазделить("а,б,в", ",")`.
