> [!abstract] Коротко
> **СписокЗначений** — коллекция элементов «значение + представление + пометка + картинка», удобна для выбора в интерфейсе. **ДеревоЗначений** — таблица с вложенными строками (`Строки` у каждой строки), обходится рекурсией. Обе коллекции живут в памяти и в базу сами не пишутся.

## Список значений

**СписокЗначений** удобен для интерфейсных наборов. Каждый его элемент содержит не только значение, но и представление, пометку и картинку.

Например, пользователь видит понятное название способа доставки, а программа работает с коротким кодом:
```1C
СпособыДоставки = Новый СписокЗначений;
СпособыДоставки.Добавить("Самовывоз", "Забрать самостоятельно");
СпособыДоставки.Добавить("Курьер", "Доставка курьером");

ПервыйЭлемент = СпособыДоставки[0];
Сообщить(ПервыйЭлемент.Значение); // Самовывоз
Сообщить(ПервыйЭлемент.Представление); // Забрать самостоятельно
```

Этот пример можно выполнить внутри клиентской или серверной процедуры. Для показа окон выбора нужен клиентский контекст.

> [!warning] Важно
> `СпособыДоставки[0]` - элемент списка значений, а не сразу строка `"Самовывоз"`. Для самой строки используем свойство `Значение`.

## Поиск и пометки

Продолжим пример:
```1C
ЭлементСписка = СпособыДоставки.НайтиПоЗначению("Курьер");

Если ЭлементСписка <> Неопределено Тогда
	ЭлементСписка.Пометка = Истина;
КонецЕсли;

Для Каждого ЭлементСписка Из СпособыДоставки Цикл
	Если ЭлементСписка.Пометка Тогда
		Сообщить(ЭлементСписка.Представление);
	КонецЕсли;
КонецЦикла;
```

Метод `ВыгрузитьЗначения()` возвращает массив значений без представлений и пометок. Если нужны сами данные, а интерфейсные свойства не используются, можно сразу работать с массивом.

## Дерево значений

**ДеревоЗначений** похоже на таблицу, но у каждой строки могут быть подчинённые строки. Например: группа товаров -> отдельные товары.

Следующий пример выполняем **на сервере**:
```1C
Дерево = Новый ДеревоЗначений;
Дерево.Колонки.Добавить("Наименование");
Дерево.Колонки.Добавить("Количество", Новый ОписаниеТипов("Число"));

Группа = Дерево.Строки.Добавить();
Группа.Наименование = "Электроника";

Товар = Группа.Строки.Добавить();
Товар.Наименование = "Телефон";
Товар.Количество = 3;
```

`Дерево.Строки` содержит строки верхнего уровня. `Группа.Строки` - дочерние строки конкретной группы.

## Обход дерева

Один цикл по `Дерево.Строки` обойдёт только верхний уровень. Для дерева произвольной глубины используем рекурсию:
```1C
Процедура ПоказатьСтрокиДерева(СтрокиДерева)
	Для Каждого СтрокаДерева Из СтрокиДерева Цикл
		Сообщить(СтрокаДерева.Наименование);
		ПоказатьСтрокиДерева(СтрокаДерева.Строки);
	КонецЦикла;
КонецПроцедуры
```

Вызываем `ПоказатьСтрокиДерева(Дерево.Строки)` из серверного кода. Процедура заканчивает углубление, когда встречает пустую коллекцию дочерних строк.

## Дерево в памяти и иерархический справочник

Дерево значений само по себе не сохраняется в базу и не создаёт элементы справочника. Иерархический справочник хранит постоянные объекты базы с родителями и ссылками.

Для временного представления данных подходит дерево. Для постоянного списка товаров с группами - справочник.

> [!question]- Проверь себя
> 1. Что вернёт `Список[0]` у списка значений?
> 2. Как обойти дерево произвольной глубины?
> 3. Как получить из списка значений обычный массив?
>
> > [!success]- Ответы
> > 1. Элемент списка (`ЭлементСпискаЗначений`), значение — в его свойстве `Значение`.
> > 2. Рекурсивной процедурой по `Строки` каждой строки.
> > 3. `ВыгрузитьЗначения()`.
