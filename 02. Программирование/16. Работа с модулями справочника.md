> [!abstract] Коротко
> **Модуль объекта** — логика конкретного элемента (`ЭтотОбъект`): заполнение, проверки, `ПередЗаписью`. **Модуль менеджера** — поведение справочника в целом: представление элементов (`ОбработкаПолученияПредставления`), данные выбора, экспортные функции «для всех элементов». `СтандартнаяОбработка = Ложь` отключает поведение платформы по умолчанию.

## Где это?

У объекта любого справочника есть раздел "Прочее". Там мы можем найти "Модуль объекта" и "Модуль менеджера":

![[Pasted image 20260915190315.png]]

*Вкладка «Прочее» справочника «Сотрудники»: кнопки «Модуль объекта», «Модуль менеджера», «Предопределённые».*

## Модуль объекта

Модуль объекта относится к самому элементу справочника. Он позволяет описать логику, которая должна выполняться для этого объекта. 
```1C
#Область ОбработчикиСобытий

Процедура ПередЗаписью(Отказ)
	ФамилияСотрудника = ЭтотОбъект.Фамилия; 
	ИмяСотрудника = Лев(ЭтотОбъект.Имя, 1);
	ОтчествоСотрудника = Лев(ЭтотОбъект.Отчество, 1);
	ЭтотОбъект.Наименование = СтрШаблон( "%1 %2.%3.", ФамилияСотрудника, ИмяСотрудника, ОтчествоСотрудника);				
КонецПроцедуры
	
#КонецОбласти
```

В данном коде мы постоянно обращаемся к `ЭтотОбъект`, который представляет собой наш элемент справочника, с Наименованием, Именем, Фамилией и т.д. Мы описываем логику, чтобы В раздел ФИО фамилия с инициалами подставлялась автоматически при записи других полей.

## Модуль менеджера

Данный модуль относится не к конкретному элементу, а как ко всем справочнику как объекту конфигурации. Он отвечает на вопрос "Что умеет делать справочник в целом?". Также в нём можно выполнить общую операцию над элементами справочника:
```1C
#Область ОбработчикиСобытий

 Процедура ОбработкаПолученияПолейПредставления(Поля, СтандартнаяОбработка)
	 
	 СтандартнаяОбработка = Ложь;	 
	 Поля.Добавить("Наименование");
	 Поля.Добавить("ДатаРождения");
	 
КонецПроцедуры

Процедура ОбработкаПолученияПредставления(Данные, Представление, СтандартнаяОбработка)
	
	СтандартнаяОбработка = Ложь;  
	
	Если НЕ ЗначениеЗаполнено(Данные.ДатаРождения) Тогда
		Представление = Данные.Наименование;
	Иначе	
		ДатаРасчета = НачалоДня(ТекущаяДатаСеанса());
		ВозрастСотрудника = Год(ДатаРасчета) - Год(Данные.ДатаРождения);
		Если Месяц(ДатаРасчета) < Месяц(Данные.ДатаРождения)
			Или (Месяц(ДатаРасчета) = Месяц(Данные.ДатаРождения)
				И День(ДатаРасчета) < День(Данные.ДатаРождения)) Тогда
			ВозрастСотрудника = ВозрастСотрудника - 1;
		КонецЕсли;
		Представление 		= СтрШаблон("%1 (%2 лет)", Данные.Наименование, ВозрастСотрудника);	
	КонецЕсли;
	
КонецПроцедуры

#КонецОбласти
```

В данном коде:
- `ОбработкаПолученияПолейПредставления(Поля, СтандартнаяОбработка)` - обработчик события, позволяющий выбрать поля (реквизиты) справочника, для того чтобы использовать их в представлении элемента справочника. Поля - массив доступных реквизитов, мы должны передать в него строку с названием реквизита через метод `Добавить()`. Аргумент `СтандартнаяОбработка` имеет булев тип, включает или выключает стандартное поведение.
- `ОбработкаПолученияПредставления(Данные, Представление, СтандартнаяОбработка)` - обработчик события, позволяющий изменить представление элемента справочника на основании данных из полей представления. В `Данные` содержатся поля, которые мы передали в методе выше. `Представление` - сама строка представления элемента. `СтандартнаяОбработка` - булево значение, включает или выключает стандартное поведение.

Возраст считаем по календарным годам с проверкой, наступил ли день рождения. Деление секунд на условную длину года не учитывает календарь. Для даты рождения 29 февраля отдельно определяют правило в невисокосном году; для вывода окончаний "год/года/лет" тоже нужен дополнительный алгоритм.

> [!warning] Важно
> В обработчике получения представления не стоит выполнять тяжёлые операции для каждого элемента списка. Представление может запрашиваться многократно. Этот пример показывает механизм, а постоянное отображение возраста требует также учитывать изменение текущей даты.

> [!question]- Проверь себя
> 1. Где автоматически формировать наименование «Фамилия И.О.» при записи?
> 2. Для чего нужен `ОбработкаПолученияПредставления`?
> 3. Есть ли в модуле менеджера доступ к реквизитам конкретного элемента без параметров?
>
> > [!success]- Ответы
> > 1. В `ПередЗаписью` модуля объекта.
> > 2. Чтобы изменить текст, которым элемент показывается в полях и списках.
> > 3. Нет: менеджер работает со справочником в целом, ссылку или данные нужно передать.
