> [!abstract] Коротко
> Операторы сравнения: `=`, `<>`, `>`, `<`, `>=`, `<=`; результат всегда Булево. Числа, строки, даты сравниваются по значению; ссылки — **по идентификатору объекта**, а не по наименованию; коллекции (массивы, структуры) — **по ссылке на экземпляр**. Тип значения проверяем через `ТипЗнч(…) = Тип("…")`.

## Операторы

| Оператор | Значение |
| --- | --- |
| `=` | Равно |
| `<>` | Не равно |
| `>` / `<` | Больше / меньше |
| `>=` / `<=` | Больше или равно / меньше или равно |

```1C
Совершеннолетний = Возраст >= 18;          // Булево
ЭтоЧисло = ТипЗнч(Значение) = Тип("Число"); // проверка типа
```

> [!info] `=` — и присваивание, и сравнение
> В 1С один знак `=` для обоих действий; смысл определяет контекст. В `Флаг = А = Б;` первое `=` — присваивание, второе — сравнение.

## Что и как сравнивается

| Типы | Как сравниваются | Пример |
| --- | --- | --- |
| Числа | По значению | `10 > 9` → Истина |
| Строки | Посимвольно, **с учётом регистра** | `"Кот" = "кот"` → Ложь |
| Даты | По моменту времени | `'20260101' < '20260102'` → Истина |
| Булево | Только `=` и `<>` | `Проведен = Истина` |
| Ссылки | По идентификатору: тот же ли это объект | Два контрагента «Ромашка» — разные ссылки, `=` → Ложь |
| Значения перечисления | По значению перечисления | `Вид = Перечисления.ВидыНоменклатуры.Товар` |
| Массив, Структура, ТаблицаЗначений | **По экземпляру**: та же ли это коллекция | Два разных массива с одинаковыми элементами не равны |
| Разные типы | `=` даёт Ложь; `>`/`<` — ошибка | `"5" = 5` → Ложь |

```1C
А = Новый Массив; А.Добавить(1);
Б = Новый Массив; Б.Добавить(1);
Сообщить(А = Б);   // Ложь: это разные массивы
В = А;
Сообщить(А = В);   // Истина: одна и та же коллекция
```

> [!warning] Сравнение со значениями «пусто»
> - Пустую ссылку сравниваем с `ПустаяСсылка()` или проверяем `ЗначениеЗаполнено()` — **не** с `Неопределено`.
> - `ЗначениеЗаполнено(0)` → Ложь: ноль считается незаполненным. Если 0 — допустимое значение (скидка 0%), проверяем диапазон, а не заполненность.

## Проверка типа

```1C
Если ТипЗнч(ДанныеЗаполнения) = Тип("ДокументСсылка.ЗаказКлиента") Тогда
	// заполнение по заказу
КонецЕсли;
```

`ТипЗнч()` возвращает тип значения, `Тип("Имя")` — описание типа по имени. Так проверяют параметры с составным типом и данные заполнения ([[14. Документы|ввод на основании]]).

> [!question]- Проверь себя
> 1. Чему равно `"10" = 10`?
> 2. Два документа с одинаковым номером и датой — равны ли их ссылки?
> 3. Как проверить, что в переменной именно строка?
>
> > [!success]- Ответы
> > 1. `Ложь` — разные типы.
> > 2. Нет, это разные объекты базы с разными идентификаторами.
> > 3. `ТипЗнч(Перем) = Тип("Строка")`.
