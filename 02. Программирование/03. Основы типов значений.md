> [!abstract] Коротко
> Примитивные типы: **Число, Строка, Дата, Булево, Неопределено, NULL, Тип**. Ссылочные — `СправочникСсылка.…`, `ДокументСсылка.…` и др. При смешивании типов в `+` платформа пробует привести второй операнд к типу первого. Явно приводим функциями `Число()`, `Строка()`, `Дата()`, `Булево()`, тип узнаём через `ТипЗнч()`. Коллекции (массив, структура) при присваивании **не копируются**.

## Примитивные типы

К примитивным относятся Число, Строка, Дата, Булево, Неопределено, NULL и Тип. Их значения неизменяемые. Классификация приведена в [разделе о системе типов 1С](https://its.1c.ru/db/pubprofdata/content/92/hdoc).

| Тип          | Пример              | Для чего используется                                |
| ------------ | ------------------- | ---------------------------------------------------- |
| Строка       | `"Магомедов"`       | Текст                                                |
| Число        | `125.50`            | Целые и дробные числа                                |
| Дата         | `'20260911'`        | Дата и время                                         |
| Булево       | `Истина`,`Ложь`<br> | Да/Нет, включено/выключено                           |
| Неопределено | `Неопределено`      | Значение отсутствует                                 |
| NULL         | `NULL`              | Отсутствие значения, например при работе с запросами |
| Тип          | `Тип("Строка")`     | Описание конкретного типа значения                   |
Например:
```1C
Имя = "Иван";
Количество = 10;
Цена = 1250.50;
ДатаДокумента = ТекущаяДата();
Проведен = Истина;
```

## Ссылочные типы

Это типы, которые обычно ссылаются на объекты конфигурации.

Например:
- **СправочникСсылка.Номенклатура**
- **СправочникСсылка.Контрагенты**
- **ДокументСсылка.РеализацияТоваровУслуг**
- **ПеречислениеСсылка.ВидыОплаты**
- **ПланВидовХарактеристикСсылка.…**
- **ПланСчетовСсылка.…**

У регистра сведений есть тип `РегистрСведенийКлючЗаписи.…`, но это **ключ записи регистра**, а не ссылочный тип справочника или документа. Эти понятия не нужно смешивать.

Например:
```1C
Товар = Справочники.Номенклатура.НайтиПоНаименованию("Телефон");
```

Переменная `Товар` здесь содержит **ссылку на элемент справочника**, а не сам объект целиком.

## Явное и неявное преобразование типов
### Неявное преобразование

Разберём следующий код:
```1C
ВерсияПродукта = 2.0;

ТекстВывода = "Версия нашего продукта: " + ВерсияПродукта;
```

В данном случае переменная ТекстВывода будет иметь тип строки, а ВерсияПродукта будет автоматически преобразована в строку. Так работает 1С, если при сложении встречаются 2 разных типа, то система пытается преобразоваться второй операнд под тип первого, в данном случае преобразует в строку.

Если же вид будет таким:
```1C
ВерсияПродукта = 2.0;

ТекстВывода = ВерсияПродукта + "8.0";
```

То система будет пытаться преобразовать строку "8.0" к числу, у неё это получится и результатом будет число 10.0.

Правила зависят от конкретного оператора и типов операндов. Например, вычитание двух дат возвращает число секунд. Нельзя считать, что любая операция автоматически превратит любые данные в числа. Если преобразование невозможно, будет ошибка.

### Явное преобразование

Для явных преобразований нужно использовать методы с названием типа:
```1C
А = 1;
Сообщить(ТипЗнч(Булево(А)));
Сообщить(ТипЗнч(Строка(А)));
Сообщить(ТипЗнч(Число(А)));
```

Встроенный метод **ТипЗнч()** позволяет нам узнать тип переменной.

Встроенный метод **Тип()** возвращает значение типа `Тип`, описывающее указанный тип. Он не создаёт строку или число:
```1C
Переменная = Тип("Строка"); // Описание типа Строка

Переменная_2 = Тип("Число"); // Описание типа Число
```

## Присваивание

Так как язык 1С является динамически типизируемым, мы можем прямо на ходу присваивать в одну и ту же переменную значения разных типов:
```1C
А = "строка";
А = 124;
А = Истина;

Сообщить(ТипЗнч(А)); // Булево
```

## Проверка заполнения

Не всегда достаточно проверить значение на `Неопределено`. У каждого типа есть своё пустое значение: пустая строка, ноль, пустая ссылка и т.д.
```1C
Сообщить(ЗначениеЗаполнено("")); // Ложь
Сообщить(ЗначениеЗаполнено(0)); // Ложь
Сообщить(ЗначениеЗаполнено(Неопределено)); // Ложь
Сообщить(ЗначениеЗаполнено("Телефон")); // Истина
```

> [!warning] Важно
> Ноль может быть допустимым значением по смыслу задачи. Например, скидка 0% заполнена корректно. В таком случае мы проверяем диапазон скидки, а не используем `ЗначениеЗаполнено()`.

## Изменяемые значения

Строки и числа неизменяемые. Массивы, структуры и таблицы значений могут изменяться. Если присвоить один массив двум переменным, обе будут обращаться к одному массиву:
```1C
ПервыйМассив = Новый Массив;
ВторойМассив = ПервыйМассив;
ВторойМассив.Добавить("Телефон");

Сообщить(ПервыйМассив.Количество()); // 1
```

Присваивание в данном случае не создаёт независимую копию коллекции. Это пригодится при изучении [[18. Массивы]] и передачи параметров в [[09. Процедуры и функции]].

> [!question]- Проверь себя
> 1. Чему равно `"Сумма: " + 10` и `10 + "5"`?
> 2. Чем `Неопределено` отличается от `NULL`?
> 3. `ВторойМассив = ПервыйМассив; ВторойМассив.Добавить(1);` — изменился ли первый массив?
> 4. Почему для скидки нельзя проверять `ЗначениеЗаполнено(Скидка)`?
>
> > [!success]- Ответы
> > 1. Строка «Сумма: 10» и число 15: второй операнд приводится к типу первого.
> > 2. `Неопределено` — «значения нет» во встроенном языке; `NULL` — отсутствие значения в результате запроса (например, при левом соединении).
> > 3. Да: обе переменные указывают на один массив.
> > 4. Ноль считается незаполненным, а скидка 0% — допустимое значение.
