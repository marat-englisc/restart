> [!abstract] Коротко
> Арифметика: `+ - * /` и `%` (остаток). Округление — `Окр(Число, Знаков)`, целая часть — `Цел()` (отбрасывает дробь, не округляет вниз). В коде дробь отделяется **точкой**. Для вывода — `Формат(Число, "ЧДЦ=2")`, результат которого — строка. Денежные суммы округляем по единому правилу везде.

## Определение

**Тип число** нужен для хранения числовых значений: как 
целочисленных, так и дробных.

## Арифметика

Поддерживаются следующие арифметические операции:

| Оператор | Значние   |
| -------- | --------- |
| +        | Сложение  |
| -        | Вычитание или смена знака |
| *        | Умножение |
| /        | Деление   |
| %        | Остаток   |

## Округление

Полезные методы для работы с числами:

| Метод / Функция  | Что делает                    | Пример                                            |
| ---------------- | ----------------------------- | ------------------------------------------------- |
| Окр()            | Округляет переданное значение | Окр(12.132, 1) // 12.1                            |
| Цел()            | Отделяет целую часть          | Цел(12.54) // 12                                  |
| Мин()            | Находит минимальное число     | Мин(10, 20) // 10                                 |
| Макс()           | Находит максимальное число    | Макс(10, 20) // 20                                |
| Число()          | Преобразует значение в число  | Число("123") // 123                               |

`Цел()` отбрасывает дробную часть и у отрицательных чисел: `Цел(-12.54)` вернёт -12. Это не округление вниз до -13.

В программном коде дробную часть отделяем точкой. В пользовательском поле число может отображаться с запятой: это зависит от региональных настроек.

Для суммы строки документа обычно нужно явно определить точность:
```1C
Количество = 3;
Цена = 12.345;
Сумма = Окр(Количество * Цена, 2); // 37.04
```

> [!warning] Важно
> Округление каждой строки и округление только общего итога могут дать разные результаты. Правило округления должно быть одинаковым в форме, при записи и в печатной форме.

## Случайное число

Случайное число получаем через объект `ГенераторСлучайныхЧисел`:
```1C
Генератор = Новый ГенераторСлучайныхЧисел;
Номер = Генератор.СлучайноеЧисло(1, 6);
Сообщить(Номер); // Целое число от 1 до 6 включительно
```

## Форматирование

Если нам нужно показать число с двумя знаками после запятой:
```1C
ТекстСуммы = Формат(1250.5, "ЧДЦ=2; ЧГ=0");
Сообщить(ТекстСуммы);
```

Результат `Формат()` имеет тип **Строка**. Само число не меняется. Для расчётов сохраняем число, а форматирование применяем при выводе.

> [!question]- Проверь себя
> 1. Чему равно `Цел(-7.8)`?
> 2. `Окр(2.5)` и `Окр(12.345, 2)` — результат?
> 3. Почему нельзя считать дальше с результатом `Формат()`?
> 4. Как получить остаток от деления 17 на 5?
>
> > [!success]- Ответы
> > 1. −7: дробная часть отбрасывается.
> > 2. 3 и 12.35 (по умолчанию округление 1,5 как 2).
> > 3. `Формат()` возвращает строку.
> > 4. `17 % 5` = 2.
