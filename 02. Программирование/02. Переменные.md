> [!abstract] Коротко
> Переменная создаётся **первым присваиванием** (`Цена = 150;`) или объявлением `Перем`. Тип не указывается — его определяет значение. Переменная внутри процедуры **локальна**; объявленная через `Перем` в начале модуля — **переменная модуля**. Имена: без пробелов и спецсимволов, не с цифры; регистр не важен.

## Объявление и присваивание

```1C
Цена = 150;           // создали переменную присваиванием
Перем Количество;     // явное объявление: значение Неопределено
Количество = 2;
Сумма = Цена * Количество;
Сообщить(Сумма);      // 300
```

| Способ | Значение до присваивания | Когда используем |
| --- | --- | --- |
| Присваивание `Имя = …` | — | Почти всегда внутри процедур |
| `Перем Имя;` | `Неопределено` | Переменные модуля, редко — для наглядности в процедуре |

Если переменная не объявлена и ей ничего не присвоено, обращение к ней — ошибка «Переменная не определена».

## Правила имён

| Можно | Нельзя |
| --- | --- |
| Буквы, цифры, `_`: `СуммаСНДС`, `Строка2` | Пробелы и спецсимволы: `Сумма-итог` |
| | Начинать с цифры: `2Строка` |
| | Совпадать с ключевыми словами: `Если`, `Цикл`, `Новый` |

Принятый стиль — `ВерблюжийРегистр`: имя из нескольких слов, каждое с большой буквы, без подчёркиваний. Имя отражает смысл: `СуммаДокумента`, а не `с1`.

> [!warning] Регистр не важен, а алфавит — важен
> `Цена`, `цена` и `ЦЕНА` — одна переменная. Но латинская `a` и русская `а` — разные символы: `Аванс` с латинской «A» — это другая переменная, хотя выглядит так же. Такие ошибки трудно найти глазами.

## Область видимости

```1C
Перем ТекущийПользователь; // переменная модуля: видна всем методам этого модуля

Процедура Расчет()
	Итог = 10;             // локальная: существует только внутри Расчет()
	ТекущийПользователь = "Иванов";
КонецПроцедуры

Процедура Показать()
	Сообщить(ТекущийПользователь); // доступна
	// Сообщить(Итог);             // ошибка: Итог здесь не определена
КонецПроцедуры
```

| Вид | Где объявлена | Время жизни |
| --- | --- | --- |
| Локальная | Внутри процедуры/функции | Пока выполняется метод |
| Переменная модуля | `Перем` в начале модуля | Пока существует экземпляр модуля (объект, форма, сеанс) |
| Экспортная переменная модуля | `Перем Имя Экспорт;` | То же, но видна снаружи (у формы — через `Форма.Имя`) |

> [!warning] Не храним данные в переменных модуля
> Переменная модуля не сохраняется в базу и пропадает при закрытии формы или перезапуске. В **общих модулях** переменных модуля нет вовсе. Результат одной функции передаём в другую через **параметры и `Возврат`** ([[09. Процедуры и функции]]).

> [!question]- Проверь себя
> 1. Какое значение у переменной после `Перем Х;`?
> 2. Можно ли в процедуре `Показать()` прочитать локальную переменную процедуры `Расчет()`?
> 3. Почему `Аванс` с латинской A может «сломать» код?
>
> > [!success]- Ответы
> > 1. `Неопределено`.
> > 2. Нет, локальная переменная видна только внутри своего метода.
> > 3. Это будет другая переменная, хотя выглядит одинаково.
