> [!abstract] Коротко
> Документ создаём `Документы.Имя.СоздатьДокумент()`, заполняем шапку и табличные части, записываем `Записать(РежимЗаписиДокумента.Запись | Проведение | ОтменаПроведения)`. Правила, которые должны действовать всегда, — в модуле объекта: пересчёт, проверки, `Отказ = Истина`. `Возврат` без `Отказ` запись не отменяет.

## Создание документа

Примеры выполняем **на сервере**. В конфигурации должен существовать `ЗаказКлиента` с реквизитом `Покупатель` и табличной частью `Товары`: `Товар`, `Количество`, `Цена`, `Сумма`.

Создадим функцию в серверном общем модуле. Она получает уже выбранные непустые ссылки:
```1C
Функция СоздатьЗаказ(Покупатель, Товар) Экспорт

	Если НЕ ЗначениеЗаполнено(Покупатель) Или НЕ ЗначениеЗаполнено(Товар) Тогда
		ВызватьИсключение "Нужно передать покупателя и товар";
	КонецЕсли;

	Заказ = Документы.ЗаказКлиента.СоздатьДокумент();
	Заказ.Дата = ТекущаяДатаСеанса();
	Заказ.Покупатель = Покупатель;

	СтрокаТовара = Заказ.Товары.Добавить();
	СтрокаТовара.Товар = Товар;
	СтрокаТовара.Количество = 2;
	СтрокаТовара.Цена = 150;
	СтрокаТовара.Сумма = 300;

	Заказ.Записать(РежимЗаписиДокумента.Запись);
	Возврат Заказ.Ссылка;

КонецФункции
```

Если в нашей конфигурации обязательны договор или другие поля, заполняем их до записи. Функция создаёт новый заказ при каждом вызове.

## Запись, проведение и отмена

У объекта документа есть режимы записи:
```1C
Заказ.Записать(РежимЗаписиДокумента.Запись);
Заказ.Записать(РежимЗаписиДокумента.Проведение);
Заказ.Записать(РежимЗаписиДокумента.ОтменаПроведения);
```

Это три отдельных варианта операции, а не рекомендуемая последовательность для каждого документа. Проведение допустимо, если оно разрешено для данного вида документа.

> [!warning] Важно
> Простое присваивание `Проведен = Истина` не заменяет корректный вызов проведения и формирование движений.

## Данные табличной части

У табличной части объекта можно добавлять, удалять и обходить строки:
```1C
Для Каждого СтрокаТовара Из Заказ.Товары Цикл
	СтрокаТовара.Сумма = Окр(СтрокаТовара.Количество * СтрокаТовара.Цена, 2);
КонецЦикла;

Заказ.ИтоговаяСумма = Заказ.Товары.Итог("Сумма");
```

Фрагмент предполагает реквизит `ИтоговаяСумма` и документ только с товарами. Если есть услуги, их добавляем к итогу по правилам нашей конфигурации.

## Проверка при записи

Обработчик изменения поля формы срабатывает при действиях пользователя. При программном заполнении документа такой обработчик формы не обязан вызываться.

Поэтому обязательную проверку количества и пересчёт размещаем в модуле объекта. Например, для документа с одной табличной частью:
```1C
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)

	Для Каждого СтрокаТовара Из Товары Цикл
		Если СтрокаТовара.Количество <= 0 Тогда
			Отказ = Истина;
			Сообщение = Новый СообщениеПользователю;
			Сообщение.Текст = "Количество товара должно быть больше нуля";
			Сообщение.Сообщить();
			Возврат;
		КонецЕсли;
		СтрокаТовара.Сумма = Окр(СтрокаТовара.Количество * СтрокаТовара.Цена, 2);
	КонецЦикла;

	ИтоговаяСумма = Товары.Итог("Сумма");

КонецПроцедуры
```

Этот пример **заменяет** обработчик `ПередЗаписью` или объединяется с уже существующим. Второй обработчик с тем же именем создавать нельзя.

Дополнительно проверяем товар, покупателя, допустимость цены и принадлежность договора покупателю. Отбор поля выбора не заменяет эти правила.

## Отказ

`Отказ = Истина` запрещает продолжение операции платформой. `Возврат` только заканчивает нашу процедуру. Если выполнить один `Возврат`, запись не будет запрещена.

Не сбрасываем `Отказ` в Ложь: его могла установить предыдущая проверка или подписка. Это правило объясняется в [стандарте 1С по параметру Отказ](https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_Development_Standards/Code_conventions/Module_formatting/Cancel_parameter_in_event_handlers/?language=en).

> [!question]- Проверь себя
> 1. Как провести документ из кода?
> 2. Достаточно ли написать `Проведен = Истина` и записать?
> 3. В `ПередЗаписью` нашли ошибку и сделали `Возврат`. Запишется ли документ?
>
> > [!success]- Ответы
> > 1. `Объект.Записать(РежимЗаписиДокумента.Проведение)`.
> > 2. Нет: движения не сформируются, это не проведение.
> > 3. Да. Чтобы отменить запись, нужно `Отказ = Истина`.
