> [!abstract] Коротко
> **Массив** — нумерованная коллекция в памяти, индексы **с 0**. Методы: `Добавить`, `Вставить`, `Удалить`, `Найти` (индекс или `Неопределено`), `Количество`. Присваивание не копирует массив; копию делаем вручную (поверхностно). `ФиксированныйМассив` запрещает изменение состава.

## Что это?

**Массив** - пронумерованная коллекция значений. Он удобен, когда нам нужен список товаров, ссылок или промежуточных результатов.

Массив находится в памяти и сам по себе не сохраняется в базу. Элементы могут иметь разные типы, но в прикладной задаче обычно удобнее хранить однородные значения.

## Создание и добавление

Примеры можно выполнить внутри процедуры клиентского или серверного модуля:
```1C
Товары = Новый Массив;
Товары.Добавить("Телефон");
Товары.Добавить("Ноутбук");
Товары.Добавить("Чайник");

Сообщить(Товары.Количество()); // 3
Сообщить(Товары[0]); // Телефон
```

> [!warning] Важно
> Индексы массива начинаются с нуля. У массива из трёх элементов допустимые индексы - 0, 1, 2. Обращение к `Товары[3]` приведёт к ошибке.

## Изменение и удаление

Продолжим предыдущий пример:
```1C
Товары[0] = "Смартфон";
Товары.Вставить(1, "Планшет");
Товары.Удалить(2);
```

Разбор:
- Заменили значение первого элемента.
- Вставили планшет перед элементом с индексом 1.
- Удалили элемент с индексом 2 - после вставки это ноутбук.

Итоговый порядок: смартфон, планшет, чайник. После вставки и удаления индексы следующих элементов сдвигаются.

## Поиск

`Найти()` возвращает индекс или `Неопределено`, если значение отсутствует:
```1C
Индекс = Товары.Найти("Смартфон");

Если Индекс <> Неопределено Тогда
	Сообщить(СтрШаблон("Найден элемент с индексом %1", Индекс));
КонецЕсли;
```

Нельзя проверять найденный индекс через `ЗначениеЗаполнено()`: у первого элемента индекс 0, а ноль эта функция считает незаполненным.

## Обход массива

Для чтения всех значений удобен `Для Каждого`:
```1C
Для Каждого Товар Из Товары Цикл
	Сообщить(Товар);
КонецЦикла;
```

Если нужно менять элементы по индексам:
```1C
Если Товары.Количество() > 0 Тогда
	Для Индекс = 0 По Товары.Количество() - 1 Цикл
		Товары[Индекс] = ВРег(Товары[Индекс]);
	КонецЦикла;
КонецЕсли;
```

Этот вариант предполагает, что все значения - строки.

## Копирование

Присваивание `Копия = Товары` не создаёт другой массив. Для самостоятельной копии создаём новую коллекцию и переносим значения:
```1C
Копия = Новый Массив;
Для Каждого Товар Из Товары Цикл
	Копия.Добавить(Товар);
КонецЦикла;
```

Если элементами были другие изменяемые коллекции, они останутся общими. Такое копирование является **поверхностным**.

## Фиксированный массив

Если состав коллекции не должен меняться, можно создать `Новый ФиксированныйМассив(Товары)`. Добавлять или удалять его элементы нельзя. Это ограничение самого массива, а не глубокая заморозка всех вложенных объектов.

> [!question]- Проверь себя
> 1. Какой последний допустимый индекс у массива из 5 элементов?
> 2. Почему нельзя проверять результат `Найти()` через `ЗначениеЗаполнено()`?
> 3. Как узнать количество элементов?
>
> > [!success]- Ответы
> > 1. 4.
> > 2. Первый элемент имеет индекс 0, который считается незаполненным.
> > 3. `Массив.Количество()`.
