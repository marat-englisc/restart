> [!abstract] Коротко
> `ОписаниеТипов` задаёт допустимые типы и квалификаторы (например, для колонки таблицы). `Метаданные` описывает **структуру** конфигурации, а менеджеры (`Справочники.…`, `Константы.…`, `Перечисления.…`) работают с **данными**. `ЗаполнитьЗначенияСвойств()` переносит одноимённые свойства — главный инструмент «копирования» данных между объектами.

## Описание типов

`Тип()` описывает один тип. **ОписаниеТипов** задаёт допустимый набор типов и при необходимости их ограничения.

Например, в серверной процедуре создадим числовую колонку с двумя знаками после запятой:
```1C
Квалификаторы = Новый КвалификаторыЧисла(15, 2);
ТипЦены = Новый ОписаниеТипов("Число", Квалификаторы);

Таблица = Новый ТаблицаЗначений;
Таблица.Колонки.Добавить("Цена", ТипЦены);
```

Для проверки допустимого типа используем:
```1C
Сообщить(ТипЦены.СодержитТип(Тип("Число"))); // Истина
Сообщить(ТипЦены.СодержитТип(Тип("Строка"))); // Ложь
```

> [!warning] Важно
> Проверка типа не проверяет все бизнес-правила. Число может иметь правильный тип, но недопустимое для задачи значение.

## Метаданные

**Метаданные** описывают структуру конфигурации: какие есть справочники, реквизиты, документы и регистры. Это описание, а не сами введённые товары.

Серверный пример для существующего справочника:
```1C
ОписаниеСправочника = Метаданные.Справочники.Номенклатура;
Сообщить(ОписаниеСправочника.Синоним);

Для Каждого Реквизит Из ОписаниеСправочника.Реквизиты Цикл
	Сообщить(Реквизит.Имя);
КонецЦикла;
```

`Метаданные.Справочники.Номенклатура` описывает справочник. `Справочники.Номенклатура` - менеджер, через который создаём и ищем его элементы. Конкретный элемент представлен ссылкой или объектом.

## ЗаполнитьЗначенияСвойств

Этот метод переносит значения одноимённых свойств:
```1C
Источник = Новый Структура("Количество,Цена", 2, 150);
Приемник = Новый Структура("Количество,Цена,Сумма", 0, 0, 0);

ЗаполнитьЗначенияСвойств(Приемник, Источник, "Количество,Цена");
Приемник.Сумма = Приемник.Количество * Приемник.Цена;
```

Первый параметр - куда переносим, второй - откуда. Третий позволяет явно ограничить список полей.

Метод не рассчитывает зависимые поля и не записывает объект в базу. В примере сумму мы вычислили отдельно.

## Константы и перечисления в коде

Если в конфигурации создана строковая константа `НаименованиеОрганизации`, на сервере можно получить или установить её значение:
```1C
Наименование = Константы.НаименованиеОрганизации.Получить();
Константы.НаименованиеОрганизации.Установить("Учебная организация");
```

`Установить()` изменяет значение в базе, а не только локальную переменную. Для выполнения нужны соответствующие права.

Если создано перечисление `ВидыНоменклатуры` со значением `Товар`, серверное обращение выглядит так:
```1C
Вид = Перечисления.ВидыНоменклатуры.Товар;
```

Для получения этого же значения на клиенте управляемого приложения можно использовать `ПредопределенноеЗначение("Перечисление.ВидыНоменклатуры.Товар")`.

Имена перечисления и значения должны совпадать с именами в нашей конфигурации. Их синонимы на экране могут отличаться.

## Проверки перед действием

- `ТипЗнч(Значение)` - какой тип у значения сейчас.
- `ЗначениеЗаполнено(Значение)` - заполнено ли оно по правилам типа.
- `ПустаяСтрока(Текст)` - пустая ли строка, в том числе состоящая из пробельных символов.
- `Структура.Свойство("Имя")` - существует ли свойство структуры.

Выбираем проверку по задаче. Например, искать товар по наименованию и сразу обращаться к его реквизитам нельзя: сначала проверяем, найдена ли непустая ссылка.

## Синтакс-помощник

Если имя метода или его параметры не помнятся, открываем **"Справка" -> "Синтакс-помощник"**:

![[Синтакс-помощник.jpg]]

*Синтакс-помощник открыт справа: вкладки «Содержание», «Индекс», «Поиск»; разделы «Глобальный контекст», «Общие объекты», «Прикладные объекты», «Работа с запросами».*

Проверяем сигнатуру, возвращаемый тип и раздел **"Доступность"**. Метод может существовать, но быть недоступным в тонком клиенте или в текущем виде модуля.

Для нашего конспекта это особенно важно при работе с таблицей значений, прикладными объектами и асинхронными методами. Названия функций из языка запросов нельзя автоматически использовать во встроенном языке.

> [!question]- Проверь себя
> 1. Чем `Метаданные.Справочники.Номенклатура` отличается от `Справочники.Номенклатура`?
> 2. Что делает `ЗаполнитьЗначенияСвойств(Приемник, Источник)`?
> 3. Записывает ли `Константы.Имя.Установить()` значение в базу?
>
> > [!success]- Ответы
> > 1. Первое — описание справочника, второе — менеджер для работы с его элементами.
> > 2. Копирует значения одноимённых свойств из источника в приёмник.
> > 3. Да, сразу.
