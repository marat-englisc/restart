> [!abstract] Коротко
> Дата в 1С хранит год…секунды; литерал — `'20260912183000'`, конструктор — `Дата(2026, 9, 12)`. Разность дат — **секунды**, прибавление числа — секунды; месяцы добавляем `ДобавитьМесяц()`. Границы периодов — `НачалоДня/КонецДня/НачалоМесяца/КонецМесяца…`. На сервере для даты документа — `ТекущаяДатаСеанса()`.

## Определение

Тип данных дата нужен для хранения информации об определённом времени. Значение этого типа хранит сразу год, месяц, день, час, минуту и секунду, например: `'20260912180000'`.

Записывать дату нужно в одинарных кавычках `''`, и можно записывать в разных форматах:
```1C
Дата_1 = '20260912210000';
Дата_2 = '2026.09.12. 21:00:00';
Дата_3 = '2026-09-12 21:00:00';
Дата_4 = '2026/09/12 21:00:00';
```

С датами мы можем проводить различные арифметические операции

Также можно создать переменную с типом Дата через метод `Дата()`:
```1C
Дата_1 = Дата(2026, 9, 12);
Дата_2 = Дата(2026, 9, 12, 18, 30, 45);
```

## Операции с датами

Даты можно вычитать, результат будет в секундах:
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 45);
Дата_2 = Дата(2026, 9, 12, 18, 30, 0);

Сообщить(Дата_1 - Дата_2); // 45
```

К дате можно прибавлять числовые значения в секундах:
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 0);
Дата_1 = Дата_1 + 60;

Сообщить(Дата_1); // 2026.9.12 18:31:0
```

Для добавления дней используем секунды, а для добавления месяцев - метод `ДобавитьМесяц()`:
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 0);
Дата_1 = Дата_1 + 5 * 24 * 60 * 60;

Сообщить(Дата_1); // 2026.9.17 18:30:0
```

`ДобавитьКДате()` не является глобальной функцией встроенного языка. Не нужно переносить названия функций из других механизмов в обычный программный код.

Если нужно добавить месяц, нельзя просто прибавить 30 дней, так как месяцы имеют разную длину:
```1C
НоваяДата = ДобавитьМесяц(Дата(2026, 1, 31), 1);
Сообщить(НоваяДата); // 28.02.2026
```

## Форматирование даты

На случай если формат вывода даты не устраивает, в 1С есть механизм её форматирования через метод `Формат()`:
```1C
Дата = '20260912183000';

СтрокаДата = Формат(Дата, "ДФ=dd.MM.yyyy");

СтрокаДата_2 = Формат(Дата, "ДФ=dd.MM.yyyy HH:mm:ss");
```

## Текущая дата сеанса

`ТекущаяДата()` возвращает дату и время компьютера, где выполняется код. На клиенте это компьютер пользователя, на сервере - сервер.

Если нужна текущая дата с учётом часового пояса сеанса, в серверном прикладном коде используем `ТекущаяДатаСеанса()`. Например, так можно заполнить дату создаваемого документа.

> [!warning] Важно
> Само значение типа `Дата` не хранит часовой пояс. При обмене данными нужно заранее договориться, какое время мы передаём.

> [!question]- Проверь себя
> 1. Как прибавить к дате 3 дня?
> 2. Что вернёт `ДобавитьМесяц('20260131', 1)`?
> 3. Почему `ТекущаяДата()` на клиенте может отличаться от серверной?
> 4. Документ от 31.10 15:00. Попадёт ли он в условие `Дата <= '20261031'`?
>
> > [!success]- Ответы
> > 1. `Дата + 3 * 86400` (86400 секунд в сутках).
> > 2. 28.02.2026 — последний день месяца, а не 03.03.
> > 3. Она берёт время компьютера, где выполняется код.
> > 4. Нет: литерал означает 31.10 00:00:00. Нужен `КонецДня()`.
