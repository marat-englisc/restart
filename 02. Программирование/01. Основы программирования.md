> [!abstract] Коротко
> Встроенный язык 1С — **динамически типизированный** язык, который платформа компилирует в байт-код и исполняет на своей виртуальной машине. Код живёт в **модулях** (приложения, объекта, формы, общих…), состоит из **процедур и функций**, каждый оператор заканчивается `;`. Регистр букв не важен, ключевые слова есть на русском и английском.

## Что за язык

| Свойство | Что означает на практике |
| --- | --- |
| Компиляция в байт-код + виртуальная машина | Ошибки синтаксиса видны при проверке модуля (`Ctrl+F7`), ошибки логики — только при выполнении |
| Динамическая типизация | Тип у значения, а не у переменной: `А = 1; А = "текст";` — допустимо |
| Не чувствителен к регистру | `Сообщить`, `сообщить`, `СООБЩИТЬ` — одно и то же |
| Двуязычный | `Если … Тогда` = `If … Then`; в проектах пишут на русском |
| Объектная модель без классов | Есть объекты платформы со свойствами и методами, но **нельзя объявить свой класс** с наследованием. Повторное использование — через общие модули и модули объектов |

## Базовые термины

| Термин | Пример |
| --- | --- |
| **Модуль** — место, где пишется код | Модуль объекта документа, модуль формы, общий модуль |
| **Переменная** — именованное значение | `Сумма = 100;` |
| **Тип значения** | Число, Строка, Дата, Булево, ссылка на справочник |
| **Выражение** — то, что вычисляется | `Цена * Количество` |
| **Оператор** — действие | `=`, `Если`, `Для`, вызов `Сообщить()` |
| **Операнды** — участники выражения | В `А + Б + 100` это `А`, `Б`, `100` |

## Первая программа

Для экспериментов удобно писать код в **модуле управляемого приложения**: ПКМ по корню «Конфигурация» → **Открыть модуль управляемого приложения**. Операторы в конце модуля (вне процедур) выполнятся при запуске Предприятия.

![[Pasted image 20260911162216.png]]

*Модуль приложения с двумя вызовами `Сообщить()`. Сообщения появятся в окне Предприятия после запуска (`F5`).*

```1C
Сообщить("Привет, мир!");
```

`Сообщить()` выводит текст в окно сообщений. Для учёбы и отладки удобно, в рабочем коде для пользователя используют `СообщениеПользователю` ([[27. Ошибки и сообщения пользователю]]).

> [!warning] Точка с запятой
> Каждый оператор заканчивается `;`. Её нет только после «открывающих» строк конструкций: `Если … Тогда`, `Для … Цикл`, `Процедура Имя()`. Пропущенная `;` — самая частая синтаксическая ошибка новичка.

## Синтакс-помощник

Документация встроена в Конфигуратор: ставим курсор на метод → ПКМ → **Поиск в синтакс-помощнике** (`Ctrl+F1`). Если у имени несколько значений, платформа предложит выбрать раздел:

![[Pasted image 20260911170644.png]]

*Метод `Сообщить` есть в глобальном контексте и у объекта `СообщениеПользователю`.*

![[Pasted image 20260911170726.png]]

*Описание метода: синтаксис, параметры, описание, **доступность** (клиент, сервер, внешнее соединение) и версия появления.*

> [!tip] Читайте раздел «Доступность»
> Метод может существовать, но быть недоступным на тонком клиенте или в текущем модуле. Это главный источник ошибок «метод не найден» в управляемом приложении.

## Комментарии и оформление

```1C
// Однострочный комментарий. Многострочных /* */ в языке нет —
// каждую строку начинаем с //.

Сумма = Цена * Количество; // комментарий в конце строки
```

Комментарий начинается с `//` и действует до конца строки. Быстро закомментировать выделенные строки — `Ctrl+/` (или **Текст → Блок → Добавить комментарий**).

## Горячие клавиши редактора

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Пробел` | Контекстная подсказка и автодополнение |
| `Ctrl+Shift+Пробел` | Подсказка по параметрам метода |
| `Ctrl+Q` | Шаблоны конструкций (Если, Для, Пока…) |
| `Shift+Alt+F` | Форматирование отступов |
| `Ctrl+Alt+P` | Список процедур и функций модуля |
| `Ctrl+F7` | Синтаксическая проверка модуля |
| `F12` | Перейти к определению метода |

Полный список — [[99. Шпаргалки/02. Горячие клавиши|Горячие клавиши]].

> [!question]- Проверь себя
> 1. Можно ли в 1С создать свой класс с наследованием?
> 2. Где посмотреть, доступен ли метод на тонком клиенте?
> 3. Как закомментировать несколько строк?
>
> > [!success]- Ответы
> > 1. Нет. Логику группируют в модулях объектов и общих модулях.
> > 2. В Синтакс-помощнике, раздел «Доступность».
> > 3. Начать каждую строку с `//` (выделить и нажать `Ctrl+/`).
