> [!abstract] Коротко
> **Структура** — пары «ключ-строка → значение», обращение через точку: `Параметры.Цена`. **Соответствие** — ключом может быть любое значение (ссылка, число): `Цены.Получить(Товар)`. Наличие ключа структуры проверяем `Свойство()`, соответствия — `Получить()` ≠ `Неопределено`.

## Структура

**Структура** хранит пары **ключ - значение**. В отличие от массива, обращаемся к данным по имени:
```1C
ПараметрыТовара = Новый Структура;
ПараметрыТовара.Вставить("Наименование", "Телефон");
ПараметрыТовара.Вставить("Цена", 30000);

Сообщить(ПараметрыТовара.Наименование); // Телефон
Сообщить(ПараметрыТовара["Цена"]); // 30000
```

Примеры этой заметки можно выполнять внутри клиентской или серверной процедуры.

Ключ структуры - строка, соответствующая правилам имени: без пробелов, без цифры в начале. В значении может быть число, строка, ссылка или другая коллекция.

## Короткое создание

Если набор полей известен заранее:
```1C
Параметры = Новый Структура("Количество,Цена", 2, 150);
Сумма = Параметры.Количество * Параметры.Цена;
```

Значения в конструкторе соответствуют именам по порядку.

## Проверка наличия свойства

Чтение отсутствующего свойства вызывает ошибку. Сначала можно проверить его наличие:
```1C
Цена = Неопределено;
Если Параметры.Свойство("Цена", Цена) Тогда
	Сообщить(Цена);
Иначе
	Сообщить("Цена не передана");
КонецЕсли;
```

`Свойство()` возвращает Булево и через второй параметр передаёт найденное значение. Наличие свойства и заполненность его значения - разные проверки: свойство может существовать и содержать `Неопределено`.

`Вставить()` с существующим ключом заменяет значение. `Удалить("Цена")` удаляет пару. `Очистить()` удаляет все пары.

## Обход структуры

При обходе получаем значение типа `КлючИЗначение`:
```1C
Для Каждого Пара Из Параметры Цикл
	Сообщить(СтрШаблон("%1: %2", Пара.Ключ, Пара.Значение));
КонецЦикла;
```

Не следует использовать порядок свойств структуры вместо порядка массива. Если последовательность важна по смыслу задачи, выбираем соответствующую коллекцию.

## Соответствие

**Соответствие** тоже хранит пары ключ - значение, но ключом может быть не только строковое имя. Например, число или ссылка на товар:
```1C
Цены = Новый Соответствие;
Цены.Вставить("Телефон", 30000);
Цены.Вставить("Ноутбук", 80000);

Цена = Цены.Получить("Телефон");
Сообщить(Цена); // 30000
```

Если ключ отсутствует, `Получить()` вернёт `Неопределено`. Но это же значение можно специально сохранить в соответствии. Поэтому такая проверка однозначна только если по условиям задачи `Неопределено` не является допустимым значением.

## Что выбрать?

Структура подходит для набора именованных параметров: количество, цена, скидка. Соответствие - для сопоставления произвольных ключей и значений, например ссылок товаров и их цен.

Для варианта без изменения состава есть `ФиксированнаяСтруктура` и `ФиксированноеСоответствие`. Они создаются из заполненных коллекций. Как и у фиксированного массива, вложенные изменяемые значения требуют отдельного внимания.

> [!question]- Проверь себя
> 1. Нужно хранить цены по ссылкам на товары. Структура или соответствие?
> 2. Что будет при чтении отсутствующего свойства структуры через точку?
> 3. Как одной строкой создать структуру с ключами Количество и Цена?
>
> > [!success]- Ответы
> > 1. Соответствие — ключ структуры может быть только строкой-идентификатором.
> > 2. Ошибка. Сначала проверяем `Свойство()`.
> > 3. `Новый Структура("Количество,Цена", 2, 150)`.
