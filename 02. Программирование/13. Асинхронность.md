> [!abstract] Коротко
> `Асинх` помечает метод, внутри которого можно `Ждать` результат асинхронной операции (вопрос, ввод, предупреждение) без блокировки интерфейса. `Асинх Функция` возвращает **Обещание**. Асинхронность — это про **клиентское ожидание**, а не про параллельные вычисления: тяжёлый расчёт переносят в фоновое задание.

## Что это?

**Асинхронность** - возможность начать операцию, результат которой будет готов позже, и организовать продолжение кода после её завершения без блокировки всего клиентского приложения.

При синхронном вызове вызывающий код получает результат после завершения метода. При асинхронном вызове результат может ещё не быть готов. Для ожидания используем `Ждать` внутри метода с модификатором `Асинх`. Ожидание приостанавливает продолжение этого метода, а не всю работу интерфейса. Механизм описан в [материале разработчиков 1С](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Standards/Enhancements_to_1C_Enterprise_language_syntax_for_asynchronous_functions__synchronous_asynchrony/?language=en).

## Отличия от синхронного программирования

Пример синхронного кода:
```1C
Функция ПолучитьВозрастВДнях(ДатаРождения)
	Возврат Окр((ТекущаяДата() - ДатаРождения) / 86400, 0);
КонецФункции 

ДатаРождения = '2002.07.18 00:00:00';
ВозрастВДнях = ПолучитьВозрастВДнях(ДатаРождения);

Сообщить(ВозрастВДнях);
```

Как мы можем заметить, все действия выполняются шаг за шагом, синхронно:

---

Создана Переменная -> Отправили её в функцию -> Выполнились вычисления в функции -> Возвращён результат -> Результат присвоен в переменную -> Значение переменной выведено на экран.

---

Пример асинхронного кода:
```1C
Функция ПолучитьВозрастВДнях(ДатаРождения)
	Возврат Окр((ТекущаяДата() - ДатаРождения) / 86400, 0);
КонецФункции

АСИНХ Процедура ПосчитатьВозраст()
	ДатаРождения = ЖДАТЬ ВвестиДатуАсинх(, "Напишите Вашу дату рождения?");
	Если ДатаРождения = Неопределено Тогда
		Возврат;
	КонецЕсли;
	ВозрастВДнях = ПолучитьВозрастВДнях(ДатаРождения);
	ЖДАТЬ ПредупреждениеАсинх("Ваш возраст в днях: " + ВозрастВДнях,, "Возраст");
	ПоказатьОповещениеПользователя("Это должно быть после закрытия");
КонецПроцедуры

Процедура ПриНачалеРаботыСистемы()
    ПосчитатьВозраст();
КонецПроцедуры
```

Этот пример размещаем в модуле управляемого приложения. В нём мы ожидаем, пока пользователь введёт дату рождения или отменит ввод. При отмене завершаем процедуру, не передавая `Неопределено` в расчёт.

---

Обработчик запуска вызывает асинхронную процедуру -> начинается ввод даты -> процедура ожидает результат -> после ввода рассчитывает количество дней -> ожидает закрытия предупреждения -> показывает оповещение и завершается.

Вызывающий обработчик `ПриНачалеРаботыСистемы` не ждёт завершения `ПосчитатьВозраст`: у асинхронной процедуры нет возвращаемого обещания для `Ждать`. Поэтому нельзя считать, что обработчик обязательно закончится только после закрытия всех окон.

---

## Обещание

Асинхронная **функция** возвращает значение типа `Обещание`. Оно представляет будущий результат операции. `Ждать` получает результат, когда операция завершится, или передаёт возникшее исключение.

Если нужна собственная асинхронная операция с возвращаемым значением, объявляем её как `Асинх Функция`, а вызываем с `Ждать` из другого асинхронного метода.

## Что асинхронность не делает автоматически

Если внутри асинхронной процедуры выполнить долгий обычный цикл, он останется обычным вычислением. Модификатор `Асинх` сам по себе не переносит расчёт на сервер и не запускает отдельный поток.

Для отдельного выполнения длительной серверной операции используем [[32. Фоновые и регламентные задания]]. Обычный вызов серверного метода и `Ждать` - тоже разные механизмы.

> [!question]- Проверь себя
> 1. Что вернёт вызов `Асинх Функции` без `Ждать`?
> 2. Можно ли использовать `Ждать` в обычной (не `Асинх`) процедуре?
> 3. Ускорит ли `Асинх` долгий цикл расчёта?
>
> > [!success]- Ответы
> > 1. Объект `Обещание`, а не сам результат.
> > 2. Нет, только внутри метода с модификатором `Асинх`.
> > 3. Нет: код выполняется так же; для длительных операций — фоновые задания.
