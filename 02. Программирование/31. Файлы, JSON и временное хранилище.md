> [!abstract] Коротко
> Пути к файлам относятся к той машине, где выполняется код: на сервере — к серверу. Текст пишем/читаем через `ТекстовыйДокумент` или `ЗаписьТекста/ЧтениеТекста`. JSON: `ЗаписьJSON` + `ЗаписатьJSON()`, `ЧтениеJSON` + `ПрочитатьJSON()`. **Временное хранилище** передаёт данные между клиентом, сервером и фоновыми заданиями по адресу.

## Клиентский и серверный файл

Путь `C:\Обмен\товары.txt` на сервере относится к диску сервера. Такой же текст пути на клиенте относится к компьютеру пользователя. Даже если в учебной файловой базе это один компьютер, в рабочей системе они могут отличаться.

В веб-клиенте работа с локальными файлами дополнительно зависит от браузера и поддерживаемых механизмов загрузки и скачивания. Сервер не может просто прочитать произвольный файл компьютера пользователя.

## Текстовый документ

Следующий пример выполняем **на сервере**. Он создаёт отдельный временный файл:
```1C
ПутьКФайлу = ПолучитьИмяВременногоФайла("txt");

ДокументТекста = Новый ТекстовыйДокумент;
ДокументТекста.УстановитьТекст("Телефон;2;30000");
ДокументТекста.Записать(ПутьКФайлу, КодировкаТекста.UTF8);

ПрочитанныйТекст = Новый ТекстовыйДокумент;
ПрочитанныйТекст.Прочитать(ПутьКФайлу, КодировкаТекста.UTF8);
Сообщить(ПрочитанныйТекст.ПолучитьТекст());
```

Для проверки существования используем объект `Файл` и метод `Существует()`. Запись по существующему пути может заменить содержимое, поэтому путь выбираем осознанно.

Для больших файлов есть последовательное чтение и запись через `ЧтениеТекста` и `ЗаписьТекста`. Открытые ресурсы нужно закрывать и при нормальном завершении, и при ошибке.

## Что такое JSON?

**JSON** - текстовый формат передачи данных. В нём есть объекты, массивы, строки, числа, булевы значения и `null`. Например:
```json
{"Наименование":"Телефон","Количество":2,"Цена":30000}
```

Платформа предоставляет потоковые и объектные средства работы с этим форматом. Они описаны в [документации 1С по JSON](https://v8.1c.ru/platforma/json/).

## Запись и чтение JSON

Серверный пример для структуры из простых значений:
```1C
Данные = Новый Структура("Наименование,Количество,Цена", "Телефон", 2, 30000);

Писатель = Новый ЗаписьJSON;
Писатель.УстановитьСтроку();
ЗаписатьJSON(Писатель, Данные);
ТекстJSON = Писатель.Закрыть();

Читатель = Новый ЧтениеJSON;
Читатель.УстановитьСтроку(ТекстJSON);
ВосстановленныеДанные = ПрочитатьJSON(Читатель);
Читатель.Закрыть();

Сообщить(ВосстановленныеДанные.Наименование); // Телефон
```

Здесь мы сначала превратили структуру в текст, а затем прочитали текст обратно. При чтении произвольного внешнего JSON учитываем допустимость имён ключей и при необходимости выбираем чтение объектов в соответствия.

> [!warning] Важно
> Ссылка на товар не превращается автоматически в товар внешней системы. Для обмена договариваемся об идентификаторах, формате дат, точности чисел и обязательных полях.

## Проверка входных данных

Даже корректный JSON может содержать отрицательное количество или неизвестный товар. После разбора проверяем структуру, типы и значения, а затем решаем, какие изменения записывать в базу.

Если загрузку можно запустить повторно, нужен способ узнать уже загруженные записи. Иначе повторный файл создаст дубликаты.

## Временное хранилище

**Временное хранилище** позволяет временно сохранить значение на стороне платформы и получить адрес для последующего обращения:
```1C
Адрес = ПоместитьВоВременноеХранилище(Данные);
ПолученныеДанные = ПолучитьИзВременногоХранилища(Адрес);
```

Это серверный фрагмент, где `Данные` уже подготовлены. Адрес хранилища не является файловым путём и не равен ссылке на объект базы.

Срок хранения зависит от способа помещения и привязки к форме или сеансу. Для сценария с формой обычно используют привязку к её уникальному идентификатору и продумывают очистку. Такое хранилище не подходит для постоянного хранения вложений между сеансами.

> [!question]- Проверь себя
> 1. Код на сервере читает `C:\Обмен\товары.txt`. Чей это диск?
> 2. Как превратить структуру в строку JSON?
> 3. Подходит ли временное хранилище для постоянного хранения файлов?
>
> > [!success]- Ответы
> > 1. Диск сервера 1С (в файловом варианте — компьютера, где работает серверная часть).
> > 2. `ЗаписьJSON.УстановитьСтроку()` → `ЗаписатьJSON(Запись, Данные)` → `Запись.Закрыть()`.
> > 3. Нет, оно живёт ограниченное время (сеанс/форма).
