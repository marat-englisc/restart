> [!abstract] Коротко
> Вопрос пользователю в управляемом приложении — **немодальный**. Современный способ: `Асинх Процедура` + `Ответ = Ждать ВопросАсинх(Текст, РежимДиалогаВопрос.ДаНет)` (8.3.18+). Классический: `ПоказатьВопрос(ОписаниеОповещения, …)` + экспортная процедура-продолжение. Ответ сравниваем с `КодВозвратаДиалога.Да`. Вопросы — только на клиенте, не внутри записи и транзакции.

Пример: команда «Очистить товары» в форме накладной очищает **данные формы** (`Объект.Товары`), услуги не трогает, документ не записывает.

## Вариант 1: `Асинх` / `Ждать`

Команда `ОчиститьТоварыСВопросом`, кнопка в панели таблицы товаров:

```1C
&НаКлиенте
Асинх Процедура ОчиститьТоварыСВопросом(Команда)

	Если Объект.Товары.Количество() = 0 Тогда
		Сообщить("Таблица товаров уже пустая");
		Возврат;
	КонецЕсли;

	Ответ = Ждать ВопросАсинх("Удалить все строки товаров?", РежимДиалогаВопрос.ДаНет);
	Если Ответ <> КодВозвратаДиалога.Да Тогда
		Возврат;
	КонецЕсли;

	Объект.Товары.Очистить();
	ПересчитатьИтогТоваров();
	Модифицированность = Истина;

КонецПроцедуры
```

- `&НаКлиенте` — над объявлением, `Асинх` — перед словом `Процедура`.
- `ВопросАсинх` возвращает **Обещание**; `Ждать` приостанавливает продолжение метода до ответа (интерфейс не блокируется).
- Без `Ждать` в `Ответ` окажется обещание, а не нажатая кнопка.
- `Ответ <> Да` охватывает все неподтверждённые исходы.

Доступность `ВопросАсинх` проверяем в Синтакс-помощнике с учётом режима совместимости. Подробнее — [материал 1С об асинхронном синтаксисе](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Standards/Enhancements_to_1C_Enterprise_language_syntax_for_asynchronous_functions__synchronous_asynchrony/?language=en) и [[02. Программирование/13. Асинхронность|13. Асинхронность]].

## Вариант 2: `ОписаниеОповещения`

Встречается во всех существующих конфигурациях:

```1C
&НаКлиенте
Процедура ОчиститьТоварыСОповещением(Команда)

	Если Объект.Товары.Количество() = 0 Тогда
		Возврат;
	КонецЕсли;
	Оповещение = Новый ОписаниеОповещения("ПослеВопросаОбОчистке", ЭтотОбъект);
	ПоказатьВопрос(Оповещение, "Удалить все строки товаров?", РежимДиалогаВопрос.ДаНет);
	// Здесь ответа ещё НЕТ — ничего не очищаем

КонецПроцедуры

&НаКлиенте
Процедура ПослеВопросаОбОчистке(Ответ, ДополнительныеПараметры) Экспорт

	Если Ответ <> КодВозвратаДиалога.Да Тогда
		Возврат;
	КонецЕсли;
	Объект.Товары.Очистить();
	ПересчитатьИтогТоваров();
	Модифицированность = Истина;

КонецПроцедуры
```

`ПоказатьВопрос` возвращает управление сразу — продолжение только в процедуре оповещения. В готовой форме оставляем один вариант.

| | `Асинх`/`Ждать` | `ОписаниеОповещения` |
| --- | --- | --- |
| Код | Последовательный, легко читать | Разбит на две процедуры |
| Платформа | 8.3.18+ и подходящий режим совместимости | Все версии 8.3 |
| Где встречается | Новый код | Типовые конфигурации, старый код |

> [!warning] Состояние формы меняется, пока ждём
> Пока открыт вопрос, данные формы могут измениться. Не сохраняем текущую строку в переменную «до вопроса» без повторной проверки после ответа. Для удаления одной строки передаём её идентификатор и после ответа проверяем, что строка ещё есть.

Вопрос — клиентское взаимодействие. В серверных методах, `&НаСервереБезКонтекста` и обработчиках записи вопросов не задаём: серверная проверка отказывает с сообщением, а подтверждение спрашиваем **до** запуска операции.

## Проверка

1. Пустая таблица → сообщение, вопроса нет.
2. Две строки + услуга → «Нет» → всё на месте.
3. «Да» → товаров 0, `ИтогТоваров` = 0, услуга сохранилась, документ не записан.

| Симптом | Проверить |
| --- | --- |
| `Ждать` не распознаётся | Версия платформы, режим совместимости, `Асинх` |
| Оповещение не вызывается | Имя процедуры и `Экспорт` |
| Данные исчезли до ответа | Очистка стоит сразу после `ПоказатьВопрос` |

> [!question]- Проверь себя
> 1. Что будет в `Ответ`, если убрать `Ждать`?
> 2. Почему после `ПоказатьВопрос(...)` нельзя сразу очищать таблицу?
> 3. Можно ли задать вопрос в `ПередЗаписью` модуля объекта?
>
> > [!success]- Ответы
> > 1. Объект `Обещание`, а не код ответа.
> > 2. Метод не ждёт ответа — продолжение в процедуре оповещения.
> > 3. Нет: модуль объекта выполняется на сервере, вопросы — только на клиенте.
