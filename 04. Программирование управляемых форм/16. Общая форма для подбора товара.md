> [!abstract] Коротко
> **Общая форма** (`Общие → Общие формы`) не привязана к объекту и открывается откуда угодно: `ОткрытьФорму("ОбщаяФорма.Имя")`. Создаём окно подбора: реквизит `ВыбранныйТовар`, входной параметр `НачальныйТовар`, две команды. Результат возвращаем **`Закрыть(Значение)`**; отмена — `Закрыть()` без значения.

| Имя | Что это |
| --- | --- |
| `ПодборТовараУчебный` | Общая форма |
| `НачальныйТовар` | Параметр открытия |
| `ВыбранныйТовар` | Реквизит формы, связанный с полем |

Тип параметра и реквизита — `СправочникСсылка.Номенклатура` (ссылка, а не строка с наименованием).

## Создаём форму

![[УФ-22-Конструктор-общей-формы.png]]

*Конструктор общих форм: тип «Произвольная форма», имя `ПодборТовараУчебный`, синоним «Подбор товара».*

1. **Общие → Общие формы → Добавить**, произвольная управляемая форма.
2. **Реквизиты → Добавить** `ВыбранныйТовар`, тип `СправочникСсылка.Номенклатура`. Основным его не делаем.
3. Перетаскиваем в **Элементы**, заголовок «Товар», путь `ВыбранныйТовар`.

![[УФ-23-Общая-форма-подбора.png]]

*Редактор `ПодборТовараУчебный`: реквизит `ВыбранныйТовар`, поле в дереве элементов и его «ПутьКДанным».*

## Входной параметр

**Параметры → Добавить** `НачальныйТовар`, тот же тип, необязательный:

![[УФ-24-Параметр-общей-формы.png]]

*Вкладка «Параметры»: `НачальныйТовар`.*

```1C
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Параметры.Свойство("НачальныйТовар") Тогда
		ВыбранныйТовар = Параметры.НачальныйТовар;
	КонецЕсли;
КонецПроцедуры
```

Поле связываем с реквизитом, а не с `Параметры.НачальныйТовар`. Начальные данные готовим при создании — см. [рекомендацию 1С](https://its.1c.ru/db/content/v8std/src/500/i8100487.htm).

## Команды

| Имя | Заголовок | Действие |
| --- | --- | --- |
| `ПодтвердитьВыбор` | Добавить в накладную | Закрыть с результатом |
| `ОтменитьПодбор` | Отмена | Закрыть без результата |

```1C
&НаКлиенте
Процедура ПодтвердитьВыбор(Команда)

	Если НЕ ЗначениеЗаполнено(ВыбранныйТовар) Тогда
		Сообщить("Выберите товар");
		Возврат;                 // форма остаётся открытой
	КонецЕсли;
	Закрыть(ВыбранныйТовар);     // результат уйдёт в оповещение о закрытии

КонецПроцедуры

&НаКлиенте
Процедура ОтменитьПодбор(Команда)
	Закрыть();                   // результат = Неопределено
КонецПроцедуры
```

Передачу результата выполняет метод `Закрыть`, а не имя команды.

## Быстрая проверка

Временная команда в форме накладной:

```1C
&НаКлиенте
Процедура ОткрытьПодборДляПроверки(Команда)
	ОткрытьФорму("ОбщаяФорма.ПодборТовараУчебный");
КонецПроцедуры
```

Подтверждение пустого поля оставляет окно открытым, заполненного — закрывает, «Отмена» — закрывает. Ничего не записывается. Получателя результата сделаем в теме 17.

| Симптом | Причина |
| --- | --- |
| «Форма не найдена» | `ОбщаяФорма` в единственном числе + точное имя |
| Нет начального значения | Тип параметра, присваивание, путь поля |
| Кнопка не работает | Не назначено «Действие» команды |
| Окно закрылось, строки нет | Нет обработчика закрытия у вызывающей формы — тема 17 |

> [!question]- Проверь себя
> 1. Чем общая форма отличается от формы документа?
> 2. Как форма передаёт результат вызвавшему коду?
> 3. Почему поле связано с реквизитом, а не с параметром?
>
> > [!success]- Ответы
> > 1. Не принадлежит объекту, открывается из любого места и не имеет основного реквизита-объекта.
> > 2. `Закрыть(Результат)` — значение получает обработчик оповещения о закрытии.
> > 3. Параметр — входные данные открытия; рабочее значение, которое меняет пользователь, хранит реквизит.
