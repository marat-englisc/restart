> [!abstract] Коротко
> Законченный алгоритм пересчёта: две общие процедуры — `ПересчитатьСтрокуТоваров(Строка)` и `ПересчитатьИтогТоваров()` — вызываются из `ПриИзменении` количества и цены, из `ПослеУдаления` таблицы, при открытии и из команды полного пересчёта. Сначала строка, потом итог. Округляем каждую строку, затем складываем.

> [!warning] Итог только по товарам
> `ИтогТоваров` — реквизит **формы** (Число 15,2). Не присваиваем его в `Объект.ИтоговаяСумма`: там ещё услуги.

## Общие процедуры

```1C
&НаКлиенте
Процедура ПересчитатьСтрокуТоваров(СтрокаТовара)

	Если СтрокаТовара = Неопределено Тогда
		Возврат;
	КонецЕсли;
	СтрокаТовара.Сумма = Окр(СтрокаТовара.Количество * СтрокаТовара.Цена, 2);

КонецПроцедуры

&НаКлиенте
Процедура ПересчитатьИтогТоваров()

	ИтогТоваров = Объект.Товары.Итог("Сумма");

КонецПроцедуры
```

Первой процедуре можно передать и текущую строку, и строку цикла. `Итог()` складывает готовые суммы и для пустой таблицы даёт 0 — формулу `Количество * Цена` он не применяет.

## Изменение количества и цены

```1C
&НаКлиенте
Процедура ТоварыКоличествоПриИзменении(Элемент)
	ПересчитатьСтрокуТоваров(Элементы.Товары.ТекущиеДанные);
	ПересчитатьИтогТоваров();
КонецПроцедуры

&НаКлиенте
Процедура ТоварыЦенаПриИзменении(Элемент)
	ПересчитатьСтрокуТоваров(Элементы.Товары.ТекущиеДанные);
	ПересчитатьИтогТоваров();
КонецПроцедуры
```

## Удаление строки

Выбираем **саму таблицу** `Товары` → События → **ПослеУдаления** (клиент):

```1C
&НаКлиенте
Процедура ТоварыПослеУдаления(Элемент)
	ПересчитатьИтогТоваров();
КонецПроцедуры
```

Именно **после**: в `ПередУдалением` строка ещё в коллекции. Для собственной команды удаления из темы 09 вызываем `ПересчитатьИтогТоваров()` сразу после `Удалить`.

## Открытие формы

В `ПриСозданииНаСервере` уже есть `ИтогТоваров = Объект.Товары.Итог("Сумма");` — клиентскую процедуру оттуда вызвать нельзя. Для клиентского этапа дополняем `ПриОткрытии`:

```1C
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	ПересчитатьИтогТоваров();
КонецПроцедуры
```

При открытии **складываем** существующие суммы, но не пересчитываем строки: просто открыв исторический документ, мы не должны менять его данные.

## Команда «Пересчитать товары»

```1C
&НаКлиенте
Процедура ПересчитатьВсеТовары(Команда)

	Для Каждого СтрокаТовара Из Объект.Товары Цикл
		ПересчитатьСтрокуТоваров(СтрокаТовара);
	КонецЦикла;
	ПересчитатьИтогТоваров();     // один раз после цикла
	Модифицированность = Истина;

КонецПроцедуры
```

Обязательный пересчёт при записи добавим на сервере в [[13. Запись из формы и события записи]]. Когда формула стабилизируется, её можно вынести в общий модуль «Клиент + Сервер» ([[02. Программирование/26. Общие модули и контекст выполнения|26. Общие модули]]).

## Контрольный пример

| Строка | Количество | Цена | Сумма |
| --- | ---: | ---: | ---: |
| Первая | 2 | 150 | 300 |
| Вторая | 3 | 100 | 300 |

Итог **600** → количество первой строки = 4 → её сумма 600, итог **900** → удаляем вторую строку → **600** → удаляем последнюю → **0**.

| Симптом | Проверить |
| --- | --- |
| Строка меняется, итог — нет | Вызов `ПересчитатьИтогТоваров()` |
| После удаления итог старый | Событие `ПослеУдаления` у таблицы |
| Поле пустое | Путь поля `ИтогТоваров` |

> [!question]- Проверь себя
> 1. Почему итог считают после пересчёта строки, а не до?
> 2. Почему пересчёт при удалении — в `ПослеУдаления`?
> 3. Почему при открытии не пересчитываем суммы строк?
>
> > [!success]- Ответы
> > 1. Итог складывает суммы строк — сначала должна обновиться изменённая.
> > 2. В `ПередУдалением` строка ещё в коллекции.
> > 3. Открытие документа не должно менять его сохранённые данные.
