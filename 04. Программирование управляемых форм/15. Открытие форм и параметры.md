> [!abstract] Коротко
> Форму открывают на клиенте `ОткрытьФорму("ПолноеИмяФормы", Параметры)`. Стандартные параметры: **`Ключ`** — ссылка на существующий объект, **`ЗначенияЗаполнения`** — структура начальных значений нового объекта. Связанный объект проще открыть `ОткрытьЗначение(Ссылка)`. Свои параметры объявляют на вкладке «Параметры» формы и читают в `ПриСозданииНаСервере`.

## Имя формы

| Имя | Что откроется |
| --- | --- |
| `"Документ.РасходнаяНакладная.Форма.ФормаДокумента"` | Конкретная форма по имени |
| `"Документ.РасходнаяНакладная.ФормаОбъекта"` | Основная форма объекта |
| `"Документ.РасходнаяНакладная.ФормаСписка"` | Основная форма списка |
| `"ОбщаяФорма.ПодборТовараУчебный"` | Общая форма |

## Открыть существующий документ — `Ключ`

```1C
&НаКлиенте
Процедура ОткрытьСохраненнуюНакладную(Команда)

	Если НЕ ЗначениеЗаполнено(Объект.Ссылка) Тогда
		Сообщить("Сначала запишите накладную");
		Возврат;
	КонецЕсли;

	ОткрытьФорму("Документ.РасходнаяНакладная.Форма.ФормаДокумента",
		Новый Структура("Ключ", Объект.Ссылка));

КонецПроцедуры
```

В `Ключ` передаём **ссылку**, а не номер или `ДокументОбъект`. Если форма этого документа уже открыта, платформа её активирует — второе окно не создаётся.

## Открыть связанный объект

```1C
&НаКлиенте
Процедура ОткрытьПокупателяУчебно(Команда)
	Если ЗначениеЗаполнено(Объект.Покупатель) Тогда
		ОткрытьЗначение(Объект.Покупатель);   // основная форма по типу ссылки
	КонецЕсли;
КонецПроцедуры
```

*Из накладной открыта карточка покупателя «Курьер».*

## Новый документ с начальными значениями — `ЗначенияЗаполнения`

```1C
&НаКлиенте
Процедура СоздатьНакладнуюДляПокупателя(Команда)

	Если НЕ ЗначениеЗаполнено(Объект.Покупатель) Тогда
		Возврат;
	КонецЕсли;

	НачальныеЗначения = Новый Структура("Покупатель", Объект.Покупатель);
	ОткрытьФорму("Документ.РасходнаяНакладная.Форма.ФормаДокумента",
		Новый Структура("ЗначенияЗаполнения", НачальныеЗначения));

КонецПроцедуры
```

Две вложенные структуры: `ЗначенияЗаполнения` — стандартный параметр формы, внутри — значения реквизитов. Параметр `"Покупатель"` в корне не сработает. Откроется **новая незаписанная** накладная, товары не копируются.

> [!warning] Что влияет на заполнение
> У реквизита должно быть включено **«Заполнять из данных заполнения»**. Если в модуле объекта есть `ОбработкаЗаполнения`, она может задавать свои правила или отключать стандартную обработку. См. [руководство 1С, 5.6.11](https://1c-dn.com/library/tutorials/1c_enterprise_developer_guide_8_3_27/?sphrase_id=1808293).

## Собственные параметры формы

Объявляются на вкладке **Параметры** редактора — это отдельный список, не реквизиты:

![[УФ-13-Параметры-формы.png]]

*Вкладка «Параметры» редактора управляемой формы.*

| Имя | Где | Назначение |
| --- | --- | --- |
| `НачальныйТовар` | Параметр общей формы | Входное значение при открытии |
| `ВыбранныйТовар` | Реквизит общей формы | Рабочее значение в окне |

Открытие (полностью — в теме 17):

```1C
ОткрытьФорму("ОбщаяФорма.ПодборТовараУчебный",
	Новый Структура("НачальныйТовар", СтрокаТовара.Товар));
```

Чтение в открываемой форме:

```1C
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Параметры.Свойство("НачальныйТовар") Тогда
		ВыбранныйТовар = Параметры.НачальныйТовар;
	КонецЕсли;
КонецПроцедуры
```

Параметры читаем **при создании** и, если нужно дальше, сохраняем в реквизит — см. [пример 1С](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/User_forms/How_to_open_a_user_form_via_programming_giving_the_form_a_parameter_while_doing_so/?language=en).

> [!warning] `ОткрытьФорму` не ждёт пользователя
> Код после `ОткрытьФорму()` выполняется сразу, до выбора в открытом окне. Результат получают через оповещение о закрытии — [[17. Выбор и возврат результата]].

## Проверка

1. Незаписанная накладная → «открыть сохранённую» → сообщение.
2. Записанная → открывается (или активируется) по ссылке.
3. «Покупатель» → карточка выбранного контрагента.
4. «Создать для покупателя» → новая накладная с тем же покупателем, без товаров; закрытие без записи ничего не создаёт.

| Симптом | Проверить |
| --- | --- |
| «Форма не найдена» | Полное имя формы |
| Открылся новый документ вместо существующего | Параметр `Ключ`, непустая ссылка |
| Покупатель не подставился | Вложенность `ЗначенияЗаполнения`, свойство реквизита, `ОбработкаЗаполнения` |

> [!question]- Проверь себя
> 1. Каким параметром открыть существующий документ?
> 2. Почему `Новый Структура("Покупатель", …)` в корне параметров не заполнит покупателя?
> 3. Где читать собственный параметр формы?
>
> > [!success]- Ответы
> > 1. `Ключ` со ссылкой на документ.
> > 2. Для заполнения нужен стандартный параметр `ЗначенияЗаполнения`, внутри которого структура значений.
> > 3. В `ПриСозданииНаСервере` через `Параметры`.
