> [!abstract] Коротко
> Расположение элементов задаёт **дерево**: обычные **группы** объединяют поля (вертикально или горизонтально), группа **Страницы** со вложенными **Страница** раскладывает блоки по вкладкам. Группы меняют только интерфейс — данные остаются на месте. Для размещения код не нужен.

## Дерево определяет вложенность

![[УФ-05-Дерево-элементов.png]]

*Дерево элементов формы: колонки `ТоварыТовар`, `ТоварыКоличество`… вложены в таблицу `Товары`.*

Переносим таблицу — переносится весь её блок; переносим колонку — меняется устройство таблицы. Перед перетаскиванием проверяем, **что именно** выделено.

> [!warning] Важно
> Создание страницы не создаёт табличную часть, перенос таблицы не меняет `Объект.Товары`. Группы — только интерфейс.

## Группа шапки

Если подходящей группы нет:

1. Корень дерева → **ПКМ → Добавить → Группа — обычная группа**.
2. Имя `ГруппаШапкаУчебная`, заголовок «Данные накладной», **Группировка: Вертикальная**.
3. Переносим в неё **существующие** поля номера, даты, покупателя (не создаём новые!) — их ПутьКДанным сохранится.

Два поля рядом — вложенная группа с **горизонтальной** группировкой (например, номер и дата).

## Страницы товаров и услуг

1. После шапки: **Добавить → Группа — Страницы**, имя `СтраницыСоставУчебные`.
2. Внутри: **Группа — Страница** `СтраницаТоварыУчебная` (заголовок «Товары») и `СтраницаУслугиУчебная` («Услуги»).
3. Таблицу `Товары` и поле `ИтогТоваров` — на первую страницу, таблицу `Услуги` — на вторую.

```text
Форма
├─ ГруппаШапкаУчебная
├─ СтраницыСоставУчебные
│  ├─ СтраницаТоварыУчебная
│  │  ├─ Товары
│  │  │  └─ колонки…
│  │  └─ ИтогТоваров
│  └─ СтраницаУслугиУчебная
│     └─ Услуги
└─ общий итог документа (вне страниц — виден всегда)
```

**Имя** нужно для кода, **заголовок** видит пользователь. Используем понятные идентификаторы без пробелов; обязательного `snake_case` у платформы нет.

`ИтогТоваров` относится только к товарам — он на странице товаров. Общий итог документа оставляем вне страниц и **не** меняем его путь на `ИтогТоваров`.

## Группы в коде

Код для размещения не нужен, но к группе можно обратиться по имени:

```1C
Элементы.ГруппаШапкаУчебная.Видимость = Истина;
```

Поэтому имя группы должно быть уникальным и осмысленным.

## Проверка

`Ctrl+S` → `F7` → открываем накладную заново:
1. Поля шапки на месте и связаны с данными.
2. На вкладке «Товары» — четыре колонки и итог; на «Услугах» — таблица услуг.
3. Общий итог документа не исчез.
4. При изменении размера окна форма остаётся удобной.

| Симптом | Проверить |
| --- | --- |
| Пустая вкладка | Есть ли элементы **внутри** страницы |
| Вместо вкладок — обычный блок | Вид родительской группы — «Страницы» |
| Пропали колонки | Не перенесли ли колонку вместо таблицы |

> [!question]- Проверь себя
> 1. Перенесли таблицу `Услуги` на страницу. Изменилась ли табличная часть документа?
> 2. Как расположить номер и дату в одной строке?
> 3. Почему общий итог лучше держать вне страниц?
>
> > [!success]- Ответы
> > 1. Нет, изменилось только размещение элемента.
> > 2. Поместить их в обычную группу с горизонтальной группировкой.
> > 3. Он виден при переключении между вкладками.
