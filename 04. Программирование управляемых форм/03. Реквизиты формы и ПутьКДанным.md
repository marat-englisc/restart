> [!abstract] Коротко
> Кроме `Объект`, у формы могут быть **собственные реквизиты** — временные данные окна (итог, флажок, значение для отбора). В базу они **не записываются**. Путь к ним — без `Объект.`: `ИтогТоваров`. В коде значение присваиваем реквизиту (`ИтогТоваров = 600`), а оформление меняем у элемента (`Элементы.ИтогТоваров.ТолькоПросмотр = Истина`).

## Реквизит объекта или реквизит формы

![[УФ-03-Реквизиты-объекта.png]]

*Реквизиты формы накладной: `Объект` раскрыт — внутри поля документа и табличные части.*

| Данные | Где определены | При записи документа |
| --- | --- | --- |
| `Объект.Покупатель` | Реквизит документа в конфигурации | Записывается |
| `ИтогТоваров` | Дополнительный реквизит формы | **Не записывается** |

Нужно сохранять значение — добавляем реквизит **документу**. Нужно временное значение для окна — реквизит **формы**.

## Создаём `ИтогТоваров`

1. На вкладке **Реквизиты** выделяем **верхний уровень** (рядом с `Объект`, не внутри).
2. **Добавить** → имя `ИтогТоваров`, тип **Число (15, 2)**, заголовок «Итого товаров».
3. Основным остаётся `Объект`.

## Выводим на форму

1. Перетаскиваем `ИтогТоваров` в дерево элементов — после таблицы `Товары`.
2. Проверяем у поля: **Имя** = `ИтогТоваров`, **ПутьКДанным** = `ИтогТоваров`.
3. Включаем **ТолькоПросмотр** — итог считает программа.

![[УФ-04-Путь-к-данным.png]]

*Свойства элемента: «ПутьКДанным» связывает поле с реквизитом. Для нашего поля путь — `ИтогТоваров`, без `Объект.`.*

```1C
Объект.Покупатель  // данные документа на форме
ИтогТоваров        // собственный реквизит формы
```

## Присваиваем значение

```1C
// Внутри процедуры модуля этой формы
ИтогТоваров = Объект.Товары.Итог("Сумма");
```

- `Объект.Товары` — строки товаров в данных формы.
- `Итог("Сумма")` — сумма колонки по всем строкам.
- Связанное поле покажет новое значение автоматически.

Этот код **суммирует уже рассчитанные** `Сумма`, но не пересчитывает строки — это в [[10. Пересчёт строк и итога товаров]]. Строку поместим в обработчик команды ([[06. Команды формы и кнопки]]) и создания формы ([[07. Создание, открытие и закрытие формы]]).

## Частые ошибки

| Неверно | Почему | Верно |
| --- | --- | --- |
| `Объект.ИтогТоваров` | У документа нет такого реквизита | `ИтогТоваров` |
| `Элементы.ИтогТоваров = 600` | В `Элементы` — поле, а не число | `ИтогТоваров = 600` |
| ПутьКДанным `Объект.ИтогТоваров` | «Поле объекта не обнаружено» | `ИтогТоваров` |
| `ТолькоПросмотр` у таблицы | Блокирует всю таблицу | `ТолькоПросмотр` у поля итога |

Одинаковые имена реквизита и элемента не делают их одним объектом. Подробнее — [разбор 1С о реквизитах и элементах формы](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Controls/Attributes_and_items_of_the_form__referring_to_them_from_the_module_of_the_form/?language=en).

## Проверка

`Ctrl+S` → `F7` → открываем накладную: поле «Итого товаров» видно и недоступно для ввода. Пока обработчика нет, значение 0 — это нормально.

> [!question]- Проверь себя
> 1. Записался ли `ИтогТоваров` в документ после «Записать»?
> 2. Чем `ИтогТоваров = 0` отличается от `Элементы.ИтогТоваров.Видимость = Ложь`?
> 3. Почему путь к реквизиту формы не начинается с `Объект.`?
>
> > [!success]- Ответы
> > 1. Нет, это реквизит формы, а не документа.
> > 2. Первое меняет данные, второе — свойство элемента интерфейса.
> > 3. Реквизит лежит на верхнем уровне формы, а не внутри `Объект`.
