> [!abstract] Коротко
> Прежде чем создавать форму — проверяем, нет ли уже **основной формы документа**. Если нет: **Формы → Добавить → Форма документа**, назначаем основной, выбираем реквизиты. Затем проверяем пути к данным элементов, обновляем БД (`F7`) и открываем документ заново.

## Сначала — существующие формы

1. **Документы → РасходнаяНакладная** → двойной щелчок → вкладка **Формы**.
2. Смотрим, какая форма указана **основной формой документа**.
3. Если она есть — работаем в ней.

![[УФ-01-Формы-документа.png]]

*Вкладка «Формы» расходной накладной в «1С:Купец»: основные формы документа, списка и выбора.*

> [!warning] Не плодите формы
> Если создать вторую форму и писать код в неё, команда «Открыть» по-прежнему будет открывать основную. Сначала изучаем существующую форму.

## Если формы ещё нет

1. В узле **Формы** документа: **ПКМ → Добавить**.
2. Тип — **Форма документа** (не списка и не выбора), имя `ФормаДокумента`.
3. Флажок **«Назначить форму основной»**.
4. Отмечаем реквизиты: номер, дата, покупатель, товары, услуги и всё, что нужно документу.
5. **Готово**. Справа появится основной реквизит `Объект`, слева — элементы для его полей.
6. На вкладке «Формы» документа проверяем, что форма стала основной.

## Проверяем пути к данным

| Элемент | ПутьКДанным |
| --- | --- |
| Покупатель | `Объект.Покупатель` |
| Таблица товаров | `Объект.Товары` |
| Колонки | `Объект.Товары.Товар`, `.Количество`, `.Цена`, `.Сумма` |

Имена элементов могут отличаться (колонка количества обычно `ТоварыКоличество`) — они понадобятся при настройке событий. Существующие элементы не переименовываем: на них может ссылаться код.

Если реквизит есть в документе, но не на форме, — перетаскиваем его из `Объект` в дерево элементов.

## Модуль формы

Вкладка **Модуль** внизу редактора — отдельный модуль этой формы. Код модуля объекта документа здесь не появится. Обработчик команды будет выглядеть так:

```1C
&НаКлиенте
Процедура ПоказатьИтогТоваров(Команда)
	// Действие кнопки
КонецПроцедуры
```

Сейчас его **не вставляем**: процедура без связи с командой кнопку не создаёт ([[06. Команды формы и кнопки]]).

## Запуск

1. `Ctrl+S` → `F7` (обновить конфигурацию БД).
2. Если мешает открытый клиент — закрываем его и повторяем `F7`.
3. `F5` → торговый раздел → список накладных → **Создать** или открыть существующую.

Проверяем расположение полей без записи и проведения.

> [!warning] Открытая форма показывает старую версию
> После `F7` уже открытое окно может показывать прежнее состояние. Закрываем его и открываем заново.

## Если результат отличается

| Симптом | Причина |
| --- | --- |
| Открывается прежняя форма | Не назначена основной или не обновлена БД |
| Нет нового поля документа | В собственной форме его надо разместить вручную |
| Нет команды документа в разделе | Документ не включён в подсистему / командный интерфейс |
| Форма похожа на список | Создан не тот тип формы |

> [!question]- Проверь себя
> 1. Документ открывается не той формой, в которую вы писали код. Почему?
> 2. Добавили реквизит в документ. Появится ли он в собственной форме сам?
>
> > [!success]- Ответы
> > 1. Ваша форма не назначена основной.
> > 2. Нет, его нужно перетащить в дерево элементов.
