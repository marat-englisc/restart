> [!abstract] Коротко
> Практика по темам 15–24: подбор товара через общую форму с возвратом результата, учебный список накладных с собственным отбором по покупателю и общая форма с таблицей результата запроса. Проверяем отмену, повторное открытие и совместную работу отборов.

Выполняется после [[26. Практика по форме документа]]. Созданные ранее формы, реквизиты и команды используем повторно.

## Шаг 1. Форма подбора

По [[16. Общая форма для подбора товара]]: `ПодборТовараУчебный`, реквизит `ВыбранныйТовар`, параметр `НачальныйТовар`, команды «Добавить в накладную» (`Закрыть(ВыбранныйТовар)`) и «Отмена» (`Закрыть()`). В общей форме нет `Объект.Товары` — она только возвращает значение.

## Шаг 2. Подбор из накладной

По [[17. Выбор и возврат результата]] — команда `ПодобратьТоварУчебно` и экспортная `ПослеЗакрытияПодбораТовара`.

| Проверяем | Ожидаем |
| --- | --- |
| Имя формы | `ОбщаяФорма.ПодборТовараУчебный` |
| Параметр | `НачальныйТовар` |
| Владелец | `ЭтотОбъект` |
| Процедура оповещения | `ПослеЗакрытияПодбораТовара`, `Экспорт` |

## Шаг 3. Все исходы подбора

| Исходное состояние | Действие | Результат |
| --- | --- | --- |
| Пустая таблица | «Отмена» | 0 строк |
| Пустая таблица | Выбрать и подтвердить | 1 строка, количество 1, цена 0 |
| Есть текущая строка | Открыть подбор | Начальный товар из строки |
| Есть текущая строка | Подтвердить | Добавлена ещё одна строка |
| Любая | Закрыть крестиком | Строк не прибавилось |
| Товар не выбран | «Добавить в накладную» | Сообщение, окно открыто |

Строка добавилась дважды — проверьте, не подключены ли одновременно результат закрытия и `ОповеститьОВыборе`.

## Шаг 4. Список с собственным фильтром

По [[19. Форма списка и динамический список|темам 19]] и [[20. Программный отбор списка|20]]: `ФормаСпискаУчебная`, `Список` (динамический), поле `ПокупательОтбор` с серверной установкой **своего** элемента отбора. Открытие из накладной:

```1C
&НаКлиенте
Процедура ОткрытьУчебныйСписок(Команда)
	ОткрытьФорму("Документ.РасходнаяНакладная.Форма.ФормаСпискаУчебная");
КонецПроцедуры
```

Чтобы передать начального покупателя, нужен объявленный параметр формы и его чтение при создании — одноимённый реквизит сам не заполнится.

## Шаг 5. Отбор и выбранная запись

1. Без покупателя — все доступные накладные.
2. А → только А; Б → только Б (не пересечение).
3. Очистили поле — снят только наш отбор.
4. Пользовательский отбор по периоду сохраняется при смене покупателя.
5. Двойной щелчок открывает документ строки, а не новый.

## Шаг 6. Статическая таблица

По [[24. Загрузка таблицы формы на сервере]]: `ТоварыУчебные`, до 100 товаров запросом в реквизит `Результаты`. Изменения справочника появятся только после «Обновить» — в отличие от динамического списка.

## Готово, если

Подбор передаёт ссылку и обрабатывает отмену; список меняет один свой отбор, сохраняя остальные; документ открывается по ссылке; запрос загружает ограниченную таблицу без `ТаблицаЗначений` на клиенте.

**Дополнительно:** верните из подбора структуру `Товар` + `Количество` (с проверкой `Количество > 0` в дочерней форме) и проверьте тип и свойства результата в накладной. Меняйте «контракт» сразу у обеих форм.
