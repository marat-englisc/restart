> [!abstract] Коротко
> `Объект` в форме — **данные формы**, у них нет экспортных методов модуля объекта. Чтобы вызвать метод объекта для **текущих, ещё не записанных** данных: на сервере `РеквизитФормыВЗначение("Объект")` → метод → `ЗначениеВРеквизитФормы(Объект, "Объект")`. `Объект.Ссылка.ПолучитьОбъект()` прочитает **сохранённую** версию — это другой источник.

## Какие значения бывают

| Значение | Что это |
| --- | --- |
| `Объект` в модуле формы | Данные формы текущего окна |
| `Объект.Ссылка` | Ссылка на документ в базе (у нового — пустая) |
| `Документы.РасходнаяНакладная.СоздатьДокумент()` | Новый прикладной объект (сервер) |
| `Ссылка.ПолучитьОбъект()` | Объект, прочитанный **из базы** (сервер) |
| `РеквизитФормыВЗначение("Объект")` | Объект из **текущих данных формы** (сервер, `&НаСервере`) |

Данные формы нужны, чтобы документ можно было редактировать в тонком и веб-клиенте, где прикладного объекта нет. При стандартной записи их преобразует платформа, в своём алгоритме — мы явно. См. [пособие 1С о типах данных формы](https://kb.1ci.com/1C_Enterprise_Platform/Tutorials/Practical_developer_guide_8.3/Lesson_27._Form_development_techniques/Form_data_types/).

## Посмотрим типы

```1C
&НаКлиенте
Процедура ПоказатьТипыДанных(Команда)
	Сообщить(ОписаниеТиповНаСервере());
КонецПроцедуры

&НаСервере
Функция ОписаниеТиповНаСервере()
	НакладнаяОбъект = РеквизитФормыВЗначение("Объект");
	Возврат СтрШаблон("Данные формы: %1; прикладной объект: %2",
		ТипЗнч(Объект), ТипЗнч(НакладнаяОбъект));
КонецФункции
```

Ожидаем `ДанныеФормыСтруктура` и `ДокументОбъект.РасходнаяНакладная`. Нужен именно `&НаСервере` — без контекста формы `РеквизитФормыВЗначение` недоступен.

## Вызываем метод модуля объекта

Предпосылка — экспортная `ПересчитатьСуммыТоваров()` в модуле **объекта** (тема 13). Команда «Пересчитать на сервере»:

```1C
&НаКлиенте
Процедура ПересчитатьЧерезОбъект(Команда)
	ПересчитатьЧерезОбъектНаСервере();
	ПересчитатьИтогТоваров();         // реквизит формы — пересчитываем на клиенте
	Модифицированность = Истина;
КонецПроцедуры

&НаСервере
Процедура ПересчитатьЧерезОбъектНаСервере()
	НакладнаяОбъект = РеквизитФормыВЗначение("Объект");   // 1. данные формы → объект
	НакладнаяОбъект.ПересчитатьСуммыТоваров();            // 2. метод объекта
	ЗначениеВРеквизитФормы(НакладнаяОбъект, "Объект");    // 3. объект → данные формы
КонецПроцедуры
```

Три шага неразделимы: без шага 3 серверная переменная изменится, а форма — нет. Метод `РеквизитФормыВЗначение` для реквизита текущей формы рекомендует [стандарт 1С](https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_Development_Standards/Code_conventions/Using_applied_objects_and_universal_value_collections/FormAttributeToValue_and_FormDataToValue_methods/).

> [!warning] Не гоняем объект на сервер без нужды
> Пересчёт одной строки при вводе остаётся на клиенте (тема 10). Преобразование нужно, когда действительно требуется метод объекта или серверный алгоритм.

## Почему не читаем по ссылке

Накладная записана с количеством **2**, пользователь изменил на **5** и не записал:

| Способ | Что получим |
| --- | --- |
| `Объект.Ссылка.ПолучитьОбъект()` | 2 — сохранённая версия |
| `РеквизитФормыВЗначение("Объект")` | 5 — текущие данные окна |

Для обработки редактируемого документа — данные формы. У нового документа ссылки нет вовсе. Не заменяем `Объект` данными произвольно прочитанного документа — потеряем несохранённые изменения.

## Где запись

В примере нет `НакладнаяОбъект.Записать()`: команда меняет данные формы, а записывает пользователь стандартной командой (порядок событий — тема 13). Ручная запись преобразованного объекта — другой сценарий, где разработчик сам отвечает за синхронизацию формы, блокировки и ошибки.

## Проверка

1. Новая накладная: количество 2, цена 150 → «Пересчитать на сервере» → сумма и итог **300**.
2. Количество 4, не записывая → команда → расчёт по **4**, а не по данным базы.
3. Записываем, переоткрываем — итог соответствует строкам.

| Симптом | Проверить |
| --- | --- |
| «Метод объекта не обнаружен» | `Экспорт`, модуль объекта (не формы), обновление БД, преобразование |
| После команды на экране старые значения | `ЗначениеВРеквизитФормы` и пересчёт `ИтогТоваров` |

> [!question]- Проверь себя
> 1. Почему `Объект.ПересчитатьСуммыТоваров()` не работает?
> 2. Какая директива нужна методу с `РеквизитФормыВЗначение("Объект")`?
> 3. Чем опасно `ПолучитьОбъект()` по ссылке в открытой форме?
>
> > [!success]- Ответы
> > 1. `Объект` — данные формы, у них нет методов модуля объекта.
> > 2. `&НаСервере` (нужен контекст формы).
> > 3. Вернётся сохранённая версия без изменений пользователя.
