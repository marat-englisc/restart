<p><code>ЧтениеXML</code> — курсор: <code>Прочитать()</code> переходит к следующему узлу (начало элемента, текст, конец элемента). Так читается файл любого размера без загрузки целиком в память.</p>
<p>Показанный читатель рассчитан только на простой формат <code>&#x3C;Товар Код="…">текст&#x3C;/Товар></code> из примера записи. Для произвольного XML одного <code>Прочитать()</code> недостаточно: текст может быть разбит на несколько узлов, а элемент — пустым или вложенным. В рабочем загрузчике накапливайте текст до соответствующего конца элемента и проверяйте атрибуты перед созданием объекта.</p>

<p><em>Контекстное меню ветки <code>XDTO-пакеты</code>: «Импорт XML-схемы…» — точка входа для схемы XSD партнёра. Для потокового чтения простого XML из начала темы импорт XSD не требуется.</em></p>
<p><code>ПрочитатьXML</code> восстанавливает значение в памяти, а не сохраняет объект в базе. После чтения нужны сопоставление ссылок, проверки и явная запись; одинаковая структура конфигураций сама по себе не гарантирует наличие объектов, на которые ссылается XML.</p>
<h2 id="правила-загрузки-данных">Правила загрузки данных</h2>

































<div class="table-wrap"><table><thead><tr><th>Правило</th><th>Почему</th></tr></thead><tbody><tr><td>Сопоставление по <strong>ключу</strong> (код, ИНН, GUID), а не по наименованию</td><td>Наименования не уникальны</td></tr><tr><td>Повторная загрузка не создаёт дубли</td><td>Сначала ищем существующий объект</td></tr><tr><td>Проверка значений до записи</td><td>Отрицательное количество, неизвестный товар</td></tr><tr><td>Порция + транзакция на порцию</td><td>Ошибка в одной записи не «роняет» всю загрузку и не держит длинную транзакцию</td></tr><tr><td>Протокол</td><td>Что загружено, что пропущено и почему</td></tr><tr><td><code>ОбменДанными.Загрузка = Истина</code> при массовой загрузке</td><td>Устанавливает признак загрузки. Прикладные проверки пропускаются, только если сами обработчики и подписки проверяют этот признак; целостность загружаемых данных обеспечивает вызывающий код</td></tr></tbody></table></div>
<p>Флаг <strong>не отключает произвольный код автоматически</strong>. Типичный обработчик сам делает ранний выход <code>Если ОбменДанными.Загрузка Тогда Возврат; КонецЕсли;</code>. Это правило и ответственность загрузчика описаны в <a href="https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_Development_Standards/Creating_and_modifying_metadata_objects/Object_event_handlers/DataExchange.Load_flag_in_object_event_handlers/" target="_blank" rel="noopener noreferrer">стандарте 1С</a>.</p>
