Печатная форма документа

Коротко

Полная печатная форма: макет с областями (Шапка, ШапкаТаблицы, Строка, Подвал) → функция модуля менеджера ПечатнаяФорма(МассивСсылок) получает данные одним запросом и выводит области в ТабличныйДокумент → команда объекта «Печать» вызывает её на сервере и показывает результат на клиенте. Поддерживаем печать нескольких документов и переносы страниц.

Опираемся на макет ПечатьНакладной из темы 24 раздела 01.

1. Макет

Документ РасходнаяНакладная → Макеты → ПечатьНакладной (табличный документ). Именованные области строк:

Исходный макет из темы 01/24 в открытой «1С:Купец»: Шапка, СтрокаТовара, Подвал, параметр итога ИтоговаяСумма. Перед кодом ниже его нужно доработать.

  1. Выделите строки 1–3 и переназначьте область Шапка; строке 4 задайте имя ШапкаТаблицы через Таблица → Имена → Назначить имя.
  2. Переименуйте область строки 5 из СтрокаТовара в Строка. Параметр подвала ИтоговаяСумма переименуйте в ИтогоСумма.
  3. Добавьте в шапку параметр Склад, в строку товара — колонку с параметром НомерСтроки; добавьте соответствующий заголовок. Если вставляете строки, проверьте границы всех областей заново.

Итоговая структура для следующей функции:

ОбластьСодержимоеПараметры ячеек
Шапка«Расходная накладная № … от …», покупатель, складНомер, Дата, Покупатель, Склад
ШапкаТаблицыЗаголовки колонок: №, Товар, Кол-во, Цена, Сумма—
СтрокаОдна строка товараНомерСтроки, Товар, Количество, Цена, Сумма
Подвал«Итого», подписиИтогоСумма

Ячейкам параметров ставим Заполнение = Параметр и имя параметра. Формат чисел задаём в свойствах ячейки (например, ЧДЦ=2).

2. Функция в модуле менеджера

ПриёмЗачем
Один запрос на все документыНе делаем запрос в цикле по ссылкам
Вложенная табличная часть Д.Товары.(…)Шапка и строки одним запросом, обход — Выборка.Товары.Выбрать()
Параметры.Заполнить(Выборка)Заполняет одноимённые параметры области — меньше кода
ПроверитьВыводСтрока не поместится — разрыв страницы и повтор заголовка таблицы
КлючПараметровПечатиПлатформа запомнит настройки печати пользователя для этой формы

Параметры страницы задаём до ПроверитьВывод: результат проверки зависит от них и доступного принтера. Для подписи, которую нельзя отрывать от последней строки, проверяем массив из строки и подвала — приём описан в примере постраничного вывода 1С.

Печать = данные документа

Итог считаем по строкам документа, а не заново по цене × количество: печать должна совпадать с тем, что записано и проведено.

3. Команда «Печать»

Документ → вкладка Команды → Добавить ПечатьНакладной:

СвойствоЗначение
ГруппаКомандная панель формы. Важное (или «Печать»)
Тип параметра командыДокументСсылка.РасходнаяНакладная
Режим использования параметраМножественный — печать нескольких выделенных в списке
Изменяет данныеНет

Модуль команды:

При множественном режиме ПараметрКоманды — массив ссылок; при одиночном — одна ссылка (тогда оборачиваем: Новый Массив + Добавить). Команда появится и в форме документа, и в списке.

Печать из формы с несохранёнными изменениями

Печать читает данные из базы. Если документ изменён, но не записан, — сначала запишите его (в типовых решениях на БСП платформа подсистемы печати предлагает это сама).

Печать в типовых конфигурациях

В решениях на БСП печатные формы подключаются через подсистему «Печать»: модуль менеджера реализует ДобавитьКомандыПечати(КомандыПечати) и Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода), а пользователь получает общее окно печати с копиями, PDF и почтой. Принцип формирования табличного документа тот же. См. 09. БСП и типовые конфигурации.

Проверка

  • Одна строка, много строк (перенос на вторую страницу, повтор заголовка), пустая табличная часть.
  • Несколько документов из списка — каждый с новой страницы.
  • Длинное наименование товара переносится в ячейке (свойство «Размещение текста: Переносить»).
  • Итог совпадает с ИтоговаяСумма документа (без услуг — если их нет в печати, это должно быть явно указано).
Проверь себя

  1. Почему данные для печати нескольких документов получают одним запросом?

  2. Что делает ОбластьСтрока.Параметры.Заполнить(ВыборкаТоваров)?

  3. Почему функция печати — в модуле менеджера, а не в модуле формы?

Ответы
  1. Запрос в цикле по ссылкам — N обращений к базе вместо одного.
  2. Заполняет параметры области значениями одноимённых полей выборки.
  3. Печать нужна из формы, из списка и из других мест; менеджер — общее место для операций над документами этого вида.
