<h2 id="вопросы-к-собеседованию">Вопросы к собеседованию</h2>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Платформа и конфигурирование</summary>
<div class="callout-body"><ol>
<li><strong>Чем конфигурация отличается от информационной базы?</strong> — Конфигурация — описание программы; ИБ — конфигурация + данные.</li>
<li><strong>Основная конфигурация и конфигурация БД?</strong> — Первую редактирует разработчик, вторую использует пользователь; переносим изменения <code>F7</code>.</li>
<li><strong>Файловый и клиент-серверный вариант?</strong> — Файл <code>1Cv8.1CD</code> или СУБД + сервер 1С; код делится на клиент/сервер в обоих.</li>
<li><strong>Справочник или документ?</strong> — Справочник — что/кто (список объектов), документ — событие во времени, может влиять на учёт.</li>
<li><strong>Перечисление или справочник?</strong> — Перечисление — фиксированный набор, задаёт разработчик; справочник пополняют пользователи.</li>
<li><strong>Регистр накопления остатков vs оборотов?</strong> — Остатки — есть остаток на дату и приход/расход; обороты — только изменения за период.</li>
<li><strong>Регистр сведений vs накопления?</strong> — Сведения хранят значения (цена), накопления — складываемые изменения (количество).</li>
<li><strong>Периодический независимый регистр сведений — ключ записи?</strong> — Период + измерения.</li>
<li><strong>Что такое проведение?</strong> — Запись документа с формированием движений в регистрах (<code>ОбработкаПроведения</code>).</li>
<li><strong>Что делает пометка удаления?</strong> — Ставит признак; удаление помеченных удаляет объект только при отсутствии ссылок.</li>
<li><strong>Владелец справочника vs ссылочный реквизит?</strong> — Владелец делает элемент подчинённым (договор без контрагента не существует), обычный реквизит — просто связь.</li>
<li><strong>Зачем подсистемы?</strong> — Разделы интерфейса и логическая группировка объектов.</li>
<li><strong>Функциональная опция?</strong> — Включает/выключает функциональность по значению (константы), без изменения конфигурации.</li>
<li><strong>Что такое расширение и зачем оно?</strong> — Отдельный слой доработок; типовая остаётся на поддержке.</li>
<li><strong><code>.cf</code>, <code>.cfe</code>, <code>.dt</code>, <code>.epf</code>?</strong> — Конфигурация; расширение; выгрузка ИБ с данными; внешняя обработка.</li>
</ol></div>
</details>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Встроенный язык</summary>
<div class="callout-body"><p>16. <strong>Процедура vs функция?</strong> — Функция возвращает значение через <code>Возврат</code>.
17. <strong>Как передаются параметры?</strong> — По ссылке; <code>Знач</code> — по значению (для коллекций копии не создаёт).
18. <strong><code>Неопределено</code>, <code>NULL</code>, пустая ссылка?</strong> — Нет значения в языке; нет значения в результате запроса; значение ссылочного типа без объекта.
19. <strong>Структура vs Соответствие?</strong> — Ключ структуры — строка-имя, соответствия — любое значение.
20. <strong>Где работает ТаблицаЗначений?</strong> — На сервере (и толстом клиенте); в управляемой форме — <code>ДанныеФормыКоллекция</code>.
21. <strong>Менеджер, ссылка, объект?</strong> — Менеджер — операции с видом; ссылка — указатель (чтение); объект — изменение и запись.
22. <strong><code>Отказ</code> vs <code>Возврат</code> в <code>ПередЗаписью</code>?</strong> — <code>Отказ = Истина</code> отменяет запись; <code>Возврат</code> только выходит из процедуры.
23. <strong>Почему нельзя <code>Записать()</code> в <code>ПередЗаписью</code>?</strong> — Рекурсия.
24. <strong>Попытка-Исключение: что нельзя?</strong> — Пустой блок <code>Исключение</code>; заменять ею обычные проверки.
25. <strong>Транзакция — шаблон?</strong> — <code>НачатьТранзакцию(); Попытка … ЗафиксироватьТранзакцию(); Исключение ОтменитьТранзакцию(); ВызватьИсключение; КонецПопытки;</code>.
26. <strong>Подписка на событие?</strong> — Общий обработчик события для нескольких объектов из общего модуля.
27. <strong>Фоновое vs регламентное задание?</strong> — Фоновое — запуск метода отдельно сейчас; регламентное — по расписанию.
28. <strong><code>Асинх</code>/<code>Ждать</code> — что делает?</strong> — Позволяет ждать результата асинхронной операции на клиенте без блокировки интерфейса; не параллелит вычисления.</p></div>
</details>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Запросы и СКД</summary>
<div class="callout-body"><p>29. <strong><code>ГДЕ</code> vs <code>ИМЕЮЩИЕ</code>?</strong> — Отбор строк до группировки / групп после.
30. <strong>Левое соединение — когда?</strong> — Нужны все строки левой таблицы, даже без пары справа (будет <code>NULL</code>).
31. <strong>Почему сумма выросла после соединения?</strong> — Справа несколько совпадений — строки размножились.
32. <strong><code>ЕСТЬNULL</code>?</strong> — Заменяет <code>NULL</code> значением.
33. <strong><code>ОБЪЕДИНИТЬ</code> vs <code>ОБЪЕДИНИТЬ ВСЕ</code>?</strong> — Первое удаляет дубли.
34. <strong>Временная таблица и пакет?</strong> — <code>ПОМЕСТИТЬ</code> + <code>;</code>; промежуточный результат для следующих запросов.
35. <strong>Виртуальные таблицы регистра накопления?</strong> — <code>Обороты</code>, <code>Остатки</code>, <code>ОстаткиИОбороты</code>; отборы — в параметры.
36. <strong>Срез последних?</strong> — Последняя запись регистра сведений не позже даты по каждому сочетанию измерений.
37. <strong>Почему запрос в цикле — плохо?</strong> — N обращений к базе; данные нужно получить одним запросом.
38. <strong><code>РАЗРЕШЕННЫЕ</code>?</strong> — Отбрасывает записи, недоступные по RLS; прав не даёт.
39. <strong>Схема СКД vs настройки?</strong> — Откуда данные и возможности / как вывести.
40. <strong>Ресурс СКД?</strong> — Поле с формулой итога по группировкам.</p></div>
</details>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Управляемые формы</summary>
<div class="callout-body"><p>41. <strong><code>Объект</code> vs <code>Элементы</code>?</strong> — Данные формы / элементы интерфейса.
42. <strong>Директивы формы?</strong> — <code>&#x26;НаКлиенте</code>, <code>&#x26;НаСервере</code>, <code>&#x26;НаСервереБезКонтекста</code>, <code>&#x26;НаКлиентеНаСервереБезКонтекста</code>.
43. <strong>Почему <code>&#x26;НаСервереБезКонтекста</code> предпочтительнее?</strong> — Не передаются данные формы.
44. <strong><code>ПриСозданииНаСервере</code> vs <code>ПриОткрытии</code>?</strong> — Сервер, подготовка данных / клиент, интерфейсные действия.
45. <strong>Как вызвать метод модуля объекта из формы?</strong> — <code>РеквизитФормыВЗначение</code> → метод → <code>ЗначениеВРеквизитФормы</code>.
46. <strong>Как открыть существующий документ / новый с заполнением?</strong> — Параметр <code>Ключ</code> / <code>ЗначенияЗаполнения</code>.
47. <strong>Как получить результат из открытой формы?</strong> — <code>Закрыть(Значение)</code> + <code>ОписаниеОповещения</code> (или <code>ОповеститьОВыборе</code>).
48. <strong>Динамический список?</strong> — Основной реквизит формы списка, читает данные порциями, отборы через компоновку.
49. <strong>Вызовется ли <code>ПриИзменении</code> при присваивании в коде?</strong> — Нет, только при интерактивном вводе.
50. <strong>Где проверять обязательные правила?</strong> — В модуле объекта (или подписке); форма — только подсказка.</p></div>
</details>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Ситуационные вопросы</summary>
<div class="callout-body"><ul>
<li><em>Документ проводится 30 секунд. С чего начнёте?</em> — Замер производительности: запросы в цикле, тяжёлые обращения через точку, отборы виртуальных таблиц, блокировки.</li>
<li><em>Пользователь видит «Недостаточно прав», администратор — нет.</em> — Роли пользователя, RLS, запросы без <code>РАЗРЕШЕННЫЕ</code>; воспроизвести под этим пользователем.</li>
<li><em>Остаток ушёл в минус.</em> — Нет контроля остатков или он без блокировки; проверить проведение и одновременные сеансы.</li>
<li><em>Нужно доработать типовую.</em> — Расширение; механизмы БСП; разметка изменений; проверка после обновления.</li>
</ul></div>
</details>
