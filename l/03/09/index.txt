<div class="callout-title">Коротко</div>
<div class="callout-body"><p><code>NULL</code> — «нет значения» в результате запроса (чаще всего при левом соединении). Проверяем <code>ЕСТЬ NULL</code> / <code>ЕСТЬ НЕ NULL</code> (не <code>= NULL</code>), заменяем <code>ЕСТЬNULL(Поле, 0)</code>. <code>NULL + 10 = NULL</code>. <code>NULL</code>, пустая ссылка, <code>0</code>, <code>""</code> и <code>Неопределено</code> — разные значения.</p></div>
</div>
<h2 id="что-означает-null">Что означает NULL?</h2>
<p><code>NULL</code> означает отсутствие значения в результате операции с данными. Типичный случай: при левом соединении для товара не нашлось строки продаж.</p>





























<div class="table-wrap"><table><thead><tr><th>Значение</th><th>Пример</th></tr></thead><tbody><tr><td><code>0</code></td><td>Число: сумма равна нулю</td></tr><tr><td><code>""</code></td><td>Пустая строка</td></tr><tr><td>Пустая ссылка</td><td>Значение ссылочного типа без выбранного объекта</td></tr><tr><td><code>NULL</code></td><td>Нет значения, например нет совпавшей строки</td></tr><tr><td><code>Неопределено</code></td><td>Отдельное значение встроенного языка; не синоним NULL</td></tr></tbody></table></div>
<h2 id="проверка-и-замена">Проверка и замена</h2>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">ГДЕ П.Номенклатура ЕСТЬ </span><span style="color:var(--shiki-token-constant)">NULL</span></span></code></pre></figure>
<p>Так найдём товары без совпавшей строки в примере левого соединения. Для обратного условия: <code>П.Номенклатура ЕСТЬ НЕ NULL</code>. Не пишем <code>= NULL</code>.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">ЕСТЬNULL(П.СуммаОборот</span><span style="color:var(--shiki-token-keyword)">,</span><span style="color:var(--shiki-token-constant)"> 0</span><span style="color:var(--shiki-foreground)">) КАК СуммаПродаж</span></span></code></pre></figure>
<p>Если сумма <code>NULL</code>, получим 0. Если она уже 0 или 500, значение сохранится. Значение замены выбираем совместимого типа.</p>
<p>У замены учитывается тип первого выражения: например, слишком длинная строка может усечься до его длины. <a href="https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Queries/Query_language/" target="_blank" rel="noopener noreferrer">Пояснение 1С о ЕСТЬNULL</a>.</p>
<p><code>ЕСТЬNULL()</code> не заменяет пустую ссылку и пустую строку. Их проверяем отдельными условиями.</p>
<h2 id="почему-пропала-строка">Почему пропала строка?</h2>
<p>После левого соединения условие <code>П.СуммаОборот > 0</code> не истинно для <code>NULL</code>, поэтому строка без продаж не пройдёт <code>ГДЕ</code>.</p>
<p>При сложении <code>NULL + 10</code> тоже получается <code>NULL</code>. Если по задаче отсутствие суммы означает ноль, сначала заменяем её через <code>ЕСТЬNULL()</code>.</p>
<p><strong>Проверка:</strong> для товара без продаж выводим рядом исходную сумму и <code>ЕСТЬNULL(Сумма, 0)</code>. Объясняем, почему значения различаются.</p>
