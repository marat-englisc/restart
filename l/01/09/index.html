Форма справочника

Коротко

Собственную форму элемента создаём, когда автоматической не хватает. Редактор формы состоит из дерева элементов (что видит пользователь), реквизитов формы (данные) и предварительного просмотра. Элемент связан с данными свойством ПутьКДанным. Группы и страницы раскладывают поля по блокам и вкладкам.

Это первое знакомство

Здесь — работа с формой мышкой в редакторе. Программирование форм подробно разобрано в разделе 04. Программирование управляемых форм.

Создание формы элемента

Открываем справочник → вкладка «Формы» → лупа у поля «Элемента»:

Вкладка «Формы» справочника и конструктор формы: выбран тип «Форма элемента справочника», флажок «Назначить форму основной».

Далее → отмечаем реквизиты, которые попадут на форму:

Выбор реквизитов: Код, Наименование, Родитель и ВидНоменклатуры.

Редактор формы

Редактор формы: слева дерево элементов, справа реквизиты (основной — Объект), внизу предварительный вид формы.

ОбластьЧто содержитПример
Элементы (слева сверху)Визуальные элементы: поля, кнопки, группы, таблицыПоле «Артикул»
Реквизиты (справа сверху)Данные, с которыми работает форма. Основной реквизит Объект — сам элемент справочникаОбъект.Код
Предварительный просмотр (внизу)Как форма будет выглядеть—
Вкладка Модуль (внизу)Код формыОбработчики событий

Элемент формы ссылается на данные через свойство ПутьКДанным (например, Объект.Наименование). Чтобы вывести реквизит на форму, перетаскиваем его мышью из области реквизитов в дерево элементов. Имена элементов внутри формы должны быть уникальными.

Новые реквизиты не появятся сами

Пока форма автоматическая, платформа сама показывает все реквизиты. Как только мы создали собственную форму, оформление — наша ответственность: реквизит, добавленный в справочник позже, нужно вручную перетащить на форму.

Список выбора у поля

Иногда реквизиту нужно разрешить лишь несколько вариантов. Выбираем поле → свойства → вкладка «Использование» → включаем РежимВыбораИзСписка и заполняем СписокВыбора:

Свойство «СписокВыбора» поля «Вид номенклатуры»: варианты «Товар» и «Услуга».

  • Значение — что записывается в базу.
  • Представление — что видит пользователь (если пусто — показывается значение).
Список выбора ≠ перечисление

Мы ограничили ввод в одном поле одной формы. В базе по-прежнему лежит строка, и другим кодом туда можно записать что угодно. Объект «Перечисление» задаёт отдельный тип с фиксированным набором значений для всей конфигурации — это надёжнее (12. Перечисления).

Поле ввода или переключатель

Свойство «Вид» элемента определяет, как он выглядит:

Поле ПроисхождениеТовара с видом «Поле переключателя»: на форме радиокнопки «Импортный» и «Отечественный».

ВидКак выглядитКогда удобно
Поле вводаПоле с кнопкой выбора или выпадающим спискомМного вариантов
Поле переключателяРадиокнопки2–4 варианта, которые полезно видеть сразу
Поле флажкаГалочкаБулево
Поле надписиПросто текст (может быть гиперссылкой)Только показать значение
Переключатель для перечисления

Чтобы радиокнопки появились, у поля нужно заполнить СписокВыбора (вкладка «Использование», кнопка «Заполнить» подставит значения перечисления). Иначе переключатель будет пустым.

Группы и страницы

Чтобы разложить поля по вкладкам: в дереве элементов ПКМ → Добавить → Группа — Страницы, внутри неё — несколько Группа — Страница. Перетаскиваем элементы на нужные страницы:

Две страницы: «Раздел основное» с ФИО и «Раздел стаж» с табличной частью СтажРаботы.

Колонки таблицы тоже можно группировать: Добавить → Группа — Группа колонок, в свойствах — Группировка: Вертикальная, затем переносим колонки внутрь группы:

Колонки дат устройства и увольнения помещены в группу колонок.

Результат: даты выводятся друг под другом в одной колонке таблицы.

Имена элементов

Для элементов используем понятные идентификаторы без пробелов: СтраницаОсновное, СтраницаСтаж. Обязательного требования к snake_case у платформы нет; в типовых конфигурациях принят ВерблюжийРегистр.

Оформление полей

Положение заголовка. Свойство ПоложениеЗаголовка = Верх выводит подпись над полем, а не слева:

У поля «Наименование» заголовок перенесён наверх; так компактнее для длинных подписей.

Шрифт заголовка. Вкладка «Оформление» → ШрифтЗаголовка → выбираем, например, полужирный:

Выбор шрифта заголовка: стилевой «Обычный шрифт текста» с начертанием «Полужирный».

Проверь себя

  1. Добавили в справочник реквизит «Артикул», но на форме его нет. Почему и что делать?

  2. Что хранится в свойстве ПутьКДанным у поля «Наименование»?

  3. Чем список выбора поля хуже перечисления?

Ответы
  1. Форма собственная — новые реквизиты нужно перетащить в дерево элементов вручную.
  2. Объект.Наименование — путь к данным, которые показывает поле.
  3. Ограничение действует только в этой форме; тип реквизита остаётся строкой, и кодом можно записать любое значение.
