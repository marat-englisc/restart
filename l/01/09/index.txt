<div class="callout-body"><p>Собственную форму элемента создаём, когда автоматической не хватает. Редактор формы состоит из <strong>дерева элементов</strong> (что видит пользователь), <strong>реквизитов формы</strong> (данные) и <strong>предварительного просмотра</strong>. Элемент связан с данными свойством <strong>ПутьКДанным</strong>. Группы и страницы раскладывают поля по блокам и вкладкам.</p></div>

<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909160533.png" alt="Pasted image 20260909160533.png" loading="lazy" decoding="async"></p>
<p><em>Редактор формы: слева дерево элементов, справа реквизиты (основной — <code>Объект</code>), внизу предварительный вид формы.</em></p>

<p>Элемент формы ссылается на данные через свойство <strong>ПутьКДанным</strong> (например, <code>Объект.Наименование</code>). Чтобы вывести реквизит на форму, перетаскиваем его мышью из области реквизитов в дерево элементов. Имена элементов внутри формы должны быть уникальными.</p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Новые реквизиты не появятся сами</div>
<div class="callout-body"><p>Пока форма автоматическая, платформа сама показывает все реквизиты. Как только мы создали собственную форму, оформление — наша ответственность: реквизит, добавленный в справочник позже, нужно <strong>вручную</strong> перетащить на форму.</p></div>
</div>
<h2 id="список-выбора-у-поля">Список выбора у поля</h2>
<p>Иногда реквизиту нужно разрешить лишь несколько вариантов. Выбираем поле → свойства → вкладка <strong>«Использование»</strong> → включаем <strong>РежимВыбораИзСписка</strong> и заполняем <strong>СписокВыбора</strong>:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909164139.png" alt="Pasted image 20260909164139.png" loading="lazy" decoding="async"></p>
<p><em>Свойство «СписокВыбора» поля «Вид номенклатуры»: варианты «Товар» и «Услуга».</em></p>
<ul>
<li><strong>Значение</strong> — что записывается в базу.</li>
<li><strong>Представление</strong> — что видит пользователь (если пусто — показывается значение).</li>
</ul>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Список выбора ≠ перечисление</div>
<div class="callout-body"><p>Мы ограничили ввод <strong>в одном поле одной формы</strong>. В базе по-прежнему лежит строка, и другим кодом туда можно записать что угодно. Объект «Перечисление» задаёт отдельный тип с фиксированным набором значений для всей конфигурации — это надёжнее (<a href="/restart/l/01/12/" data-internal="true">12. Перечисления</a>).</p></div>
</div>

<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Переключатель для перечисления</div>
<div class="callout-body"><p>Чтобы радиокнопки появились, у поля нужно заполнить <strong>СписокВыбора</strong> (вкладка «Использование», кнопка <strong>«Заполнить»</strong> подставит значения перечисления). Иначе переключатель будет пустым.</p><p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909192255.png" alt="Pasted image 20260909192255.png" loading="lazy" decoding="async"></p></div>

<h2 id="группы-и-страницы">Группы и страницы</h2>
<p>Чтобы разложить поля по вкладкам: в дереве элементов <strong>ПКМ → Добавить → Группа — Страницы</strong>, внутри неё — несколько <strong>Группа — Страница</strong>. Перетаскиваем элементы на нужные страницы:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909235842.png" alt="Pasted image 20260909235842.png" loading="lazy" decoding="async"></p>
<p><em>Две страницы: «Раздел основное» с ФИО и «Раздел стаж» с табличной частью <code>СтажРаботы</code>.</em></p>
<p>Колонки таблицы тоже можно группировать: <strong>Добавить → Группа — Группа колонок</strong>, в свойствах — <strong>Группировка: Вертикальная</strong>, затем переносим колонки внутрь группы:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260910000710.png" alt="Pasted image 20260910000710.png" loading="lazy" decoding="async"></p>
<p><em>Колонки дат устройства и увольнения помещены в группу колонок.</em></p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260910000821.png" alt="Pasted image 20260910000821.png" loading="lazy" decoding="async"></p>
<p><em>Результат: даты выводятся друг под другом в одной колонке таблицы.</em></p>
<div class="callout callout-tip" data-callout="tip">
<div class="callout-title">Имена элементов</div>
<div class="callout-body"><p>Для элементов используем понятные идентификаторы без пробелов: <code>СтраницаОсновное</code>, <code>СтраницаСтаж</code>. Обязательного требования к <code>snake_case</code> у платформы нет; в типовых конфигурациях принят ВерблюжийРегистр.</p></div>

<h2 id="оформление-полей">Оформление полей</h2>
<p><strong>Положение заголовка.</strong> Свойство <strong>ПоложениеЗаголовка = Верх</strong> выводит подпись над полем, а не слева:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260910000959.png" alt="Pasted image 20260910000959.png" loading="lazy" decoding="async"></p>
<p><em>У поля «Наименование» заголовок перенесён наверх; так компактнее для длинных подписей.</em></p>
<p><strong>Шрифт заголовка.</strong> Вкладка <strong>«Оформление» → ШрифтЗаголовка</strong> → выбираем, например, полужирный:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260910001121.png" alt="Pasted image 20260910001121.png" loading="lazy" decoding="async"></p>
<p><em>Выбор шрифта заголовка: стилевой «Обычный шрифт текста» с начертанием «Полужирный».</em></p>
