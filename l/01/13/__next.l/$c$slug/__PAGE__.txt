<div class="callout-title">Коротко</div>
<div class="callout-body"><p>В 1С объекты обычно не удаляют сразу, а <strong>помечают на удаление</strong> (<code>Del</code>). Затем администратор запускает <strong>«Удаление помеченных объектов»</strong>: платформа удаляет только те объекты, на которые никто не ссылается. <strong>Непосредственное удаление</strong> (<code>Shift+Del</code>) проверку не выполняет и оставляет «битые» ссылки.</p></div>
</div>
<h2 id="зачем-двухэтапное-удаление">Зачем двухэтапное удаление</h2>
<p><strong>Пометка удаления</strong> — стандартный реквизит <code>ПометкаУдаления</code> (Булево). На нём построен механизм удаления с <strong>контролем ссылочной целостности</strong>: объект не удалится, если на него ссылаются другие данные.</p>
<p>С точки зрения платформы удаление без контроля допустимо, и ссылки на отсутствующие объекты ошибкой базы не считаются. Поэтому за целостность отвечает именно этот механизм — и пользователю обычно дают право только на пометку.</p>
<pre><pre class="mermaid-source">flowchart LR
    A["Пользователь:&#x3C;br/>пометить на удаление"] --> B["Объект остаётся&#x3C;br/>в базе, значок ×"] --> C["Администратор:&#x3C;br/>удаление помеченных"]
    C -->|ссылок нет| D[Удалён]
    C -->|есть ссылки| E[Остаётся, показан список мешающих ссылок]
</pre></pre>
<h2 id="пометка">Пометка</h2>
<p>В списке: ПКМ → <strong>Пометить на удаление / Снять пометку</strong> (<code>Del</code>):</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909192907.png" alt="Pasted image 20260909192907.png" loading="lazy" decoding="async"></p>
<p><em>Контекстное меню списка. Помеченный элемент «Магомедов М.М.» отмечен красным крестиком.</em></p>
<p>Помеченный объект никуда не исчез: его можно открыть, снять пометку, на него по-прежнему ссылаются документы.</p>
<h2 id="удаление-помеченных-объектов">Удаление помеченных объектов</h2>
<p>Меню (≡) → <strong>Функции для технического специалиста</strong>:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909193254.png" alt="Pasted image 20260909193254.png" loading="lazy" decoding="async"></p>
<p><em>Главное меню 1С:Предприятия: пункт «Функции для технического специалиста».</em></p>
<p>→ <strong>Стандартные → Удаление помеченных объектов</strong>. Доступно два режима:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909193459.png" alt="Pasted image 20260909193459.png" loading="lazy" decoding="async"></p>
<p><em>Выбор режима: полное удаление всех помеченных или выборочное.</em></p>
<p>При выборочном удалении отмечаем нужные объекты:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909193653.png" alt="Pasted image 20260909193653.png" loading="lazy" decoding="async"></p>
<p><em>Список помеченных объектов: два сотрудника.</em></p>
<p>Если на объект есть ссылки, он не удалится, а платформа сообщит об этом. Остальные помеченные объекты удаляются:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909193806.png" alt="Pasted image 20260909193806.png" loading="lazy" decoding="async"></p>

</div>
<h2 id="непосредственное-удаление">Непосредственное удаление</h2>
<p><strong>Ещё → Удалить</strong> (<code>Shift+Del</code>) удаляет объект сразу, без проверки ссылок. Команда доступна только при наличии права «Интерактивное удаление»:</p>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909195058.png" alt="Pasted image 20260909195058.png" loading="lazy" decoding="async"></p>
<p><em>Меню «Ещё» формы списка: «Удалить» (Shift+Del) рядом с «Пометить на удаление» (Del).</em></p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Битые ссылки</div>
<div class="callout-body"><p>Если удалить объект, на который ссылались, в этих местах появится <code>&#x3C;Объект не найден></code> с идентификатором:</p><p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/Pasted%20image%2020260909195150.png" alt="Pasted image 20260909195150.png" loading="lazy" decoding="async"></p><p><em>Константа «Генеральный директор» ссылается на удалённого сотрудника.</em></p><p>Поэтому право непосредственного удаления обычным пользователям не выдают.</p></div>
</div>
