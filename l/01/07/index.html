Константы

Коротко

Константа хранит одно значение на всю базу: название организации, ИНН, основной склад. Значения всех констант лежат в одной таблице. У каждого объекта конфигурации есть имя (для кода), синоним (для пользователя) и тип значения.

Что такое константа

Константа — прикладной объект конфигурации для данных, которые не меняются во времени или меняются очень редко. Каждая константа хранит ровно одно значение.

Пример таблицы констант: имя для кода, синоним для пользователя и хранимое значение.

Если значение должно иметь историю (например, курс или цена на дату) — константа не подходит, нужен регистр сведений (20. Регистры сведений). Если значений много и они однотипны — нужен справочник.

Правила имён объектов

Эти правила действуют для любых объектов конфигурации, реквизитов и переменных:

МожноНельзя
Буквы (русские и латинские), цифры, _Пробелы и спецсимволы (-, ., !…)
ИНН_Организации, Товары2Начинать с цифры: 2Товары

Принятый стиль — ВерблюжийРегистр без подчёркиваний: НазваниеОрганизации, ОсновнойСклад.

Создание константы

Константы → ПКМ → Добавить. Сразу откроется палитра свойств:

Свойства константы НазваниеОрганизации: строка длиной 200 символов переменной длины.

СвойствоЧто задаёт
ИмяИдентификатор в коде: Константы.НазваниеОрганизации
СинонимНазвание, которое видит пользователь
КомментарийПояснение для разработчиков, видно только в Конфигураторе
ТипТип хранимого значения: Строка, Число, Дата, Булево или ссылка (11. Ссылочный тип данных)

Дополнительные свойства зависят от типа:

ТипСвойства
СтрокаДлина; Неограниченная длина — для текста произвольного размера
ЧислоДлина — всего цифр; Точность — цифр после запятой; Неотрицательное — запрет отрицательных значений (ноль разрешён)
ДатаСостав даты: Дата, Время или Дата и время

Подробнее о квалификаторах типов — в 25. Общие реквизиты и составные типы.

Форма констант

Форма — то, через что пользователь видит и вводит данные. По умолчанию платформа строит формы автоматически, и для одной константы это окно выглядит так:

Автоматическая форма одной константы «Генеральный директор».

Чтобы редактировать несколько констант в одном окне, создаём общую форму: Общие → Общие формы → Добавить. Откроется конструктор:

Конструктор общих форм: выбираем тип «Форма констант».

  1. Выбираем тип «Форма констант».
  2. Отмечаем «Использовать стандартные команды» — платформа добавит команду открытия формы в интерфейс.
  3. Далее → отмечаем константы, которые будут на форме:

Шаг выбора реквизитов: три константы организации.

  1. Готово. Чтобы форма появилась в разделе, включаем её в подсистему.

Константы в коде

Установить() сразу записывает значение в базу. Подробнее — 22. Описание типов, метаданные и общие методы.

Проверь себя

  1. Подойдёт ли константа для хранения курса доллара по дням?

  2. Чем имя отличается от синонима?

  3. Число с длиной 10 и точностью 2 — сколько цифр может быть до запятой?

Ответы
  1. Нет: константа хранит одно значение без истории. Нужен периодический регистр сведений.
  2. Имя используется в коде и не может содержать пробелы; синоним видит пользователь.
  3. Восемь: длина включает и целую, и дробную часть.
