Общие модули и контекст выполнения

Коротко

Общий модуль хранит повторно используемые методы; где он доступен, задают флажки: Клиент, Сервер, Вызов сервера, Внешнее соединение, Глобальный, Привилегированный. В модуле формы место выполнения задают директивы &НаКлиенте, &НаСервере, &НаСервереБезКонтекста. С клиента на сервер передаём только простые данные и ссылки, число серверных вызовов минимизируем.

Где живёт код?

МодульДля чего нужен
Управляемого приложенияСобытия запуска и завершения клиентского приложения
СеансаСерверная инициализация сеанса и его параметров
ОбъектаЛогика конкретного элемента или документа
МенеджераОперации для вида объектов в целом
ФормыПоведение конкретной формы, клиентская и серверная части
ОбщийПовторно используемые процедуры и функции

Например, расчёт строки можно вынести в общий модуль. Проверку перед записью оставить в модуле объекта, а реакцию на изменение поля - в модуле формы.

Общий модуль

Создаём его в "Общие" -> "Общие модули". Для функции расчёта без обращения к базе создадим неглобальный РасчетыКлиентСервер, включив "Клиент (управляемое приложение)" и "Сервер".

Новый общий модуль РасчетыКлиентСервер в ветке «Общие модули» и его текст в «1С:Купец», 8.5.1.1150.

Палитра свойств модуля: включены «Клиент» и «Сервер», флажки «Глобальный», «Вызов сервера» и «Привилегированный» сняты. В палитре этой базы флажок клиента подписан коротко — «Клиент».

Из клиентского или серверного кода:

На клиенте выполняется клиентская копия общего модуля, на сервере - серверная. Наличие двух флажков само по себе не отправляет каждый вызов на сервер.

Общий модуль содержит процедуры и функции. В нём нет переменных модуля и исполняемого тела инициализации. Его контекст задаётся свойствами, а не директивами форм. Варианты настройки приведены в стандарте создания общих модулей 1С.

Серверный вызов

Если серверный общий модуль должен вызываться с клиента, включаем "Сервер" и "Вызов сервера". Экспортируем только методы, предназначенные для таких вызовов.

Свойство "Глобальный" позволяет обращаться к экспортным методам без имени модуля. Обычно явное имя понятнее: сразу видно, откуда взят метод.

Свойство "Привилегированный" связано с выполнением без обычной проверки прав. Его не включают просто ради устранения ошибки доступа. Требования к серверному интерфейсу описаны в стандарте 1С.

Директивы модуля формы

ДирективаГде выполняетсяДоступ к данным формы
&НаКлиентеНа клиентеЕсть
&НаСервереНа сервереЕсть, с передачей контекста формы
&НаСервереБезКонтекстаНа сервереНет, только параметры и доступный серверный контекст
&НаКлиентеНаСервереБезКонтекстаВ месте вызоваНет контекста формы

На клиенте показываем окна и обрабатываем действия пользователя. На сервере работаем с объектами базы. Даже в файловом варианте это разделение сохраняется.

Пример вызова из формы

Код модуля формы документа с реквизитом Покупатель:

Обработчик ПоказатьПокупателя связываем с командой формы. На сервер передаётся ссылка, обратно возвращается строка. Серверная функция не обращается к Объект или Элементы формы.

Важно

Не все значения можно передавать между клиентом и сервером. Например, объект документа не передаём на тонкий клиент вместо ссылки. Серверный вызов также не означает асинхронное выполнение.

Директивы и препроцессор

&НаКлиенте задаёт место выполнения метода формы. #Если Сервер Тогда ... #КонецЕсли определяет, какой текст участвует в компиляции для выбранного контекста. #Область группирует код для удобства чтения.

Это разные механизмы. Область с названием Сервер сама по себе не переносит код на сервер.

Число вызовов

Если нужно обработать сто строк, лучше передать необходимые данные и выполнить обработку одним серверным методом, чем делать отдельный вызов для каждой строки. Но на клиент возвращаем только нужный результат и учитываем права пользователя.

Проверь себя

  1. Какие флажки нужны общему модулю, который клиент вызывает для чтения из базы?

  2. Чем &НаСервере отличается от &НаСервереБезКонтекста?

  3. Можно ли передать ДокументОбъект с сервера на тонкий клиент?

Ответы
  1. «Сервер» и «Вызов сервера».
  2. Первая передаёт на сервер данные формы (доступны Объект, реквизиты), вторая — нет, только параметры; она «легче».
  3. Нет; передаём ссылку или простые данные (структуру).
