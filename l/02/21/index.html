Таблицы значений

Коротко

ТаблицаЗначений — таблица в памяти: Колонки.Добавить(), Добавить() строку, Итог(), Найти()/НайтиСтроки(), Сортировать(), Свернуть() (группировка с суммированием). Работает только на сервере (на клиенте — ДанныеФормыКоллекция). Табличная часть объекта выгружается в таблицу через Выгрузить().

Что это?

ТаблицаЗначений - таблица в памяти с колонками и строками. Её удобно использовать для промежуточных расчётов, группировки и подготовки данных.

Таблица значений не является таблицей базы и не записывает данные сама. В управляемом приложении приведённые ниже примеры выполняем на сервере. У формы есть отдельные типы данных, поэтому передавать такую таблицу на тонкий клиент как обычное значение не следует.

Создание колонок и строк

Колонки создаём до обращения к полям строк. Таблица[0] возвращает первую строку, а Таблица[0].Цена - значение её колонки.

Обход и итог

Для общего итога используем числовую колонку. Количество() возвращает количество строк, а не сумму колонки Количество.

Поиск

Найти() возвращает первую подходящую строку или Неопределено:

Для нескольких условий и всех совпадений используем НайтиСтроки():

Результат - массив строк этой таблицы. Изменение найденной строки изменит исходную таблицу, а не независимую копию.

Сортировка и свёртка

После свёртки в копии будет одна строка на товар, а количество и сумма сложатся. Колонки, не указанные в параметрах свёртки, удаляются из результата. Поэтому цену мы здесь потеряем, а исходную таблицу сохранили отдельно.

Важно

Нельзя просто складывать цены разных строк. Среднюю цену, если она нужна, рассчитываем по правилам задачи, например как сумму, делённую на количество.

Выгрузка и загрузка

У табличной части объекта есть методы Выгрузить() и Загрузить(). Они позволяют получить таблицу значений и загрузить совместимые данные обратно.

При загрузке содержимое табличной части заменяется. Сам объект документа после этого ещё нужно записать. Пример работы с ним есть в 24. Программная работа с документами.

Индексы таблицы

Для повторяющегося поиска по одним колонкам можно добавить индекс: Таблица.Индексы.Добавить("Товар"). Он помогает поиску, но не сортирует строки и не запрещает дубликаты.

Проверь себя

  1. Что делает Свернуть("Товар", "Количество,Сумма")?

  2. Почему таблицу значений нельзя просто передать на тонкий клиент?

  3. Чем Найти() отличается от НайтиСтроки()?

Ответы
  1. Оставляет по строке на товар и суммирует количество и сумму; остальные колонки удаляются.
  2. Это серверный тип; на клиенте данные формы представлены другими типами.
  3. Найти возвращает первую строку по значению, НайтиСтроки — массив всех строк по структуре отбора.
