<div class="callout-title">Коротко</div>
<div class="callout-body"><p>Арифметика: <code>+ - * /</code> и <code>%</code> (остаток). Округление — <code>Окр(Число, Знаков)</code>, целая часть — <code>Цел()</code> (отбрасывает дробь, не округляет вниз). В коде дробь отделяется <strong>точкой</strong>. Для вывода — <code>Формат(Число, "ЧДЦ=2")</code>, результат которого — строка. Денежные суммы округляем по единому правилу везде.</p></div>
</div>
<h2 id="определение">Определение</h2>
<p><strong>Тип число</strong> нужен для хранения числовых значений: как
целочисленных, так и дробных.</p>
<h2 id="арифметика">Арифметика</h2>
<p>Поддерживаются следующие арифметические операции:</p>





























<div class="table-wrap"><table><thead><tr><th>Оператор</th><th>Значние</th></tr></thead><tbody><tr><td>+</td><td>Сложение</td></tr><tr><td>-</td><td>Вычитание или смена знака</td></tr><tr><td>*</td><td>Умножение</td></tr><tr><td>/</td><td>Деление</td></tr><tr><td>%</td><td>Остаток</td></tr></tbody></table></div>
<h2 id="округление">Округление</h2>
<p>Полезные методы для работы с числами:</p>



































<div class="table-wrap"><table><thead><tr><th>Метод / Функция</th><th>Что делает</th><th>Пример</th></tr></thead><tbody><tr><td>Окр()</td><td>Округляет переданное значение</td><td>Окр(12.132, 1) // 12.1</td></tr><tr><td>Цел()</td><td>Отделяет целую часть</td><td>Цел(12.54) // 12</td></tr><tr><td>Мин()</td><td>Находит минимальное число</td><td>Мин(10, 20) // 10</td></tr><tr><td>Макс()</td><td>Находит максимальное число</td><td>Макс(10, 20) // 20</td></tr><tr><td>Число()</td><td>Преобразует значение в число</td><td>Число("123") // 123</td></tr></tbody></table></div>
<p><code>Цел()</code> отбрасывает дробную часть и у отрицательных чисел: <code>Цел(-12.54)</code> вернёт -12. Это не округление вниз до -13.</p>
<p>В программном коде дробную часть отделяем точкой. В пользовательском поле число может отображаться с запятой: это зависит от региональных настроек.</p>
<p>Для суммы строки документа обычно нужно явно определить точность:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">Количество </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-token-constant)"> 3</span><span style="color:var(--shiki-token-keyword)">;</span></span>

<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Важно</div>
<div class="callout-body"><p>Округление каждой строки и округление только общего итога могут дать разные результаты. Правило округления должно быть одинаковым в форме, при записи и в печатной форме.</p></div>

<h2 id="форматирование">Форматирование</h2>
<p>Если нам нужно показать число с двумя знаками после запятой:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">ТекстСуммы </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-token-function)"> Формат</span><span style="color:var(--shiki-foreground)">(</span><span style="color:var(--shiki-token-constant)">1250.5</span><span style="color:var(--shiki-token-keyword)">,</span><span style="color:var(--shiki-token-string-expression)"> "ЧДЦ=2; ЧГ=0"</span><span style="color:var(--shiki-foreground)">)</span><span style="color:var(--shiki-token-keyword)">;</span></span>

<p>Результат <code>Формат()</code> имеет тип <strong>Строка</strong>. Само число не меняется. Для расчётов сохраняем число, а форматирование применяем при выводе.</p>
