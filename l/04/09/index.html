Таблица формы и текущая строка

Коротко

Различаем три вещи: Объект.Товары — данные всех строк, Элементы.Товары — таблица на экране, Элементы.Товары.ТекущиеДанные — данные текущей строки (или Неопределено). Обходим и меняем данные, текущую строку получаем через элемент. Активную строку задаём идентификатором: ТекущаяСтрока = Строка.ПолучитьИдентификатор().

ВыражениеЧто это
Объект.ТоварыКоллекция строк в данных формы
Элементы.ТоварыЭлемент-таблица
Элементы.Товары.ТекущиеДанныеДанные строки под курсором
Элементы.ТоварыКоличествоПоле-колонка количества

ТоварыКоличество — имя элемента, Количество — имя реквизита строки.

Проверяем таблицу и колонки

У таблицы Товары — ПутьКДанным = Объект.Товары, у колонок — Объект.Товары.Товар, .Количество, .Цена, .Сумма.

Таблица Товары и её колонки в дереве элементов.

Нет колонки — переносим реквизит из Объект → Товары. Не создаём реквизит Количество в корне формы: это будет не количество строки.

Текущая строка

Команда ПоказатьТекущуюСтроку + кнопка в командной панели таблицы:

ТекущиеДанные — не копия: присваивание СтрокаТовара.Количество = 2 изменит строку формы. Проверка на Неопределено обязательна: таблица пустая или активной строки нет.

Все строки — обходим данные

Цикл по Элементы.Товары написать нельзя — это элемент, а не коллекция. Сортировка на экране не влияет на расчёт.

Добавить строку программно

  • Добавить() — у коллекции данных.
  • ТекущаяСтрока принимает идентификатор строки данных формы, а не номер: 0 не означает «первая строка».
  • Модифицированность = Истина — форма считается изменённой (при закрытии будет вопрос о сохранении); это не запись.

Удалить текущую строку

Стандартная команда удаления умеет больше (множественное выделение) — собственная кнопка нужна не всегда.

Текущая строка — только на клиенте

На сервере нет состояния выделения. Нужен выбранный товар на сервере — получаем строку на клиенте и передаём СтрокаТовара.Товар параметром. См. пояснение 1С о реквизитах и элементах.

Проверка

  1. Пустая таблица → «показать строку» → понятное сообщение.
  2. Две строки → команда показывает именно выбранную.
  3. Общее количество учитывает обе строки.
  4. Удаление текущей строки сохраняет остальные.
  5. Закрываем без записи — в базе ничего не изменилось.
Проверь себя

  1. Как обойти все строки товаров на клиенте?

  2. Почему Элементы.Товары.ТекущаяСтрока = 0 — ошибка в логике?

  3. Записывает ли Модифицированность = Истина документ?

Ответы
  1. Для Каждого Строка Из Объект.Товары Цикл.
  2. Свойство ожидает идентификатор строки, а не её номер.
  3. Нет, только помечает форму изменённой.
