<div class="callout-title">Коротко</div>
<div class="callout-body"><p>Жизненный цикл формы: <code>ПриСозданииНаСервере</code> (сервер — подготовка данных и настроек) → <code>ПриОткрытии</code> (клиент) → … → <code>ПередЗакрытием</code> (можно отменить) → <code>ПриЗакрытии</code>. Начальные значения готовим <strong>на сервере при создании</strong>, чтобы не делать лишний серверный вызов. Обработчик работает, только если он <strong>назначен</strong> в свойствах формы.</p></div>

<h2 id="события-формы">События формы</h2>
<pre><pre class="mermaid-source">flowchart LR
    A["ПриСозданииНаСервере&#x3C;br/>сервер"] --> B["ПриОткрытии&#x3C;br/>клиент"] --> C["работа пользователя"] --> D["ПередЗакрытием&#x3C;br/>клиент, Отказ"] --> E["ПриЗакрытии&#x3C;br/>клиент"]
</pre></pre>






























<div class="table-wrap"><table><thead><tr><th>Событие</th><th>Контекст</th><th>Для чего</th></tr></thead><tbody><tr><td><code>ПриСозданииНаСервере</code></td><td>Сервер с контекстом</td><td>Начальные значения, настройки элементов, данные из базы</td></tr><tr><td><code>ПриОткрытии</code></td><td>Клиент</td><td>Клиентские действия при показе окна</td></tr><tr><td><code>ПередЗакрытием</code></td><td>Клиент</td><td>Проверка, можно ли закрыть</td></tr><tr><td><code>ПриЗакрытии</code></td><td>Клиент</td><td>Завершающие действия; отменить закрытие уже нельзя</td></tr></tbody></table></div>
<p>Если платформа активирует <strong>уже открытое</strong> окно, оно не создаётся заново — <code>ПриСозданииНаСервере</code> не повторится.</p>
<h2 id="где-найти-события">Где найти события</h2>
<p>Вкладка <strong>Форма</strong> → выделяем <strong>корень</strong> дерева «Форма» (не поле!) → свойства → <strong>События</strong>:</p>

<p>Обработчик есть — переходим к нему; нет — создаём кнопкой рядом. Конфигуратор подставит правильные параметры.</p>
<div class="callout callout-warning" data-callout="warning">

<h2 id="закрытие">Закрытие</h2>
<p>Платформа сама спрашивает о сохранении изменённого документа — не заменяем это своим вопросом без причины. Закрытие окна не означает записи. Для собственного подтверждения используем асинхронный вопрос (<a href="/restart/l/04/22/" data-internal="true">22. Асинхронные вопросы пользователю</a>). При завершении всего приложения в обработчиках закрытия есть ограничения — см. <a href="https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_8.3.23_Developer_Guide/Chapter_7._Forms/7.9._Working_with_a_form_from_the_1C_Enterprise_language/7.9.7._Different_approaches_to_modality/?language=en" target="_blank" rel="noopener noreferrer">документацию 1С</a>.</p>
<h2 id="проверка">Проверка</h2>
<ol>
<li>Открываем накладную с суммами 300 и 300 — сразу видим <strong>600</strong>; новую пустую — <strong>0</strong>.</li>
<li>Ставим точки останова в обоих обработчиках: сначала остановимся на сервере, затем на клиенте.</li>
</ol>
<p>Не вызываем обработчики друг из друга «для проверки»: прямой вызов не воспроизводит жизненный цикл формы.</p>
