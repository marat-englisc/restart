<h2 id="подготовка">Подготовка</h2>
<ul>
<li><code>Договоры</code> подчинён контрагентам (вкладка «Владельцы»), у договора есть <code>Владелец</code>.</li>
<li>У <code>Номенклатура</code> есть реквизит <code>ВидНоменклатуры</code> типа <code>ПеречислениеСсылка.ВидыНоменклатуры</code>.</li>
<li>Для проверки: два покупателя с договорами, товар и услуга с заполненным видом. На пустом справочнике ограничение не проверить.</li>
</ul>
<h2 id="договор-только-выбранного-покупателя">Договор только выбранного покупателя</h2>
<ol>
<li><code>РасходнаяНакладная → Данные → Договор</code> → свойства → <strong>Связи параметров выбора</strong>.</li>
<li>Имя параметра <code>Отбор.Владелец</code>, реквизит <code>Покупатель</code>, режим изменения <strong>Очищать</strong>.</li>
</ol>
<p>Связь работает в форме выбора, быстром выборе и вводе по строке — см. <a href="https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_8.3.23_Developer_Guide/Chapter_5._Configuration_objects/5.4._Common_configuration_object_properties/5.4.17._Choice_parameter_links/?language=en" target="_blank" rel="noopener noreferrer">руководство 1С</a>. В форме проверяем, что у поля договора путь <code>Объект.Договор</code> и его собственные настройки не противоречат реквизиту. Собственная связь у поля нужна, только если это поле должно вести себя иначе (тогда источник — <code>Объект.Покупатель</code>).</p>
<p>«Очищать» срабатывает при <strong>интерактивной</strong> смене покупателя. Если покупателя меняет код — сбрасываем договор сами:</p>

<h2 id="только-товары-в-колонке-товар">Только товары в колонке «Товар»</h2>
<ol>
<li><code>Товары → Товар</code> → <strong>Параметры выбора</strong> → <code>Отбор.ВидНоменклатуры</code>.</li>
<li>Значение — <strong>значение перечисления</strong> <code>Товар</code> (не строка «Товар»).</li>
<li>Для <code>Услуги → Услуга</code> — значение <code>Услуга</code>.</li>
</ol>
<p>Своя форма выбора или произвольная общая форма сама эти параметры не учтёт. Поэтому у поля <code>ВыбранныйТовар</code> формы подбора (тема 16) задаём параметр выбора отдельно:</p>

<p><em>Параметры выбора у поля <code>ВыбранныйТовар</code> общей формы: <code>Отбор.ВидНоменклатуры</code> = «Товар».</em></p>
<h2 id="почему-нужна-серверная-проверка">Почему нужна серверная проверка</h2>
<p>Обработка может присвоить <code>Товары[0].Товар</code> ссылку на услугу, не открывая окно выбора. Обязательные правила — договор принадлежит покупателю, в товарах только товары — проверяем в модуле объекта с <code>Отказ = Истина</code>. Отбор в окне выбора не заменяет и права доступа.</p>
<h2 id="проверка">Проверка</h2>
<ol>
<li>Покупатель А → выбор договора → только договор А.</li>
<li>Меняем на Б → договор очистился → выбор → договор Б.</li>
<li>Проверяем и ввод по строке, и быстрый выбор.</li>
<li>В товарах нет услуг, в услугах — товаров; подбор тоже фильтрует.</li>
</ol>
