<div class="callout-body"><p>Чтобы показать на форме результат запроса: реквизит формы типа <strong>ТаблицаЗначений</strong> с заранее объявленными колонками → таблица на форме → серверная процедура (<code>&#x26;НаСервере</code>) выполняет запрос и вызывает <code>ЗначениеВРеквизитФормы(Таблица, "Результаты")</code>. <p>Создаём общую форму <code>ТоварыУчебные</code> с таблицей номенклатуры и кнопкой «Обновить товары». Ничего не записываем. Для больших рабочих списков удобнее <a href="/restart/l/04/19/" data-internal="true">динамический список</a>; здесь — явная загрузка ограниченного набора.</p>
<h2 id="реквизит-и-таблица">Реквизит и таблица</h2>
<ol>
<li><strong>Общие → Общие формы → Добавить</strong> <code>ТоварыУчебные</code>.</li>

</ol>

<p>Для неиерархического справочника убираем <code>НЕ Н.ЭтоГруппа</code> — такого поля нет. <code>ПЕРВЫЕ 100</code> — это не постраничный вывод, а ограничение: остальные товары не попадут.</p>
<h2 id="три-уровня-одной-таблицы">Три уровня одной таблицы</h2>





















<div class="table-wrap"><table><thead><tr><th>Выражение</th><th>Что это</th></tr></thead><tbody><tr><td><code>ТаблицаТоваров</code> в серверной процедуре</td><td>Обычная <code>ТаблицаЗначений</code> на сервере</td></tr><tr><td><code>Результаты</code></td><td>Данные формы, <code>ДанныеФормыКоллекция</code></td></tr><tr><td><code>Элементы.Результаты</code></td><td>Таблица интерфейса</td></tr></tbody></table></div>
<p>Методы таблицы значений нельзя автоматически применять к <code>Результаты</code> — см. <a href="https://kb.1ci.com/1C_Enterprise_Platform/Tutorials/Practical_developer_guide_8.3/Lesson_27._Form_development_techniques/Form_data_types/" target="_blank" rel="noopener noreferrer">пособие 1С о типах данных формы</a>. <code>ЗначениеВРеквизитФормы</code> требует контекста формы — <code>&#x26;НаСервере</code>, а не без контекста.</p>
<h2 id="открытие-и-проверка">Открытие и проверка</h2>
<p>Из формы накладной: <code>ОткрытьФорму("ОбщаяФорма.ТоварыУчебные");</code>.</p>
<ul>
<li>После «Обновить товары» — до 100 строк по алфавиту, без групп и помеченных.</li>
<li>Повторное нажатие <strong>заменяет</strong> набор, а не удваивает.</li>
<li>До первого нажатия таблица пустая; для автозагрузки вызываем процедуру из <code>ПриСозданииНаСервере</code>.</li>
<li>Запрос выполняется с правами пользователя — у ограниченной роли строк может быть меньше.</li>
</ul>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Проверь себя</summary>
<div class="callout-body"><ol>
<li>
<p>Почему процедура загрузки — <code>&#x26;НаСервере</code>, а не <code>&#x26;НаСервереБезКонтекста</code>?</p>
</li>
<li>
<p>Что будет, если колонки реквизита назвать иначе, чем поля запроса?</p>
</li>
<li>
<p>Чем такая таблица хуже динамического списка для 100 000 товаров?</p>
</li>
</ol><details class="callout callout-success" data-callout="success">
<summary class="callout-title">Ответы</summary>
<div class="callout-body"><ol>
<li><code>ЗначениеВРеквизитФормы</code> изменяет реквизит формы — нужен её контекст.</li>
<li>Значения не попадут в колонки — сопоставление идёт по именам.</li>
<li>Загружает весь набор в форму сразу; динамический список читает порциями.</li>
</ol></div>
