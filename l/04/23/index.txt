<div class="callout-title">Коротко</div>
<div class="callout-body"><p>Элементы, реквизиты и команды можно создавать кодом <strong>на сервере</strong> (обычно в <code>ПриСозданииНаСервере</code>): реквизиты — <code>ИзменитьРеквизиты(МассивРеквизитовФормы)</code> одним вызовом, поля и кнопки — <code>Элементы.Добавить(Имя, Тип, Родитель)</code>, команды — <code>Команды.Добавить()</code>, обработчики — <code>УстановитьДействие()</code> / <code>Действие</code>. Это нужно, когда состав формы заранее неизвестен; в остальных случаях — редактор.</p></div>
</div>
<p>Пример: в форме накладной создать поле «Учебный комментарий», обработчик его изменения и кнопку «Показать комментарий». Значение живёт только в форме.</p>
<h2 id="подготовка">Подготовка</h2>
<ol>
<li>В редакторе — обычная группа <code>ГруппаУчебныхЭлементов</code> (заголовок «Учебные элементы»): место для новых элементов.</li>
<li>Имён <code>КомментарийУчебный</code>, <code>ПоказатьКомментарийУчебный</code>, <code>КнопкаКомментарияУчебного</code> в форме ещё нет.</li>
<li>В <code>ПриСозданииНаСервере</code> добавляем вызов <code>ДобавитьУчебныеЭлементы()</code>.</li>
</ol>

<p>К динамическому реквизиту обращаемся через <code>ЭтотОбъект.Имя</code>: при проверке модуля он ещё не объявлен, и простое <code>КомментарийУчебный</code> вызвало бы «Переменная не определена».</p>
<h2 id="порядок-и-правила">Порядок и правила</h2>
<ol>
<li><strong>Данные → элемент → команда → кнопка.</strong> Поле без <code>ПутьКДанным</code> ничего не покажет.</li>
<li>Все реквизиты — <strong>одним</strong> вызовом <code>ИзменитьРеквизиты</code> (каждый вызов перестраивает форму). См. раздел 7.9.4 <a href="https://1c-dn.com/download-trial/files/guides/developer_guide.pdf" target="_blank" rel="noopener noreferrer">руководства разработчика 1С</a>.</li>
<li>Изменения живут только в <strong>текущем экземпляре</strong> формы: дерево в Конфигураторе не меняется, при следующем открытии код создаст элементы заново.</li>
<li>Удалять программно можно только программно созданное; обычный элемент скрываем <code>Видимость</code>.</li>
</ol>
