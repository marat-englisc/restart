<div class="callout-body"><p>Практика по темам 15–24: подбор товара через общую форму с возвратом результата, учебный список накладных с собственным отбором по покупателю и общая форма с таблицей результата запроса. Проверяем отмену, повторное открытие и совместную работу отборов.</p></div>

<p>Выполняется после <a href="/restart/l/04/26/" data-internal="true">26. Практика по форме документа</a>. Созданные ранее формы, реквизиты и команды используем повторно.</p>
<h2 id="шаг-1-форма-подбора">Шаг 1. Форма подбора</h2>
<p>По <a href="/restart/l/04/16/" data-internal="true">16. Общая форма для подбора товара</a>: <code>ПодборТовараУчебный</code>, реквизит <code>ВыбранныйТовар</code>, параметр <code>НачальныйТовар</code>, команды «Добавить в накладную» (<code>Закрыть(ВыбранныйТовар)</code>) и «Отмена» (<code>Закрыть()</code>). В общей форме нет <code>Объект.Товары</code> — она только возвращает значение.</p>
<h2 id="шаг-2-подбор-из-накладной">Шаг 2. Подбор из накладной</h2>

<h2 id="шаг-5-отбор-и-выбранная-запись">Шаг 5. Отбор и выбранная запись</h2>
<ol>
<li>Без покупателя — все доступные накладные.</li>
<li>А → только А; Б → только Б (не пересечение).</li>
<li>Очистили поле — снят только наш отбор.</li>
<li>Пользовательский отбор по периоду сохраняется при смене покупателя.</li>
<li>Двойной щелчок открывает документ строки, а не новый.</li>
</ol>
<h2 id="шаг-6-статическая-таблица">Шаг 6. Статическая таблица</h2>
<p>По <a href="/restart/l/04/24/" data-internal="true">24. Загрузка таблицы формы на сервере</a>: <code>ТоварыУчебные</code>, до 100 товаров запросом в реквизит <code>Результаты</code>. Изменения справочника появятся только после «Обновить» — в отличие от динамического списка.</p>
