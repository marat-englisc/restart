Горячие клавиши

О шпаргалке

Сочетания клавиш Конфигуратора и 1С:Предприятия, которые используются в курсе. Актуальный список — в меню соответствующей версии платформы.

Конфигуратор: общее

КлавишиДействие
Ctrl+SСохранить основную конфигурацию
F7Обновить конфигурацию базы данных
F5Начать отладку (запустить Предприятие с отладчиком)
Ctrl+F5Запустить Предприятие без отладки
Alt+EnterПалитра свойств выбранного объекта
Ctrl+Alt+MПоиск в дереве конфигурации
Ctrl+Shift+FГлобальный поиск по модулям
F9 (в дереве)Скопировать объект
InsertДобавить объект
Ctrl+Shift+Up / DownПереместить объект вверх/вниз
Alt+Shift+F2Добавить объект в расширение
Ctrl+F1Синтакс-помощник для слова под курсором

Редактор модулей

КлавишиДействие
Ctrl+ПробелКонтекстная подсказка, автодополнение
Ctrl+Shift+ПробелПодсказка по параметрам метода
Ctrl+QШаблоны кода (Если, Для, Пока…)
Ctrl+Alt+PСписок процедур и функций модуля
F12Перейти к определению метода
Ctrl+F7Синтаксическая проверка модуля
Shift+Alt+FФорматирование отступов
Ctrl+/ / Ctrl+Shift+/Закомментировать / раскомментировать строки
Ctrl+F, F3Найти, найти следующее
Ctrl+HЗаменить
Ctrl+GПерейти к строке

Отладка

КлавишиДействие
F9Поставить / снять точку останова
F10Шаг без захода в метод
F11Шаг с заходом в метод
Shift+F11Выйти из текущего метода
F5Продолжить выполнение
Shift+F9Вычислить выражение

Список точек останова, условная точка останова, табло, стек вызовов — в меню Отладка (сочетания отличаются по версиям).

КлавишиДействие

Shift+DeleteУдалить непосредственно (если есть право)

Ctrl+QОтменить поиск
Ctrl+EnterЗаписать и закрыть
Ctrl+SЗаписать
Ctrl+Shift+FПоиск по всей программе
Ctrl+F11 / Shift+F11Получить / перейти по ссылке
