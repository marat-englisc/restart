Где писать код

О шпаргалке

Самый частый вопрос новичка — «в какой модуль это писать?». Таблица модулей, ключевых событий и решений «клиент или сервер».

Решение «куда писать»

flowchart TD
    Q{"Правило должно работать<br/>при ЛЮБОЙ записи?"} -- да --> O["Модуль объекта<br/>(или подписка для многих объектов)"]
    Q -- нет --> F{"Это реакция<br/>интерфейса?"}
    F -- да --> FC["Модуль формы &НаКлиенте<br/>(+ сервер без контекста для данных)"]
    F -- нет --> R{"Нужно в нескольких местах?"}
    R -- да --> C["Общий модуль"]
    R -- нет --> M["Модуль менеджера<br/>(операция над видом объектов)"]

Клиент или сервер

НужноГде
Показать вопрос, предупреждение, открыть формуКлиент
Текущая строка таблицы, видимость элементаКлиент
Простая арифметика над данными формыКлиент
Запрос, ПолучитьОбъект(), запись, движенияСервер
Чтение реквизита по ссылке (Ссылка.Наименование)Сервер
Файлы на диске сервера, HTTP-запросы к внешним сервисамСервер
Тяжёлая длительная операцияФоновое задание

Директивы модуля формы

ДирективаДанные формы на сервереКогда
&НаКлиенте—Интерфейс и ввод
&НаСервереПередаютсяНужно менять реквизиты формы на сервере (ЗначениеВРеквизитФормы, РеквизитФормыВЗначение)
&НаСервереБезКонтекстаНе передаютсяПолучить данные по параметрам — по умолчанию для серверных функций формы
&НаКлиентеНаСервереБезКонтекста—Чистые вычисления, нужные и там и там
